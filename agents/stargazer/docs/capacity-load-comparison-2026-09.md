# Stargazer 采集并发负载对比（2026-09）

数值均来自 `event=collection_capacity`、运行终态汇总和 NATS 发布终态，不使用主观观察值。

默认有 4 个 Sanic worker。并发参数按 worker 生效，因此理论聚合活跃目标上限从 `4 × 160 = 640`
降为 `4 × 120 = 480`；三类数值是公平调度软配额，某类没有积压时其他类别仍可借满该 worker 的总并发。
