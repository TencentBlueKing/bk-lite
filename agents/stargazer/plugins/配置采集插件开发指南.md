# Stargazer 采集插件开发指南

## 统一契约

配置采集插件和业务 `monitor_plugins` 共用 `CollectionRuntime`、协议预检、目标并发、目标内凭据
轮询、结果发布和 Redis fencing。两类插件只保留输入参数与结果产物差异。

注册插件必须暴露协程入口：

```python
class ExampleCollector:
    async def list_all_resources(self):
        ...
```

`PluginExecutor` 始终执行：

```python
result = await collector_instance.list_all_resources()
```

运行时没有同步插件 Adapter、`execution_mode` 或插件专用线程池。

## 原生异步插件

优先使用异步网络客户端，并在每一层配置真实连接、读取和总超时：

```python
class HttpCollector:
    async def list_all_resources(self):
        async with httpx.AsyncClient(
            timeout=httpx.Timeout(connect=5, read=30, write=10, pool=5)
        ) as client:
            response = await client.get(self.endpoint)
            response.raise_for_status()
        return {"success": True, "result": {"example": [response.json()]}}
```

禁止在 `async def` 中直接调用 `requests`、同步数据库驱动、同步 SSH/SNMP SDK 或 `time.sleep()`。

## 同步 SDK 包装

暂时无法原生异步化的插件必须在插件自身显式包装：

```python
import asyncio


class LegacySdkCollector:
    async def list_all_resources(self):
        return await asyncio.to_thread(self._sync_collect)

    def _sync_collect(self):
        # SDK 本身仍必须设置真实 timeout；外层取消无法杀死已运行线程。
        return self.client.fetch(timeout=30)
```

`asyncio.to_thread()` 使用 asyncio 共享默认线程池。不要在插件里创建新的 `ThreadPoolExecutor`，
也不要把整个目标任务包装进线程。目标窗口会限制同时执行或等待共享线程池的采集数量。

如果父类已经是异步插件，子类必须 `await super()`：

```python
class CompatibleDatabaseCollector(PostgresqlInfo):
    async def list_all_resources(self):
        data = await super().list_all_resources()
        return rename_model(data)
```

## plugin.yml

每个 executor 必须声明正数超时：

```yaml
executors:
  protocol:
    type: protocol
    timeout: 30
    collector:
      module: plugins.inputs.example.example_info
      class: ExampleCollector
```

HTTP 入口的 `model_id`、`executor_type`、目标和凭据由运行时组装。插件一次只接收一个目标和一
个凭据，不得自行展开 IP×凭据，不得提交新的全局任务。

## 结果

配置插件继续返回：

```python
{
    "success": True,
    "result": {"model_id": [{"inst_name": "example"}]},
}
```

`CollectionService` 将结果转为配置采集指标；`NatsResultPublisher` 添加
`collection_task_id`、`collection_target`、`collection_plugin_ref` 和 `collection_fence` 后发布。
callback 插件返回业务字典。密码、Token、community 和私钥不得出现在结果、异常、日志或
Redis 状态中。

错误必须保留可分类信息：

- 认证/权限错误：允许同一目标继续尝试下一凭据；
- IP/端口不可达：结束目标，不冷冻凭据；
- SNMP 无响应：可尝试下一凭据，但不直接判定 IP 离线；
- 限流、解析或插件代码错误：结束目标，不盲目换凭据。

## 测试

新增或修改插件至少运行：

```bash
uv run pytest -q -o addopts='' tests/test_async_plugin_contract.py
```

插件测试必须 `await list_all_resources()`。同步 SDK 包装还要验证事件循环心跳持续推进，以及
SDK 收到真实 timeout 参数。统一运行时回归覆盖预检失败不尝试凭据、目标内串行轮询、冷冻/
亲和、fencing、断点和 `255×5×200` 并发场景。
