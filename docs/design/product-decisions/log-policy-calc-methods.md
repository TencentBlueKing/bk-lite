# 日志策略计算方式产品决策记忆

- 最近更新：2026-10-27
- 当前规格：`specs/changes/log-policy-calc-catalog/spec.md`（第二批，approved）；第一批 `specs/changes/log-policy-calc-methods/spec.md`（implemented）

## 产品定位

日志聚合策略的条件从「本窗聚合值比固定阈值」扩展为「函数 × 比较方式 × 对照」，覆盖竞品（Datadog、Elastic、Loki、Splunk、SLS）日志告警里客户实际会配的场景：突增、断流、占比、影响面、同比、分位、抖动抑制。能力用命名函数和下拉表达，不做公式编辑器。关键字策略保持「命中即告警」，另加策略级无数据告警。日志告警仍由人工关闭，不引入恢复状态机。

## 已确认范围

- 第一批（已落地）：`count_rate`（条/秒）、变化量、只读试算端点、聚合样本 ≤10、回跳查询冻结、通知带命中数 / 样本 / 检索链接。
- 第二批（approved，2026-10-27）：
  - 函数新增 `count_uniq`（去重计数）、`quantile`（P50/P90/P95/P99）、`ratio`（占比，分子为 LogsQL 过滤、分母为策略查询）、`bytes_rate`（字节/秒）。
  - 比较方式 `absolute / delta / percent`，对照 `previous_window / offset_1h / offset_24h / offset_7d`，适用于 `count / sum / avg / max / min / count_uniq / quantile`。
  - 策略级无数据告警开关 + 独立级别；无分组看本窗 0 行，有分组看「上一等长窗出现、本窗缺失」的分组。
  - 规则级连续满足次数 `trigger_count` 1..5，无状态重查前 N−1 窗。
  - 试算、通知命中行、告警名称模板、详情页随契约扩展为逐条件展示。

## 已确认设计决策

- 条件模型为正交三元「函数 × 比较方式 × 对照」，`compare` / `params` 作为条件内可选字段，无新模型列、无迁移。原因：七个可比较函数乘三种比较方式不能再用函数枚举铺开；与监控 `compare_mode` 同一套词。
- 第一批的 `count_delta` 在读写两侧归一为 `count + delta + previous_window`，仍接受旧载荷。原因：已提交未发版，不构成对外契约破坏。
- 对照窗跑与本窗同一条聚合查询（只换起止），一次拿到所有函数的对照值；每个不同的对照时段查一次。
- `percent` 对照为 0 时无定义，该条件判 False、试算显示「对照为 0」；`delta` 对照缺分组：计数类记 0（可触发），均值 / 分位记缺失（不触发）。原因：没日志对计数是 0，对均值是「没有值」。
- `ratio` 用 VictoriaLogs 条件计数 `count() if (<filter>)` 在同一条查询里算，分母为 0 不触发；不另写分母查询。
- 对照查询失败：依赖它的条件判 False，不告警不通知，记有界 WARNING；不重试不阻塞。
- 无数据是策略级开关而不是 `count < 1` 条件；有分组时以上一等长窗分组集合为全集；无数据事件与正常事件 `source_id` 不同，互不归并；连续次数不作用于无数据。
- 连续次数无状态实现（重查前 N−1 窗），N ≤ 5 限住查询放大；任一窗失败本轮不判。
- 不做公式编辑器 / 任意 SQL / 自定义触发表达式。原因：表达式会让校验、试算、回跳、通知渲染全退化成字符串。
- `ratio` 分子筛选拒绝 `|`，并经检索同一套 `message → _msg` 映射后整体加括号拼接。
- 速率单位固定条/秒；`delta` 允许负阈值表示骤降。
- 样本上限 10；`limit` 默认 5；通知默认带截断样本与检索链接，不做策略级开关。
- 回跳查询由后端在事件产生时冻结；试算与保存同一授权；试算弹窗为 log app-local 组件。

## 已替代决策

- 2026-10-27 替代「用条件函数枚举而不是策略级计算方式字段」：改为条件内正交字段「函数 × 比较方式 × 对照」。原枚举思路在加入百分比与多对照后膨胀为二十余个组合。
- 2026-10-27 替代「对照固定上一等长窗，只做绝对差」：对照改为四档可选，比较方式加入变化率；「对照为 0 时百分比无定义」的顾虑通过「判 False 并在试算里展示」处理，`delta` 仍保留「缺分组记 0、新分组突增可响」。
- 2026-10-27 把「1h / 24h / 7d 环比、百分比、错误占比、无数据」从明确后置移入第二批范围。
