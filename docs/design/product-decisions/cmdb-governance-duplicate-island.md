# CMDB 数据治理产品决策记忆

- 最近更新：2026-11-06
- 当前规格：`specs/changes/cmdb-governance-duplicate-island/spec.md`

## 产品定位

数据治理页用来处理已经落库的资产问题。它不替代唯一规则的写入拦截，也不把重复和孤岛塞进运营分析看板。

## 已确认范围

- 检查路径是完整性、新鲜度、重复、孤岛。唯一性冲突出现在清单里，没有单独的指标卡。
- 重复规则不拦截写入。任一比较字段为空的实例不进组。字段不能和唯一规则重叠。
- 孤岛只看必连关系的源实例。目标模型没有实例时不报。
- 只有内置名称唯一、没有其他治理配置的模型，不进入健康度分母。
- 问题行按日重算。忽略只在成员和规则字段都没变时生效。指标比例等下一次日更。
- 重新采集进入现有采集任务页，不另做实例级重跑。
