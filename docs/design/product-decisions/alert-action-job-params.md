# 告警处理作业参数产品决策记忆

- 最近更新：2026-09-20
- 当前规格：`specs/changes/alert-action-job-params/spec.md`

## 产品定位

告警处理规则把作业脚本跑起来，服务「命中后自动处置」和「值班人员手动补跑」。参数来源可以是告警字段，也可以是规则里的手填值；不是把作业模板的每个入参都强制映射成告警字段。

## 已确认范围

- 选作业后每个脚本参数默认手动填写，并回写模板明文默认值。
- 每个参数可改为变量传递；变量传递必须选告警字段或触发事件类型才能保存。
- 变量下拉可绑定本次触发事件；脚本收到的是事件 Key（创建 `created`、分派 `assigned`、认领 `acknowledged`、恢复 `resolved`、关闭 `closed`）。手动执行按告警当前状态映射为同一套 Key，不传 `manual`。
- 仅手动填写可打开「执行时可改」，默认关；手动触发（含再次执行）只弹这些项。
- 规则级「自动执行」默认开，存量视为开；关掉则命中不自动跑，仍可手动跑。手动关闭且规则勾选了关闭时，关闭前询问是否按现有手动执行流程跑一次。生命周期已结束（关闭、自动关闭、自动恢复、已处理）禁止手动执行。
- 编辑时按作业最新参数做结构对齐；提供从作业模板重新加载，覆盖手填默认值、保留变量映射。

## 已确认设计决策

- 告警中心持有并下发完整参数列表，不依赖作业入口补缺 key 的默认值。原因：当前告警调用的执行入口不会补。
- 「自动执行」挂在规则上，与启停分离。停用规则则自动、手动都不可用。
- 「执行时可改」不对变量传递生效：告警字段始终按绑定取值，弹框不能改。
- 弹框只展示允许改的手填项，其余静默按规则带上。
- 加密/脱敏默认值不回写进规则，该项为空。
- 打开编辑只做结构对齐（增补、删除、同名保留）；只有用户点重新加载才用手填最新默认值覆盖已有常量。

## 明确后置

- 作业平台缺 key 补默认值。
- 规则内存加密手填值。
- 目标主机与脚本参数同一套手动/变量表。
- Playbook / ITSM / Webhook。
- 审批、维护窗口、批量多告警手动执行。

无。

## 已替代决策

- 「参数只能绑告警字段」：2026-09-20 改为每项可选手动填写或变量传递。
- 「命中即自动执行、不可关掉」：2026-09-20 改为规则级开关，默认开。
- 「靠作业接口不传值来用模板默认值」：2026-09-20 否决；告警中心回写并显式下发。
