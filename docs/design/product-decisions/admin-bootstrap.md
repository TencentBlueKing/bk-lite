# 管理员引导产品决策记忆

- 最近更新：2026-08-21
- 当前规格：`specs/capabilities/legacy-ard-modules-infra-deployment.md`

## 产品定位

BK-Lite 默认安装优先保证零配置完成初始化并可立即登录，同时允许有安全要求的部署显式注入受管管理员凭据。

## 已确认范围

- 全新安装在未配置管理员凭据时创建默认域管理员 `admin`，初始密码为 `password`。
- `BK_INIT_ADMIN_PASSWORD` 与 `BK_INIT_ADMIN_PASSWORD_FILE` 继续作为显式覆盖方式。
- 已存在任意域同名 `admin` 时保持既有 no-op 语义，不因重复启动覆盖密码。
- 既有默认域管理员密码迁移继续要求显式受管凭据和 `BK_INIT_ADMIN_PASSWORD_MIGRATE_EXISTING=true`。

## 已确认设计决策

- 缺少管理员 Secret 不阻断 Server 启动，回退默认密码 `password`。原因是产品确认安装便利性优先，并接受固定初始管理员密码可能被安全扫描识别及在首次改密前可被使用的风险。
- 回退只改变鲜装缺省凭据分支，不撤销 Secret 文件读取边界、存量用户保护、事务、并发幂等和显式迁移保护。
- 使用默认凭据时输出不含密码值的告警，配置样例和部署规格明确首次登录后应修改密码。
- 本决策是对全局“最低安全边界不能后置”原则的显式产品例外；后续安全扫描命中应关联本决策做定点风险接受，不得全局关闭硬编码凭据规则。

## 明确后置

- 安装器自动生成并受控交付随机初始密码。
- 服务端强制首次改密及临时会话权限收敛。

无。
