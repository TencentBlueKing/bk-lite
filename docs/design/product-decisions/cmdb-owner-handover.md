# 负责人交接产品决策记忆

- 最近更新：2026-11-17
- 当前规格：`specs/changes/cmdb-owner-handover/spec.md`

## 产品定位

人员离职或调岗时，把 CMDB 资产上的用户类型负责人批量交给另一名用户。这是管理菜单中的一次可预览、可部分成功、可按交接场景追溯的操作。

## 已确认范围

- 先单选一个用户字段，再选定原负责人、新负责人和含该字段的模型，预览后执行。
- 一次只移交所选字段中仍包含原负责人的值。同一模型上的其他用户字段不动。
- 同一字段中的其他共有人保留。
- 部分失败不回滚已成功实例，并给出失败清单。
- 操作日志按「负责人交接」场景查询。执行按批写图，变更记录也按批创建。

## 已确认设计决策

- 不新增负责人字段，沿用 `attr_type=user` 的现有属性。结论来自需求「与现有负责人属性对齐」和用户对字段范围的确认。
- 字符串类型的负责人不适用，不猜测用户身份。
- 不改组织、关系和其他属性，因此数据权限不随负责人转移。列表和详情显示新负责人，是因为用户字段及其展示值被更新。
- 原负责人允许已离职或已禁用；新负责人必须未禁用且不是离职。
- 执行范围受当前团队约束，超管也不跨出当前团队。

## 明确后置

- 一次勾选多个用户字段。
- 跨组织一次交完全部资产。
- 交接摘要同步到平台操作日志。
- 禁用账号、告警分派、值班和外部系统销户。

## 仍待确认

无。
