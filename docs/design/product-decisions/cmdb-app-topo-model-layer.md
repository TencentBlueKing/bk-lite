# CMDB 应用拓扑模型层级产品决策记忆

- 最近更新：2026-08-28
- 当前规格：`specs/changes/cmdb-app-topo-model-layer/spec.md`

## 产品定位

应用拓扑的展示带由模型上的视图属性决定，不把层级做成模型分类之外的第二套全局身份，也不改成按层取数。

## 已确认范围

- 模型管理新增「应用拓扑层级」单选：系统层、服务层、主机层、应用服务层、基础设施层、不分类。
- 内置模型按模型身份初始化；新建模型默认不分类。
- `model_config.xlsx` 的 models 表导入导出该字段。
- 拓扑按关联跳数展开，层级只决定落带；不分类节点不进入五条展示带。

## 已确认设计决策

- 字段是应用拓扑专用，不复用模型分类，也不给 K8S/网络拓扑用。
- 系统层给应用系统模型；当前图中心节点仍固定在系统带。
- 主机层含 `host` 以及所有虚拟机/云主机；应用服务层含全部中间件与数据库；基础设施层含物理设备、网络设备和机房机柜。
- 官方初始化默认只补空值；一次性对齐当前种子分层用 `model_init --sync-app-topo-layer`。用户 Excel 导入在写了显式值时更新已有模型。
- 缺字段时拓扑回落内置默认映射。
- 有编辑权限时可改内置模型，但只允许改应用拓扑层级；名称、图标、组织、模型 ID 仍只读。

## 明确后置

- 按层加载、按层过滤。
- 自定义层名/层数。
- 资源清单分组改用该字段。

## 仍待确认

无。
