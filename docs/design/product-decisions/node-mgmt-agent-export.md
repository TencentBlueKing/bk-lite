# 节点管理 Agent 清单导出产品决策记忆

- 最近更新：2026-09-28
- 当前规格：`specs/changes/node-mgmt-agent-export/spec.md`

## 产品定位

节点清单在筛选和跨页勾选之后，要把圈出的集合带出产品做对账和报备。这是现有纳管闭环的导出补强，不是导入导出中心。

## 已确认范围

- 工具栏同步导出 Excel。
- 导出下拉显式选择：已选择 / 当前页 / 全部。
- 已选择：跨页勾选全集，忽略组合筛选；没有勾选时禁用。
- 当前页：本页表格节点，忽略组合筛选和是否另有勾选。
- 全部：当前云区域下的筛选结果（含仅未归属），即使有勾选也不改成已选集合。
- 固定列，一行一台；托管组件写在同一格。
- 能看列表就能导出。

## 已确认设计决策

- 范围必须显式选择，对齐 CMDB 资产列表导出下拉。原因：隐式「有勾选就导勾选」会让人搞不清带走的是哪一批。
- 「全部」仍受当前筛选约束，不是忽略筛选的整库。原因：与 CMDB「全部」一致，导出的是当前圈出的清单。
- 「当前页」为空不得改走「全部」。原因：空页应失败，不能把整份筛选结果当成本页。
- 列固定对齐列表可见信息，不跟表格显隐、不提供字段选择器。原因：带走的是完整清单，不依赖当时藏了哪些列。
- 一行一台，组件状态拼在一格。原因：导出对象是 Agent 清单，不是组件明细。
- 同步下载，上限 5000，超限失败不截断。原因：节点量远小于 CMDB 实例导出，不引入异步任务。
- 空结果不给只有表头的文件。原因：空表会被当成导出成功。
- 无权或已删的已选 ID 丢弃，剩余继续导出。原因：少几台已失效对象不应阻断整单。
- 状态口径复用列表加工结果。原因：文件必须和页面 Sidecar / 托管组件列对得上。

## 明确后置

- 导入。
- 异步导出任务与导出记录。
- 字段选择器。
- 按组件拆行或第二张明细表。
- 一键全选当前筛选结果。
- 导出节点内部 ID。
