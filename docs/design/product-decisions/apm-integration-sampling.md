# APM 接入采样产品决策记忆

- 最近更新：2026-09-04
- 当前规格：`specs/capabilities/apm-product.md`

## 产品定位

采样率是接入安装脚本的生成参数，不是平台正在执行的采集策略。

## 已确认范围

- 接入页可选择本次脚本的采样率；选项为 100 / 50 / 20 / 10 / 5 / 1，文案只写百分比。
- 低于 100% 时，脚本写入 `OTEL_TRACES_SAMPLER=parentbased_traceidratio` 与对应比例。
- 配置即时生成、只供复制，不持久化，也不巡检已运行应用。

## 已确认设计决策

- 采用方案「接入脚本可选项」：用户改接入页只影响下一次复制的安装命令。
- 接入页只提供常用档，不额外用提示条，选项文案不写「默认」。

## 明确后置

- 应用/服务上的持久采样策略，以及改页面即改线上采集。
- 自适应采样、按服务不同比例、Collector 尾采样、采样前 Span Metrics、探针远程热更新。
