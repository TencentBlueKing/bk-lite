# CMDB 机房机柜布局产品决策记忆

- 最近更新：2026-08-14
- 当前规格：`specs/changes/cmdb-rack-room-layout-editing/spec.md`

## 产品定位

机房俯视图与机柜正视图是同一套 CMDB 台账的布局入口：有权限时可在图上放置或移出，不另存图纸，也不在布局里删除实例。

## 已确认范围

- 点空格/空 U：新建（复用资产新建表）或选择已有，系统写位置并建关联。
- 已在其它机房/机柜的对象在选择列表中灰色展示，点击新开详情，由用户自行解关联。
- 已占用对象经现有抽屉「移出布局」：只拆关联、清位置。

## 已确认设计决策

- 位置字段：机柜只写 `location`（画布行列由该字段解析）；设备 `rack_u_start`。移出保留设备 `u_size`。
- 机柜内设备抽屉只读展示 CMDB 属性，不允许在抽屉里编辑。
- 关联：机房→机柜为 `run`，机柜→设备为 `contains`。
- 设备模型仅限 `switch` / `router` / `firewall` / `loadbalance` / `physcial_server`。
- 点起始 U，高度在表单填；超出或重叠则拒绝。
- 空机房也画默认 12×6 网格；网格随已放置范围增大。不加行加列。
- 权限对齐资产列表：新建要新增；选已有与移出要编辑 + 该实例 Operate。后端同样拒绝越权。
- 专用布局变更接口一次完成校验与写入，避免前端拼多个通用接口。

## 明确后置

- 拖拽改位、同机房挪格、加行加列。
- 布局内删除实例。
- `host` 等无 U 字段模型上架。
- 3D 机房大屏对等编辑。
- 独立「布局编辑」权限点。
