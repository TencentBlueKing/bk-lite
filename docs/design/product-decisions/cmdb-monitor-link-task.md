# CMDB ↔ 监控同步任务产品决策记忆

- 最近更新：2026-10-19
- 当前规格：`specs/changes/cmdb-monitor-link-task/spec.md`

## 产品定位

跨模块对账用「任务」承接，而不是一次点按钮就结束。先关联身份，缺对象再进人补齐的接入或台账写入。凭据留在各自域。

## 已确认范围

- 本期只做 **CMDB → 监控** 单向任务。
- 任务第一段：无凭据自动关联，不开采集、不暗建。
- 任务第二段：监控没有的对象按插件分组，生成接入草稿，跳转监控接入页预填身份，人补凭据后提交。
- 监控 → CMDB 逻辑对称，实现后置：先关联，再确认要不要同步台账数据（新建 CI 或覆盖不一致字段）。

## 已确认设计决策

- 扫描不再是双向推送的必经之路；扫描仍可一次做完发现+关联+带凭据接入。
- CMDB 不发明监控采集配置。
- 异构模型必须拆组成不同接入草稿。
- 冲突不自动合并，用手绑。
- K8s / 云 / vCenter 子对象不进本任务。
- 同步任务的页面和编排独立成胶水模块，不属于 CMDB / 监控核心。
- 识别不到对端模块许可时入口不出现；胶水模块始终装入。
- 任务记录延时回收，避免堆积；回收不拆已建立的身份关联。

## 已确认实现决议

- 胶水模块名 `module_link`：后端 `apps.module_link`，前端 `/module-link/...`，不进顶栏、不单独售卖。
- 胶水模块始终装入；前端用已授权应用列表 fail-closed（加载中 / 空列表 / 无 CMDB 或监控许可都不显示按钮）。
- 接入草稿单组上限 = 任务内该对象 `not_found` 行（≤100），本期不分页。
- 「同步数据 / 保持 CMDB」只属于反向，本期不出现。
- 跳转只带 `cmdb_draft` + 对象名；插件数字 ID 由监控页解析。
- 列表入口跳独立任务页；CMDB 只留薄入口和详情手绑。
- 回收：创建起 7 天，每日 Beat 删任务/草稿/行；不改 CI 与监控实例上的关联 ID。
- 「去配置」先选该对象下的接入模板（内置或 DIY），再进预填页；复用监控接入列表，不猜默认插件。
- 无内置映射的自定义模型：任务里指定监控对象后再出草稿；映射记在胶水模块。K8s/云/vCenter 仍跳过。

## 已替代决策

- 无。列表无凭据同步仍作为任务第一段，不退役手绑。

## 决策来源

- 2026-10-19 对话：单向任务、预填跳转接入、反向先关联再确认是否同步数据。
- 2026-10-19 对话：任务独立于 CMDB/监控核心；对端未装或无许可则隐藏入口；任务延时回收。
- 2026-10-19 对话：接入前先选模板；无全量对象映射时自定义模型手指定对象，不改内置常量。
