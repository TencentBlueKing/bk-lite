# CMDB ↔ 监控同步任务产品决策记忆

- 最近更新：2026-10-20
- 正向规格：`specs/changes/cmdb-monitor-link-task/spec.md`（implemented）
- 反向规格：`specs/changes/monitor-cmdb-link-task/spec.md`（implemented）

## 产品定位

跨模块对账用「任务」承接，而不是一次点按钮就结束。先关联身份，缺对象再等人补齐：正向补监控接入，反向确认新建 CI。凭据留在各自域。

## 已确认范围

- 正向 **CMDB → 监控** 已交付：无凭据自动关联，对不上的生成接入草稿。
- 反向第一期 **监控 → CMDB**：先只写关联指针；CMDB 没有的经确认后按监控名称 / IP / 组织 / 云区域新建 CI。已关联进桶，不覆盖台账字段。实例未填云区域时用监控节点或默认云区域 `default`（id=1），host 必带 cloud。
- 字段覆盖白名单（名称 / IP / 组织 / 云区域等）与交互稿「同步数据」屏仍后置。

## 已确认设计决策

- 扫描不再是双向推送的必经之路；扫描仍可一次做完发现+关联+带凭据接入。
- CMDB 不发明监控采集配置；监控凭据不写入 CMDB。
- 异构模型必须拆组成不同接入草稿。
- 冲突不自动合并，用手绑。
- K8s / 云 / vCenter 子对象不进本任务。
- 同步任务的页面和编排独立成胶水模块，不属于 CMDB / 监控核心。
- 识别不到对端模块许可时入口不出现；胶水模块始终装入。
- 任务记录延时回收，避免堆积；回收不拆已建立的身份关联。
- 反向第一期倒内置 `CMDB_MODEL_TO_MONITOR_OBJECT`，未知对象不默认 host；无映射对象不显示入口。
- 反向禁止列表直调会 upsert 的 `push_to_cmdb`；主机创建钩子保持 best-effort，不替代任务。

## 明确后置

- 用监控覆盖已有 CI 字段（「同步数据 / 保持 CMDB」）。
- 未关联跨任务收件箱。
- 反向为无映射对象手指定 CMDB 模型。

## 已确认实现决议

- 胶水模块名 `module_link`：后端 `apps.module_link`，前端 `/module-link/...`，不进顶栏、不单独售卖。
- 胶水模块始终装入；前端用已授权应用列表 fail-closed（加载中 / 空列表 / 无 CMDB 或监控许可都不显示按钮）。
- 接入草稿单组上限 = 任务内该对象 `not_found` 行（≤100），本期不分页。反向勾选同样 ≤100。
- 跳转只带 `cmdb_draft` + 对象名；插件数字 ID 由监控页解析。
- 列表入口跳独立任务页；CMDB / 监控只留薄入口和详情手绑。
- 回收：创建起 7 天，每日 Beat 删任务/草稿/行；不改 CI 与监控实例上的关联 ID。
- 「去配置」先选该对象下的接入模板（内置或 DIY），再进预填页；复用监控接入列表，不猜默认插件。
- 正向无内置映射的自定义模型：任务里指定监控对象后再出草稿；映射记在胶水模块。K8s/云/vCenter 仍跳过。
- 反向任务与正向分表，不复用 `waiting_access`。确认新建叠加 CMDB `asset_info-Edit`。

## 已替代决策

- 「监控 → CMDB 整段后置」已替代为：第一期（关联 + 确认新建）进入 `monitor-cmdb-link-task`；字段覆盖仍后置。
- 无。列表无凭据同步仍作为任务第一段，不退役手绑。

## 决策来源

- 2026-10-19 对话：单向任务、预填跳转接入、反向先关联再确认是否同步数据。
- 2026-10-19 对话：任务独立于 CMDB/监控核心；对端未装或无许可则隐藏入口；任务延时回收。
- 2026-10-19 对话：接入前先选模板；无全量对象映射时自定义模型手指定对象，不改内置常量。
- 2026-10-20 对话：反向第一期做关联 + 确认新建；已关联不覆盖字段；倒内置映射、禁止默认 host；不把 `push_to_cmdb` 接到列表。
