# APM 服务详情错误 Tab 产品决策记忆

- 最近更新：2026-09-02
- 当前规格：`specs/capabilities/apm-function-list.md`

## 产品定位

服务详情错误 Tab 解释当前窗错误率由哪些失败类型构成。它不是失败事件流水，也不是调用链红条的计数。

## 已确认范围

- 错误率仍是该服务、环境、时间窗内入口 Span（SERVER / CONSUMER）的 OTel ERROR 比例。
- 错误 Tab 与错误率同源：只取入口 ERROR Span，聚成 Top Issue。
- 调用链 Tab 保持近窗混合样本，不与错误率对账。
- 探索「错误分析」仍是全量 Error Span，不收成入口口径。

## 已确认设计决策

- Tab 只写「错误」，不用 Issue 种类冒充错误条数。
- 列表顶部用与错误率同一条 RED 聚合的请求次数 / 失败次数 / 错误率对账。
- 卡片次数标明「失败样本构成」，不装成全窗出现次数。
- 服务详情不按 Span 翻页；更早样本走「在错误分析中打开」。
- `get_trace` 失败的未归因兜底并入同服务最大的已归因 Issue，避免同一种失败拆成两张卡。

## 明确后置

- Issue 持久化与全窗精确出现次数。
- Issue 生命周期、认领、激增 / 回归标记。
