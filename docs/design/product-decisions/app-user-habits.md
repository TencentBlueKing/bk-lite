# 应用用户习惯产品决策记忆

- 最近更新：2026-08-17
- 当前规格：`specs/changes/app-user-habits/spec.md`

## 产品定位

用户习惯是各应用工作台的个人状态（收起、列、侧栏），跟账号走，不是命名查询，也不是语言/时区。

## 已确认范围

- 每个应用一张同构用户习惯表，不建平台总表。
- 监控不复用 `MonitorViewColumnPreference` 的列语义；迁入新表后删除旧表。
- 列配置旧 HTTP 门面保留，存储改为习惯表。
- 第一波：监控 + 日志建表、列习惯迁移、告警分布图收起落库。

## 已确认设计决策

- 存储为 `user + habit_key + JSON habit_value`。
- 不复用 CMDB `UserPersonalConfig`。
- 语言/时区仍走账号偏好，不进习惯表。
- 日志 `SearchCondition` 仍是命名查询，不是习惯表。

## 明确后置

- 侧栏宽/收起、日志搜索展示字段、统一告警页图表开关。
- 告警、作业等应用按同一抽象补自己的表。
- CMDB 保留现表，仅视为已有等价物。

## 仍待确认

无

## 已替代决策

- 2026-08-17：告警分布图收起不再以 localStorage 为账号习惯真相源。

## 决策来源

- 告警页收起要保留用户习惯，且必须落库。
- 监控已有列表列习惯表，但不能承载无监控对象的 UI 状态。
