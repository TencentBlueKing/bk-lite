# CMDB 场景视图产品决策记忆

- 最近更新：2026-08-27
- 当前规格：`specs/changes/cmdb-scene-view/spec.md`

## 产品定位

场景视图是可保存、可分享的跨模型活查询，用来回答「某一类场景下有哪些资产」，而不是再做一个分析看板。标签是默认条件，模型范围是边界。

## 已确认范围

- 创建顺序：先选模型范围，再选标签。
- 标签集合一个 AND/OR 开关，默认 AND；无括号分组。
- 活查询，打开再算；0 条就是没搜到，不解释原因；0 条模型不分表。
- 分析：匹配总数 + 按模型数量。
- 列表：按模型分表，列复用该模型资产列表展示列；只读；点进现有详情。
- 导出：一个 Excel，有命中的模型各一 Sheet。
- 入口：同一导航列表；我的 / 组织 / 全局只是分组标题；空组不出现。
- 可见范围：个人（能看资产即可建）+ 组织只读分享（单独权限）+ 全局（管理员建，全员能看见定义，不自动置顶）。

## 已确认设计决策

- 分享的是查询定义，结果按打开者实例权限过滤。
- 组织/全局只读，非创建者只能另存为个人场景。
- 第一版条件只有模型范围和标签，不加组织/负责人/状态。
- 不复用单模型已保存筛选和个人 user_configs 来存场景。
- 挂在 CMDB「视图」下，与资产总览、专题视图并列；不占一级新导航。

## 明确后置
