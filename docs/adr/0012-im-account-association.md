# ADR 0012：IM 身份对应独立成账号关联

Status: accepted

平台用户和外部 IM 身份的对应原来写在每条 IM 通知渠道上。通知、群聊小助手、智能机器人和事故建群都要使用这份对应。继续挂在渠道上，会让每条渠道各存一套匹配字段和同步结果，群助手和机器人又不是通知渠道。因此对应关系独立成账号关联：一个集成实例可以有多条，消费方选择其中一条。渠道不再保存匹配字段、定时和同步动作。

曾考虑让其他消费方指向某一条通知渠道来复用它的映射。这条路要求先有通知渠道，也无法在同一个实例上同时保留不同的匹配方式，所以没有采用。

当前规则见 `specs/capabilities/im-account-association.md`。拆分迁移的逆向执行不把字段合并回渠道。功能已经使用后，回退以迁移前的数据库备份为准，后续修正向前新增迁移。
