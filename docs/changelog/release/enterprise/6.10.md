# 6.10 版本日志
版本发布时间：2026年7月

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| 作业管理 | 作业执行过程中，作业详情页支持流式展示执行进度与结果 |
| CMDB | 新增网络设备配置采集能力，支持统一采集与管理网络配置 |
| CMDB | 新增应用拓扑视图，帮助快速了解应用关系与依赖结构 |
| 监控中心 | 新增 TCP 拨测能力，支持对端口连通性与服务可用性进行探测 |
| 监控中心 | 监控列表支持自定义展示字段，满足不同场景下的查看需求 |
| 监控中心 | 监控接入流程支持连通性测试，提前发现网络、端口或认证配置问题 |
| 运营分析 | 数据源类型进一步拓展，支持 MySQL、PostgreSQL、REST API、Excel |
| OpsPilot | 工作台支持对接企业微信机器人，便于将智能能力接入企业协作场景 |
| 系统管理 | 用户同步新增支持接入 AD / 飞书 |
| 系统管理 | 登录认证新增支持 AD / 飞书 / 微信 |
| CMDB | 新增 K8S 专属视图，提升容器资源管理与查看体验 |
| 监控中心 | 告警策略支持多指标计算，满足复杂监控场景下的告警判断需求 |
| 运营分析 | 新增 3D 机房机柜视图，直观展示机房资源布局与设备状态 |
| 监控中心 | 新增监控对象接入指南，帮助用户快速完成监控配置 |
| OpsPilot | NATS 触发节点新增「作为 Web 对话」模式 |
| OpsPilot | Workflow 测试运行支持手动停止 |
| 系统管理 | 用户同步支持配置新用户密码规则 |
| 监控中心 | 主机磁盘监控支持按文件系统类型过滤 |
| 运营分析 | 数据源参数新增「日期范围」类型，完善统一筛选与画布参数绑定能力 |
| 运营分析 | 单值组件周期对比支持日期范围，并可展示具体增减值 |
| 运营分析 | 新增多值指标组件，支持集中展示同一数据源返回的多项指标 |
| 节点管理 | 支持非 root 用户通过 sudo 执行控制器安装命令，提升部署灵活性 |
| 节点管理 | 安装控制器时新增节点与 Server 时间一致性校验，提升部署可靠性 |
| 系统管理 | 支持跨窗口无刷新恢复登录态 |
| 监控中心 | 网站拨测新增高级配置能力，支持请求内容、认证凭据及响应校验 |
| 监控中心 | 支持配置自动发现资产清理策略，提升资产生命周期管理能力 |
| 监控中心 | 监控列表支持自定义展示字段与排序，满足个性化查看需求 |
| 监控中心 | 支持查看内置指标配置，提升监控配置透明度 |
| 告警中心 | 告警分派支持按组织选择通知范围，提升告警触达精准度 |
| 运营分析 | 支持画布分享，便于分析结果协作与复用 |
| 补丁管理 | 补丁管理正式上线，支持补丁合规检查与自动化安装，实现补丁全生命周期治理 |
