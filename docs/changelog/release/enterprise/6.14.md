# 6.14 版本日志
版本发布时间：2026年11月

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| CMDB | 腾讯云采集新增 TKE 集群与节点、VPN 和 NAT 网关资产，并支持同步云标签 |
| CMDB | 内置模型及模型分组支持修改名称、图标和所属组织，便于适配实际资产管理习惯 |
| 监控中心 | 新增 PostgreSQL 专业仪表盘，支持查看数据库健康状态、Top SQL、等待事件及主从复制情况 |
| APM | 新增 Ruby、C++、Erlang、Swift 离线 Trace 探针，支持在平台下载并获取接入配置 |
| APM | 新增 PHP、Windows .NET 和指定 Go 进程的 Trace 探针，扩展应用链路接入范围 |
| 告警中心 | 通知模板支持引用事件样本和日志检索链接，收到告警后可更快查看问题上下文 |
| 运营分析 | 新增多画布轮播，支持将多个仪表盘、架构图等视图加入轮播列表并全屏播放 |
| 运营分析 | 筛选项支持级联：上游条件变化时，下游候选项随之更新 |
| 作业管理 | Ansible 作业支持不同操作系统混合主机执行 |
| 编排中心 | 新增「文件分发」节点，可在流程中调用作业平台分发文件 |
| OpsPilot | 新增作业管理工具，智能体可执行脚本、分发当前会话暂存文件，并提供作业记录入口 |
| OpsPilot | 对话输入区支持查看已暂存文件 |

### 功能优化

| 模块 | 功能优化 |
| --- | --- |
| 节点管理 | 删除或卸载节点时保留采集配置，节点重新接入后可继续使用 |
| CMDB | 资产导出保留跨页选择，采集操作日志补充任务及变更来源 |
| 监控中心 | PostgreSQL 监控补充复制延迟与复制槽积压指标，辅助排查同步异常 |
| 监控中心 | Riverbed SteelHead 监控补充连接、优化服务和对端信息 |
| 运营分析 | 仪表盘补充主机与进程健康状态、CPU IO Wait 等数据 |
| 作业管理 | 优化 Windows PowerShell 作业输出，减少中文实时日志乱码 |
| 编排中心 | 加固流程执行与终止处理，减少重复提交作业和终止后继续执行的风险 |
