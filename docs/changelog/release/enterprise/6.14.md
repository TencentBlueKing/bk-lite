# 6.14 版本日志
版本发布时间：2026年11月

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| 系统管理 | 新增腾讯云、阿里云短信和语音通知渠道，支持使用已审核的云厂商模板发送 |
| 系统管理 | 新增模块管理员和模块审计员，可按应用授予管理或只读审计权限 |
| 系统管理 | 新增「超级审计员」角色，可只读查看全部组织和应用数据 |
| CMDB | 新增火山引擎配置采集，覆盖云服务器、公网 IP、负载均衡、MySQL、PostgreSQL 和对象存储 |
| CMDB | 采集任务支持连通性测试，可提前检查网络和凭据是否可用 |
| CMDB | 采集任务支持暂停和恢复，暂停期间保留任务配置和已入库资产 |
| CMDB | 支持按指定用户字段批量交接资产负责人 |
| CMDB | 资产列表支持按关联实例快捷筛选，无需打开高级筛选 |
| CMDB | 云资源配置采集支持同步云资源的标签 |
| CMDB | 腾讯云采集新增 TKE 集群与节点、VPN 和 NAT 网关资产，并支持同步云标签 |
| CMDB | 内置模型及模型分组支持修改名称、图标和所属组织，便于适配实际资产管理习惯 |
| 监控中心 | 新增 RocketMQ 监控，支持查看 Broker 读写速率和采集状态等指标 |
| 监控中心 | 新增 SQL Server 专业仪表盘，集中查看实例健康、缓冲与内存、I/O 与存储及等待情况 |
| 监控中心 | 策略组支持增减策略模板，并可查看各监控实例当前生效的模板 |
| 监控中心 | Nginx 监控补充请求、连接累计值及采集状态，并支持按需开启 VTS 指标采集 |
| 监控中心 | F5 BIG-IP 监控新增故障切换角色与配置同步状态，支持对同步失败、对端失联等情况告警 |
| 监控中心 | 新增 PostgreSQL 专业仪表盘，支持查看数据库健康状态、Top SQL、等待事件及主从复制情况 |
| 日志中心 | 新增「来源设备」页面，自动发现发送 Syslog 的设备，可查看最近上报时间和活跃状态，点击设备直达日志检索 |
| 日志中心 | 日志提取器新增 Grok 模式，支持搜索内置模式并用历史日志预览提取结果 |
| RUM | 会话列表支持按终端用户 ID 筛选，可从会话时间线跳转到关联的 APM 调用链，串联前端体验和后端排查 |
| RUM | 应用接入支持配置会话采样率 |
| 运营分析 | 柱状图支持堆叠，折线图和柱状图支持添加参考线，大屏列表支持自动滚动 |
| 运营分析 | 排行、饼图和柱状图支持对查询结果排序并限制展示条数，方便搭建 Top N 视图 |
| 运营分析 | 新增内置「监控概况」大屏，集中查看监控覆盖、未恢复告警情况 |
| 运营分析 | 新增内置「网络设备汇总」大屏，集中查看网络设备运行情况 |
| 运营分析 | 大屏支持将查询结果的指定列保存为变量，供组件参数引用 |
| 运营分析 | 大屏新增限时投屏链接，可供电视等设备展示，并支持设置有效期、停用或重新生成链接 |
| 运营分析 | 新增 CMDB、监控、告警通用查询数据源，可按条件筛选并配置图表 |
| 运营分析 | 新增多画布轮播，支持将多个仪表盘、架构图等视图加入轮播列表并全屏播放 |
| 运营分析 | 筛选项支持级联：上游条件变化时，下游候选项随之更新 |
| 作业管理 | 作业目标、脚本和 Ansible Playbook 支持批量调整所属组织，并在提交前预览变更 |
| 作业管理 | 目标管理支持引用系统管理-凭据管理中的主机凭据 |
| 作业管理 | Ansible 作业支持不同操作系统混合主机执行 |
| 编排中心 | 企业微信群机器人支持直接发送文件 |
| 编排中心 | 定时流程支持绑定执行账号和组织，启动前校验执行权限，执行记录展示实际运行组织 |
| 编排中心 | 新增「文件分发」节点，可在流程中调用作业平台分发文件 |
| OpsPilot | 智能体支持导出并导入当前组织，方便复用提示词、工具和技能包配置 |
| OpsPilot | 支持对回答评分并填写反馈，可按时间、渠道或指定会话生成并导出历史分析报告 |
| OpsPilot | 支持智能体无人值守运行 |
| OpsPilot | 新增作业管理工具，智能体可执行脚本、分发当前会话暂存文件，并提供作业记录入口 |
| OpsPilot | 对话输入区支持查看已暂存文件 |
| 告警中心 | 事故影响拓扑支持展开关联资产，并查看相关应用和应用系统的当前告警 |
| 告警中心 | 告警丰富支持补充所属应用、应用系统及负责人信息，便于识别业务归属和通知责任人 |
| 告警中心 | 通知模板支持引用事件样本和日志检索链接，收到告警后可更快查看问题上下文 |
| APM | 新增 Ruby、C++、Erlang、Swift 离线 Trace 探针，支持在平台下载并获取接入配置 |
| APM | 新增 PHP、Windows .NET 和指定 Go 进程的 Trace 探针，扩展应用链路接入范围 |
