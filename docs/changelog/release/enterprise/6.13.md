# 6.13 版本日志
版本发布时间：2026年10月

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| 运营分析 | AI 仪表盘搭建：支持对话式数据源检索与图表生成 |
| 运营分析 | 新增内置应用拓扑大屏 |
| 监控中心 | 新增二十余款厂商设备接入：Calix、Ubiquiti、Cisco、Huawei、Aruba 等 |
| APM | 服务详情能按方法查看对外 HTTP 调用和数据库查询 |
| 作业平台 | 新增 Windows / Linux 主机健康巡检，「表单 → 作业 → 报告 → 通知」一条线打通 |
| 作业平台 | 脚本模板参数支持枚举类型，提示中的链接可点击 |
| 告警中心 | 通知模板按告警级别自动着色 |
| 告警中心 | 推送告警附带对象字段与 IP 摘要 |
| 告警中心 | 告警详情可一键跳转到告警来源 |
| 节点管理 | 节点安装进度支持手动刷新 |
| OpsPilot | 新增智能体文档生成能力，支持 Excel、Word、Markdown、PDF 等多种格式 |
| OpsPilot | 支持在对话中上传附件，结合附件内容进行 AI 分析 |
| OpsPilot | 支持批量删除知识库资料，提升资料管理效率 |
| 系统管理 | 新增 ITSM 用户目录与组织目录 OpenAPI 接口 |
| 系统管理 | 许可管理新增超额限制与许可提醒 |
| 运营分析 | 仪表盘、报表、拓扑及大屏组件支持导出 CSV 数据 |

### 功能优化

| 模块 | 功能优化 |
| --- | --- |
| 运营分析 | 3D 机房完善机房统计信息 |
| 运营分析 | 大屏搭建能力增强：支持尺寸、背景图、文字颜色配置及撤销/恢复 |
| 监控中心 | 事件入口改为「告警 / 策略组 / 单策略 / 策略模板」四级，整组策略可一键生效或停用 |
| 作业平台 | 编排中心：终止流程自动取消关联作业，敏感信息管控更严 |
| 告警中心 | 用资产负责人替换上报责任人并优先通知 |
| OpsPilot | 优化智能体交互机制，用户长时间未响应时，任务不再自动中断 |
