# 6.13 版本日志

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| CMDB | 新增采集数据调和，多个任务采集同一资产时，可按字段配置来源优先级，保留人工修改 |

| 监控中心 | 策略组规则支持独立编辑指标、告警条件与无数据配置 |
