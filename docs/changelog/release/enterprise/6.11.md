# 6.11 版本日志
版本发布时间：2026年8月

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| 系统管理 | 安全策略支持 OTP 白名单 |
| 系统管理 | 用户管理支持OTP解绑 |
| 系统管理 | AD 用户同步支持配置多个拉取 DN |
| 节点管理 | Windows 远程安装/卸载支持 WinRM HTTPS/HTTP协议 |
| CMDB | 新增标签视图，支持按属性筛选并记住筛选条件 |
| CMDB | 物理服务器采集支持网卡入库，网络拓扑可关联交换机与服务器网卡 |
| CMDB | 机柜视图支持多选对比 |
| 监控中心 | 新增 vLLM、SGLang、llama-server 的 LLM 监控能力及其专业仪表盘 |
| 监控中心 | 新增 Active Directory、Microsoft Exchange 监控能力及其专业仪表盘 |
| 监控中心 | 新增 NetFlow/sFlow 专业流量分析仪表盘，支持会话表、Top 会话与 Top 协议分析 |
| 监控中心 | 监控接入页面支持自动创建监控策略 |
| APM | 服务接入：支持 Java、Python、Node.js、Go，按语言提供接入指引 |
| APM | 服务概览：从应用/服务视角查看健康状况以及可用性、时延 SLO 是否达标 |
| APM | 服务拓扑：展示服务间调用依赖，未接入的 Redis、PostgreSQL 等下游服务也可识别 |
| APM | 调用链分析：按时间、服务检索 Trace，详情支持瀑布图、火焰图与跨度列表 |
| APM | 错误分析：按异常类型聚合错误，定位失败请求更直接 |
| APM | 性能告警：按错误率、时延、吞吐配置告警策略，及时发现服务问题 |
| 日志中心 | Syslog、SNMP Trap 支持按采集类型配置字段提取器 |
| 运营分析 | 大屏新增 Application3D 应用立体场景组件 |
| 运营分析 | 画布支持个人草稿 |
| OpsPilot | AI助手支持读取当前页面上下文（目前仅开放监控仪表盘页面内容） |
| 系统管理 | 系统管理支持本地批量添加用户，批量初始化账号更高效 |
| 节点管理 | 支持批量修改节点组织，节点归属调整更方便 |
| CMDB | 新增扫描，支持多凭据多IP段批量扫描（暂时只支持网络设备SNMP和主机SSH） |
| CMDB | 扫描发现支持生成采集任务并推送到监控中心，资产发现到监控接入链路更顺 |
| CMDB | CMDB 与监控联动增强，支持同步监控成功后回写 monitor_id |
| 监控中心 | 告警策略选资产支持展示列变量与 resource_ip，策略配置时资产识别更直观 |
| 日志中心 | K8s 日志接入支持配置 Namespace / Pod 采集范围，采集边界更可控 |
| 日志中心 | 告警策略查询支持字段联想，日志告警条件配置更顺手 |
| 运营分析 | 报表画布支持报表类型 |
| 运营分析 | 画布全局筛选条件支持组件自定义 |
| 补丁管理 | 基线合规详情支持多选与批量导出，可按主机或补丁视角导出评估明细 |
| OpsPilot | 智能体支持多渠道独立发布，包括发布到平台供用户使用 |
| OpsPilot | 技能包支持执行期环境变量参数配置 |
| 节点管理 | 支持Windows节点远程安装（要求Windows Server 2016、PowerShell 5.1 及以上） |
| 节点管理 | 节点创建支持按需推送到 CMDB 与监控中心，帮助统一主机身份与观测对象 |
| 节点管理 | 节点删除/卸载时支持同步处理关联对象，减少残留资产和无效监控实例 |
| CMDB | 专题视图支持实例选择、最近访问与独立记忆，常用拓扑和资源视图访问更便捷 |
| 监控中心 | 新增多类专业监控仪表盘，覆盖 Docker、Etcd、HAProxy、InfluxDB、MinIO、Oracle 等对象 |
| 监控中心 | 支持 MinIO 多版本指标监控，完善对象存储场景观测能力 |
| 监控中心 | 支持所有对象创建自定义 SNMP 模板，网络与设备类监控扩展更灵活 |
| 运营分析 | 新增「连接库」能力，支持 MySQL、PostgreSQL、REST 连接复用，减少重复配置凭据 |
| 运营分析 | REST / Excel 数据源支持可选 Python 转换，便于将原始数据加工成组件可用结构 |
| 运营分析 | 新增卡片列表、雷达图、事件时间线、关系拓扑等组件，丰富看板与大屏表达方式 |
| 告警中心 | 告警通知时间支持按通知人时区格式化，跨地区协作时更易理解 |
| 补丁管理 | 周期评估支持通知配置，可在发现不合规或评估失败主机时发送汇总提醒 |
| 补丁管理 | 周期任务支持按用户时区调度与展示，评估时间更符合个人使用习惯 |
| 补丁管理 | 基线合规详情支持查看失败原因与评估时间，问题定位更直接 |
| 补丁管理 | 基线管理支持从主机和补丁两个视角查看合规矩阵 |
| OpsPilot | 知识库支持多资料的同知识冲突审批，知识治理流程更可控 |
| 系统管理 | 新增企业微信集成能力，支持用户同步、登录认证及 IM 通知 |
| 系统管理 | 支持配置平台新用户默认密码策略 |
| 监控中心 | 新增进程监控能力，支持进程状态与运行情况监测 |
| 监控中心 | 自动发现对象清理策略支持分钟级自动清理 |
| CMDB | 新增 UIS 自动发现能力，提升资产纳管效率 |
| 补丁管理 | 内置YUM/DNF/APT公网补丁源 |
| 运营分析 | 报告订阅能力扩展至大屏场景，支持显式刷新快照 |
| OpsPilot | 平台右下角增加OpsPilot AI助手聊天窗 |
