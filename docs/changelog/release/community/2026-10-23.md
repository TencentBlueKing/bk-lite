# 2026年10月23日 更新日志
版本发布时间：2026年10月23日
了解更多产品能力，欢迎查阅[官方文档](https://www.bklite.ai)或直接体验[Demo环境](https://bklite.canway.net)

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| 平台 | WorkBuddy技能市场上线「BK-Lite运维助手」，支持对接平台获取数据加入AI分析 |
| 系统管理 | 新增通知渠道查询与消息投递 OpenAPI，方便外部系统复用平台通知能力 |
| CMDB | 网络设备采集新增机箱、板卡等硬件序列号信息，方便资产核对 |
| CMDB | 资产列表与实例详情支持查看 UUID，并可按 UUID 筛选定位 |
| 监控中心 | 新增策略组功能，支持打包策略模版统一生效于监控资产 |
| 监控中心 | 告警策略支持多指标同时满足后触发，例如「CPU 高且内存高」 |
| 告警中心 | 事件与告警原始数据支持展示 CMDB 补充信息及负责人，排查上下文更完整 |
| 告警中心 | 集成事件列表支持按状态筛选，告警中的字节类数值自动换算为易读单位 |
| 运营分析 | 架构图支持批量插入并绑定 CMDB 资源，查看资源详情与告警状态 |
| 运营分析 | 仪表盘支持设为登录首页，登录后直达关注的业务视图 |
| 作业管理 | 作业脚本支持平台变量，自动获取执行用户和作业ID等信息 |
| 编排中心 | 全新发布「编排中心」模块，支持灵活编排自动化流程，实现复杂任务的自动化执行 |
| 编排中心 | 支持包括作业执行、文档生成、对外通知等15种流程节点 |
| 编排中心 | 内置 Windows/Linux 系统巡检流程模板，开箱即用，快速体验自动化巡检能力 |
| OpsPilot | 企业微信长连接支持直接回传 AI 生成的文件，短连接消息提供下载链接 |

### 功能优化

| 模块 | 功能优化 |
| --- | --- |
| CMDB | 未识别的网络设备支持补全类型、品牌和型号后确认入库 |
| 监控中心 | MySQL 仪表盘升级，按概览、性能、复制、Top SQL、等待分类排查，重点异常更直观 |
| 告警中心 | 企业微信、飞书通知完善告警级别着色，紧急程度更容易辨识 |
| 运营分析 | 优化资产总览视图，亮暗主题适配 |
| 补丁管理 | Windows 补丁安装前增加磁盘空间和系统版本检查，提前发现不满足安装条件的主机 |
| 补丁管理 | Windows基线评估增加WUA匹配校验，自动识别补丁适配性，如.NET补丁是否适配该主机Framwork版本 |
| OpsPilot | 平台AI助手统一管理历史会话与已生成文件，查找、下载更方便 |
| OpsPilot | 优化页面上下文与工具调用配合，以及知识库导入过程中的交互反馈 |
