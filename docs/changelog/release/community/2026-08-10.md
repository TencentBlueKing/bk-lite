# 2026年8月10日 更新日志

版本发布时间：2026年8月10日  
了解更多产品能力，欢迎查阅[官方文档](https://www.bklite.ai)或直接体验[Demo环境](https://bklite.canway.net)

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| CMDB | 实例业务身份切换为不可变 `inst_uuid`（UUIDv4）；OpenAPI/NATS/跨模块以 UUID 定位实例 |
| CMDB | 提供维护期清洗命令与切换 Runbook，支持图库重建后引用稳定 |

### 功能优化

| 模块 | 功能优化 |
| --- | --- |
| CMDB | 关联边持久化 UUID 端点；对外响应剥离图 `_id` 业务键 |
| CMDB | 配置文件采集协议 v2：下发/回调使用 `target_instance_uuid` / `instance_uuid` |
| 运营分析 | 网络拓扑等实例引用字段更名为 `bk_inst_uuid` |
| 告警中心 | CMDB enrichment 使用 `inst_uuid`（protocol_version=2） |

### 破坏性变更 / 迁移注意

| 模块 | 说明 |
| --- | --- |
| CMDB / Web | 数字 `inst_id` URL 与请求体不再作为实例定位方式；**Web 需同版本或紧随切换**（本仓前端改动另票） |
| CMDB | Telegraf 监控标签仍为 `cmdb_{task_id}`，勿与实例 UUID 混淆 |
| 运维 | 切换步骤见 `docs/operations/cmdb-instance-uuid-cutover.md`；清洗命令不属于 `batch_init` |
