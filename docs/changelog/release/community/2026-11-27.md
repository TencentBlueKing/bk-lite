# 2026年11月27日 更新日志
版本发布时间：2026年11月27日
了解更多产品能力，欢迎查阅[官方文档](https://www.bklite.ai)或直接体验[Demo环境](https://bklite.canway.net)

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| 系统管理 | 新增腾讯云、阿里云短信和语音通知渠道，支持使用已审核的云厂商模板发送 |
| 系统管理 | 新增模块管理员和模块审计员，可按应用授予管理或只读审计权限 |
| CMDB | 新增火山引擎配置采集，覆盖云服务器、公网 IP、负载均衡、MySQL、PostgreSQL 和对象存储 |
| CMDB | 采集任务支持连通性测试，可提前检查网络和凭据是否可用 |
| 监控中心 | 新增 RocketMQ 监控，支持查看 Broker 读写速率和采集状态等指标 |
| 日志中心 | 新增「来源设备」页面，自动发现发送 Syslog 的设备，可查看最近上报时间和活跃状态，点击设备直达日志检索 |
| RUM | 会话列表支持按终端用户 ID 筛选，可从会话时间线跳转到关联的 APM 调用链，串联前端体验和后端排查 |
| RUM | 应用接入支持配置会话采样率 |
| 运营分析 | 柱状图支持堆叠，折线图和柱状图支持添加参考线，大屏列表支持自动滚动 |
| 运营分析 | 排行、饼图和柱状图支持对查询结果排序并限制展示条数，方便搭建 Top N 视图 |
| 作业管理 | 作业目标、脚本和 Ansible Playbook 支持批量调整所属组织，并在提交前预览变更 |
| 编排中心 | 企业微信群机器人支持直接发送文件 |
| OpsPilot | 智能体支持导出并导入当前组织，方便复用提示词、工具和技能包配置 |
| OpsPilot | 支持对回答评分并填写反馈，可按时间、渠道或指定会话生成并导出历史分析报告 |
