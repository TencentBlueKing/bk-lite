# 2026年9月18日 更新日志

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| CMDB | 新增 SSL 证书 TLS 握手采集 |
| CMDB | 采集接入凭据管理 |
| CMDB | Oracle 采集覆盖 CDB、PDB、RAC |
| CMDB | 资产列表内网/外网 IP 支持一次精确查询多个地址 |
| CMDB | 资产详情支持监控视图、告警列表、监控策略、关联拓扑、资产变更与节点状态 |
| 监控中心 | 新增多品牌网络与电源设备 SNMP 采集能力（含华为交换机/路由器/WLAN、H3C/Ruckus 无线，以及 PDU、UPS、传输设备等） |
| 监控中心 | 对象详情支持关联拓扑、资产信息、资产变更与节点状态 |
| 日志中心 | 新增 通用-Kafka日志订阅 集成能力 |
| 日志中心 | Syslog、SNMP Trap提取器支持 条件 配置项 |
| 告警中心 | 告警与事件列表支持按监控源筛选 |
| 告警中心 | 集成源详情展示监控源事件统计 |
| 告警中心 | 分派通知方式纳入企微应用与 IM 通道 |
| 告警中心 | 告警详情支持监控视图、资产信息、资产变更、告警原始日志、节点状态、服务概览与调用链 |
| 运营分析 | 3D 应用墙按告警排序并支持分页 |
| OpsPilot | 新增CMDB/监控中心/日志中心/告警中心工具 |
| OpsPilot | 知识库支持 OKF 导出导入、embedding增强 |
