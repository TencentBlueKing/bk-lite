# 正常方向海豚跳圈双版本动画设计

## 目标

替换第三版动画中翻身、倒游和复杂回程带来的怪异感，制作两个动作方向始终自然的透明背景 GIF。两个版本共用同一套海豚、圆环和跳跃动作，仅使用不同的循环收尾方式。

## 共同视觉规则

- 继续使用 Q 版扁平线稿海豚和蓝青渐变，但收紧夸张比例，保持正常海豚侧身轮廓。
- 海豚始终朝右上方运动，旋转幅度不超过约 15°，不得头朝下、翻身或倒着游。
- 圆环缩小并固定在画面中央，不跟随海豚移动。
- 海豚从左下方沿单一抛物线穿过圆环，圆环以简单前后遮挡表达穿圈深度。
- 不增加水花、气泡、文字、阴影或其他装饰，避免小尺寸展示时显得杂乱。

## 版本 A：穿圈后出画面

文件名为 `web/public/logo-site-animated-v3-exit.gif`。

1. 海豚从左侧画面外进入，在左下方短暂蓄力。
2. 海豚沿抛物线跃起并从圆环中央穿过。
3. 穿圈后海豚保持头朝右上，继续向右游出画面。
4. 首尾帧均不显示海豚，只保留固定圆环；循环切换时不会出现可见的位置跳变。

## 版本 B：停留圈内

文件名为 `web/public/logo-site-animated-v3-stay.gif`。

1. 海豚从左下方蓄力，沿与版本 A 相同的抛物线跳入圆环。
2. 海豚在圆环中央恢复水平姿态，轻轻摇尾巴并停留片刻。
3. 海豚在固定位置淡出；淡出完成后回到起点，避免展示倒游回程。
4. 首尾帧保持一致，循环切换不可出现明显闪烁。

## 输出规格

- 两个 GIF 均为 512 × 512、透明背景、无限循环，时长约 2.5 秒。
- 使用相同线宽、渐变、圆环尺寸和跳跃节奏，便于直接比较收尾效果。
- 保留现有 PNG、第一版和第二版 GIF，不覆盖已有素材。

## 验收标准

- 两版均能第一眼看出海豚从左下方跳过固定圆环。
- 海豚始终保持自然朝向，不出现翻转、头朝下、倒游或复杂回程。
- 穿圈遮挡清楚，但不切断海豚主体或产生残影。
- 版本 A 出画面后循环无可见跳变；版本 B 淡出后循环无明显闪烁。
- 两个文件均具有透明通道、正确尺寸、稳定帧时序和无限循环标记。
