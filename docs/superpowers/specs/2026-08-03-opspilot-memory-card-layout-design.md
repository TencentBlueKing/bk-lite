# OpsPilot 记忆列表卡片统一设计

日期：2026-08-03
状态：已确认

## 目标

将 OpsPilot 记忆列表页的卡片布局收敛到智能体、工作台已有的实体卡片视觉语言，解决固定四列、卡片内部排版独立、窄屏挤压和元信息位置不一致的问题。

本次只修改记忆列表页，不调整接口、表单、权限、编辑删除逻辑，也不改动智能体、工作台、知识库等现有页面。

## 采用方案

采用“统一视觉结构，保留记忆业务内容”的 app-local 实现：

- 不扩展共享 `EntityCard`，避免对已有消费者产生视觉或行为回归。
- 记忆卡片沿用智能体卡片的四段式结构：顶部视觉区、图标锚点、标题描述区、底部元信息区。
- 复用 Ant Design `Card`、项目现有 `Icon`、`MoreActionsDropdown`、颜色 token 和间距规范。
- 不新增 shared 组件；如果需要拆分，仅在 OpsPilot memory 页面目录内创建 app-local 组件。

## 页面布局

### 页头

- 桌面宽度下，标题说明位于左侧，搜索和“新建记忆”位于右侧。
- 窄屏下改为纵向排列；操作区允许换行，搜索框占可用宽度，新建按钮保持完整可点击。
- 不使用固定页面最小宽度，不产生整页横向滚动。

### 卡片网格

与智能体实体列表保持相同响应式密度：

| 视口 | 列数 |
|---|---:|
| 默认 | 1 |
| `sm` | 2 |
| `md` | 3 |
| `lg` | 4 |
| `2xl` | 5 |

网格间距统一为 `16px`。卡片等高，长标题和长描述不能撑高单个卡片。

## 卡片结构

### 顶部视觉区

- 高度与智能体卡片接近，使用现有 OpsPilot Banner 资源或现有主题 token，不创建新的装饰背景。
- 组织记忆与个人记忆使用克制的视觉差异，并同时显示文字标签，不能只依赖颜色表达。
- 更多操作保持右上角，点击操作菜单时不触发卡片跳转。
- 记忆图标放在 Banner 与内容区交界处，位置和尺寸与智能体卡片头像锚点一致。

### 内容区

- 标题使用 `14px / 600`，单行省略并提供可访问的完整文本提示。
- 描述使用 `12px` 辅助文本，固定可用高度，最多显示三行。
- 空描述显示 `-`，不改变卡片高度。

### 底部元信息

- 左侧显示记忆条数，数字使用 tabular numbers。
- 右侧显示创建人，长用户名安全省略。
- 元信息与正文通过间距或细分隔线分组，不增加嵌套卡片。

## 交互和可访问性

- 卡片整体进入详情页，支持鼠标点击、键盘 Enter 和 Space。
- 卡片提供清晰的 hover、focus-visible 和 active 状态。
- 更多操作按钮具有可读的 `aria-label`，菜单保持现有编辑和删除权限控制。
- 遵循 `prefers-reduced-motion`，悬停只使用轻微位移、边框或阴影反馈，不做装饰性动画。
- 保持现有 loading、接口失败提示、创建、编辑和删除行为。

## 组件与数据流

数据流不变：

1. 页面调用 `fetchMemorySpaces` 获取记忆空间。
2. 搜索词在前端过滤名称。
3. 卡片接收 `MemorySpace`，渲染 scope、name、introduction、memory_count 和 created_by。
4. 卡片点击进入 `/opspilot/memory/detail/config?id=<id>`。
5. 编辑和删除仍由页面现有 handler 处理。

视觉结构可以抽成 memory app-local 卡片组件，使列表页只负责数据、搜索和弹窗；不得放入 `web/src/components`。

## 异常与边界

- 名称、描述、创建人为空时使用稳定占位。
- 中文、英文、长资源名和连续字符不能破坏布局。
- 只有一张卡片时不拉伸到异常宽度；网格列宽与智能体页保持一致。
- 搜索无结果时应保留稳定空区域；如现有页面已有 Empty 约定则复用，不自行创建新空状态组件。
- 亮色和暗色模式只使用语义 token；Banner 图片之外不硬编码品牌色。

## 验证

- 运行目标文件 ESLint 和 TypeScript 检查。
- 在真实记忆页验证桌面宽屏、常规桌面、平板宽度和窄屏。
- 验证 1、4、5 个以上卡片时的列数和等高效果。
- 验证长标题、长描述、空描述、长创建人。
- 验证点击卡片、键盘进入、编辑菜单、删除菜单和权限状态。
- 验证亮色、暗色以及 reduced-motion。

## 非目标

- 不统一改造所有 OpsPilot 卡片组件。
- 不修改记忆详情页。
- 不调整记忆接口、数据模型或分页方式。
- 不新增卡片主题、动画系统或全局 design token。
