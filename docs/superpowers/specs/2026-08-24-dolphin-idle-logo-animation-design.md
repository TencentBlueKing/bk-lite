# Q 版海豚待机 Logo 动画设计

## 目标

以用户附件中圆脑袋、弯眼睛的 Q 版线稿海豚为唯一主体，制作一版动作自然、克制的透明背景待机 GIF。动画不再使用圆环、穿越画面或大幅旋转，只通过漂浮、摆尾和眨眼让 Logo 轻微动起来。

## 视觉约束

- 使用现有 `web/public/logo-dolphin-q.png` 作为透明素材，它与用户附件中的海豚轮廓一致。
- 保留蓝青渐变、圆角线条、弯眼睛、短嘴和完整尾鳍，不重绘整体轮廓。
- 画面中只有一只海豚，不增加圆环、水花、气泡、文字、阴影或背景。
- 海豚保持竖向跃起姿态并居中展示，不横向穿越画面。

## 动画节奏

动画约 2.4 秒并无限循环：

1. 海豚在起始位置轻轻上浮约 5–6 像素，同时整体倾斜不超过 2°。
2. 上浮过程中尾鳍以尾根为轴柔和左右摆动两次；头部和身体主体保持稳定。
3. 动画中段将弯眼睛短暂压成闭眼线，完成一次约 120–150 毫秒的眨眼。
4. 海豚缓慢回落到起点，尾鳍和整体倾斜同时复位。
5. 首尾帧的位置、角度、尾鳍和眼睛状态完全一致。

## 实现边界

- 身体主体、尾鳍和眼睛作为三个独立动画区域处理，避免整只海豚跟随尾巴晃动。
- 尾鳍只做小角度局部变形；若局部分割造成断线或重影，优先降低摆动幅度，不修改主体轮廓。
- 眨眼只改变眼睛区域，不遮挡头部轮廓。
- 输出文件为 `web/public/logo-site-animated-v4-idle.gif`，保留现有全部 PNG 和 GIF。

## 输出与验收

- 512 × 512、透明背景、约 2.4 秒、无限循环。
- 第一眼仍是一枚稳定的 Logo，而不是在画面中移动的角色动画。
- 漂浮幅度克制，尾巴没有断线或残影，眨眼清楚但不突兀。
- 海豚不翻身、不横移、不倒游，首尾循环无可见跳变。
- GIF 具有透明通道、正确尺寸和稳定帧时序。
