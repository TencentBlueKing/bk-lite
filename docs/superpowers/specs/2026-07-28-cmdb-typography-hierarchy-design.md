# CMDB 字号层级治理设计

## 背景

CMDB 部分页面存在下级内容字号大于上级标题的问题，与
`web/DESIGN.md` 和 `web/src/app/cmdb/DESIGN.md` 的产品字号阶梯不一致。

本次采用严格字号阶梯：

- 页面、抽屉、弹窗标题：16px。
- 区块标题、卡片标题、正文、按钮和主要数据：14px。
- 辅助标签、状态说明和副标题：12px。
- 统计值通过 `font-semibold` / `font-bold`、语义色和
  `tabular-nums` 强调，不再通过超大字号强调。

## 修改范围

仅处理已经确认的 8 组问题：

1. 资产数据的 K8s 资源详情标题和指标值。
2. 自动发现的节点管理同步抽屉统计值。
3. 自动发现的任务详情抽屉统计值。
4. 专业采集首页统计卡。
5. 自定义上报首页统计卡。
6. 公共枚举库弹窗中的枚举库名称。
7. 资产变更记录统计计数。
8. 资产搜索首页 Hero 标题和分类数量。

以下待视觉确认项不在本次范围：

- 关系视图中的机架和机房详情。
- 网络拓扑节点告警角标。
- 表格字段编辑器中的 `+` / `−` 操作符。

## 设计方案

### 页面与弹层

页面主标题保留或收敛为 16px。弹窗和抽屉内部的区块标题使用 14px，
不得超过弹层标题。

### 统计卡

统计卡标签使用 12px，统计值使用 14px。统计值保留较高字重、语义色和
等宽数字，以保持可扫描性，但不再形成字号倒挂。

### 资产搜索

Hero 标题由 22px 收敛为 16px；分类卡名称与分类数量均使用 14px，
通过字重区分名称和数量。搜索框作为页面主操作，控件高度不在本次调整范围。

## 非目标

- 不修改数据请求、状态管理、路由或交互逻辑。
- 不调整颜色、间距、卡片结构和响应式布局。
- 不顺带治理 CMDB 其他设计问题。
- 不修改告警中心和运营分析。

## 验证

- 增加定向静态回归检查，覆盖 8 组字号声明。
- 对修改文件运行 ESLint。
- 运行 `git diff --check`。
- 在可用的本地页面上抽查统计卡、弹窗和资产搜索的实际层级。
- 确认 3 个待视觉确认项未被改动。
