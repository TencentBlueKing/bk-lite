# 带原 Logo 圆环的 Q 版海豚待机动画设计

## 目标

在第四版 Q 版海豚待机动画的基础上恢复原 `logo-site.png` 的标志性倾斜椭圆环。海豚不跳圈，圆环完全固定；整体构图、线条交叉关系和蓝青渐变应与原 Logo 保持一致。

## 构图与层次

- 使用 `web/public/logo-dolphin-q.png` 作为 Q 版海豚主体。
- 椭圆环沿用原 Logo 的倾斜方向、长宽比例、线宽和蓝青渐变。
- 圆环分为后半环与前半环：先绘制后半环，再绘制海豚，最后绘制前半环，以恢复原 Logo 中环线穿过海豚前后的交叉关系。
- 海豚位于环内并采用与原 Logo 相近的占比和视觉中心；动画过程中不得离开椭圆环。
- 画面只包含海豚和椭圆环，不增加水花、气泡、文字、背景或阴影。

## 动画

沿用第四版约 2.4 秒的克制待机动作：

1. 椭圆环全程静止，不缩放、不旋转、不位移。
2. 海豚在环内上浮约 5–6 像素，并轻微倾斜不超过 2°。
3. 尾鳍以尾根为固定点局部柔和摆动两次，身体主体保持稳定。
4. 中段将弯眼睛短暂压平，完成一次约 120–150 毫秒的眨眼。
5. 海豚回到初始位置、角度、尾鳍和眼睛状态；首尾帧完全一致。

## 输出与验收

- 输出为 `web/public/logo-site-animated-v5-brand.gif`。
- 512 × 512、透明背景、约 2.4 秒、无限循环。
- 静止帧第一眼应与原 Logo 属于同一构图，只是海豚变为更可爱的 Q 版。
- 动画只发生在海豚上；圆环始终稳定，交叉遮挡不抖动、不穿帮。
- 海豚不跳圈、不横向穿越、不翻身，尾巴无断线或残影，眨眼不影响头部轮廓。
- 保留现有 PNG 与所有历史 GIF，不覆盖已有素材。
