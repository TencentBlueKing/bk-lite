# ITSM 设置

Status: done

| 设置项 | 在业务中何时生效 |
| --- | --- |
| 处理组、代理、VIP | 维护本域的人员配置。处理组的成员和负责人可用于分派等场景；代理、VIP 各自维护。 |
| 通知模板 | 通知事件渲染工单变量并生成消息。触发器的发送通知动作可选模板或自定义内容；即时消息的通道与账号映射复用平台能力。 |
| 满意度模板 | 工单完成时保存适用问卷的快照，后续评分、评论或回答按该工单的配置展示和校验。其他域的模板不会改变此工单。 |
| 打印预览 | 样例和真实工单共用固定版式。真实打印使用该工单可见且支持打印的字段，按实际值展示。 |
| 公告、基础配置 | 公告用于门户展示。基础配置维护产品名称、页签标题、附件扩展名、流转日志显示和用户显示方式。 |

## 验收

1. 在本域配置满意度模板，完结工单后修改模板，打开旧工单仍能读取原问卷；提交时检查必答项。另一个域的配置不参与选择。[满意度测试](../../../server/apps/itsm/tests/test_ticket_surveys.py)
2. 对照打印样例和真实工单，检查两者的区块和表单布局。可见字段有值，隐藏字段不输出；已保存的自定义模板不能改变工单打印版式。[打印测试](../../../server/apps/itsm/tests/test_print_templates.py)
3. 配置待办通知，核对消息中的工单标题、单号、流程、当前节点和详情链接；权限与通道选择见[自动化与时效](../itsm-rule/spec.md)。[模板测试](../../../server/apps/itsm/tests/test_notify_templates.py)
4. 按当前域保存和读取基础配置，验证配置确实作用于运行入口。[基础配置测试](../../../server/apps/itsm/tests/test_runtime_settings.py)
