# CMDB SSL 证书采集发现

Status: ready

## Problem Statement

证书许可分类和 `ssl_cer` 模型已经能手工录入 SSL 证书，资产详情也能展示实例名、域名、颁发者、颁发时间和截止时间。运维仍要自己去站点上查当前出示的证书，并手工改截止时间。没有采集任务时，过期证书不会自动刷新，到期治理缺了自动发现这一环。

## Solution

用户先在 CMDB 录入 SSL 证书实例（实例名和域名），再创建只选这些实例的采集任务。接入点对实例域名做 TLS 握手，取出当前出示的证书元数据，写回同一条实例。采集不新建、不删除证书资产，也不改用户填好的实例名和域名。

## User Stories

1. As a CMDB 管理员, I want 在采集对象树看到「证书许可 / SSL 证书」, so that 我能按证书资产而不是网段来建采集任务
2. As a CMDB 管理员, I want 先录入证书实例的实例名和域名再选进采集任务, so that 任务目标和资产清单是同一批对象
3. As a CMDB 管理员, I want 采集任务不能选网段且不需要登录凭据, so that 不会把证书探活做成主机扫描或 SSH 采集
4. As a CMDB 管理员, I want 接入点按域名 TLS 握手取出颁发者、颁发时间和截止时间, so that 资产详情里的证书时效字段能自动更新
5. As a CMDB 管理员, I want 证书过期或自签时采集仍然成功, so that 到期治理不会因为校验失败而看不到截止时间
6. As a CMDB 管理员, I want 某个目标 DNS 失败、连不上、超时或拿不到证书时只失败该目标, so that 其他证书实例仍能更新，失败实例保持原值且不被删除
7. As a CMDB 管理员, I want 手工执行和周期执行都只更新已选实例, so that 预录入的证书资产不会被采集复制或清掉

## Implementation Decisions

- 复用已有模型 `ssl_cer` 和分类 `certificate`，不改模型字段，不新增关联，不做 Django 迁移。
- 采集对象树新增分组「证书许可」，子项 SSL 证书。任务类型为协议采集，驱动为 protocol，无加密凭据字段。中英文采集对象树语言包必须覆盖该分组和插件。
- 任务只接受已有 `ssl_cer` 实例。服务端拒绝 `ip_range`；前端按模型关闭网段选择，走只选资产形态，并选择接入点。
- 连接主机取实例的 `domain`，端口固定 443，SNI 使用该域名。不校验证书链和主机名。预检使用 TLS/HTTPS 可达语义：证书校验失败仍视为目标可达，正式采集再取证书。
- 下发目标必须同时携带实例名和域名。采集结果按实例名匹配任务中的已录入资产后回写。禁止使用默认协议身份 `{ip}-{model}-{port}`。
- 允许回写的字段仅限：颁发者、颁发时间、截止时间、是否自动发现、上次更新时间、采集任务。实例名、域名、组织不得覆盖。
- 采集不得新建 `ssl_cer` 实例。预录入且尚未挂本任务的实例，按实例名命中后更新并打上本任务。探活失败或本轮未见，不得进入删除列表；即使任务配置了立即清理，本插件也不删除证书实例。
- 手工执行与周期执行都只走更新。域名缺失、DNS/连接/超时、握手后无证书，按目标失败并使用稳定错误码，任务允许部分成功。过期、自签、主机名不匹配视为采集成功。
- 不采集私钥、证书 PEM、指纹、序列号或 SAN 列表。日志不得输出证书正文或私钥。
- 插件说明文档描述：先录入实例、只选实例、默认 443、无凭据、过期证书仍采集。

## Testing Decisions

- 只测外部行为：任务能否创建、探活写回哪些字段、失败是否删资产、过期证书是否入库。不把 TLS 库内部调用顺序当契约。
- Agent：用本地自签/过期证书夹具做握手与解析，覆盖成功取出颁发者与时间、过期证书成功、连不上/无证书失败。对标物理服务器 Redfish 的本地 TLS 夹具，而不是真实公网站点。
- Server：采集对象树登记、语言包覆盖、任务拒绝网段、无凭据、按实例名更新且不新增/不删除、字段白名单、部分成功摘要。对标 InfluxDB/网络配置文件的对象树与任务校验测试。
- Web：SSL 证书任务只能选 `ssl_cer` 实例，不能选网段，不渲染凭据。对标配置文件任务的只选资产表单。
- 模型配置工作簿保持现有 `ssl_cer` 字段，本变更不改表结构。

## Out of Scope

- 软件许可或其他证书许可子模型
- 网段扫描、从 Nginx/Apache 证书文件解析
- 非 443 端口、独立 SNI 字段、按 IP 指定后端
- 证书与主机、负载均衡的关联
- 到期提醒、告警或许可证容量
- 云厂商 CAS 证书清单（如阿里云 SSL）并入本模型
- 客户端证书双向认证

## Further Notes

- 截图中的 `rex-test` / `www.baidu.cn` 是手工录入形态，采集只刷新时效字段，不改命名。
- 同一域名被两条实例共用时，本轮按任务快照里的实例名分别回写同一份证书元数据；不在本期加域名唯一约束。
