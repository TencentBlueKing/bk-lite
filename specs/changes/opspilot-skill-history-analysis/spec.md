# 智能体历史的智能分析

智能体管理员从「历史 → 智能分析」打开任务抽屉。每次分析生成一份独立报告，关闭页面后任务继续执行，同一管理组织内可重新打开或导出报告。

## 创建任务

1. 点击「新建分析」，默认分析最近七个自然日。时间选择按操作人的显示时区解释，沿用历史页已生效的渠道、人员筛选。
   按该范围内实际有用户提问的渠道类型多选，同类型的不同入口合并。普通渠道默认勾选，编排中心和工作台默认不勾选。仅有流程对话时可主动勾选后创建任务。
2. 也可以选择「指定对话」，按渠道类型筛选候选、按标题搜索，跨页勾选多个对话。切换候选筛选保留已选对话，创建按明确勾选的对话执行。预览显示有用户提问的对话数与提问条数。
3. 选择综合分析、高频需求或回答质量。每种目标有内置分析说明，可补充关注点、修改默认任务名称。
4. 确认后进入队列。列表显示任务范围、创建人、时间、状态。失败显示原因；重试沿用原任务引用的消息。超出范围或容量时须调整选择，系统不会抽样后当成全量报告。

## 分析口径与证据

- 时间范围按用户提问的创建时间计算，包含结束日。配对回复可发生在时间窗之后，最靠近窗口的上一轮只作理解上下文。指定对话按创建任务时的内容分析。附件和工具调用明细不进入模型。
- 单次最多 50 个对话、200 条提问、650 条含上下文的消息，另有正文长度限制。预览与创建共用同一筛选逻辑，任务落库时固定消息 ID。执行前发现源消息已删除会失败。
- 报告由智能体配置的模型生成，语言跟随创建人的界面。后台计算覆盖数，校验每条发现的证据都来自选中的提问。模型只接收可见文字，采用匿名会话编号，屏蔽常见明文凭据、邮箱和手机号。
- 新任务保存实际覆盖的渠道类型，列表、报告及 PDF 均展示。报告展示范围、覆盖数、发现和改进建议。点击证据直接打开引用的消息，可切换到完整对话，关闭回放后回到原报告。导出 PDF 包含范围、结论、建议和消息编号。
- 创建、列表、查看、重试、导出均检查智能体管理权限。报告按智能体及当前组织隔离，原文回放重新检查原对话所属智能体的管理权限。正文遵循历史页的管理可见范围。
- OpsPilot 0093 创建分析任务表，0097 在智能体会话中保存来源流程名称。原会话缺少名称时仅显示渠道类型，再次从同一流程调用时补上名称。后台复用现有的 opspilot_maintenance 队列。提交后派发任务，同一创建请求幂等，重复投递或旧轮次回执不会覆盖新一轮结果。

## 回归入口

后端回归覆盖渠道类型聚合、提问时间边界、任务范围快照、权限以及中英文 PDF。前端回归覆盖流程名称、渠道默认选项、仅有流程对话的范围、跨页或切换渠道后保留已选对话、证据定位和导出。
