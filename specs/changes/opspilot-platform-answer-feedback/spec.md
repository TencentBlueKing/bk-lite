# 平台对话回答评价

登录用户可以在平台对话窗口对自己的单条智能体回答点赞或点踩。两种评价互斥，重复点击已选项可取消。保存失败时保留原评价，并在回答下方提示重试。

回答操作栏在复制旁显示一个组合赞踩图标。点击「评价回复」打开两项菜单：「回复优秀」和「回复不佳」。打开菜单不写入数据；选中一项即保存评分。历史回答在悬停或键盘聚焦时显示操作栏，触屏可直接点击。

首次评分或改评后打开居中的「提交反馈」弹窗。两种评价分别提供五个和八个标签，均可多选；也可只填写最多 500 字的说明。关闭弹窗保留已保存的评分。工具栏在未评价时显示描边组合图标，评价后显示对应方向的实心拇指。再次打开菜单时，当前评分使用实心图标并带勾，另一项保留描边；再点该项撤回。通过「更多操作 → 编辑反馈」回看、修改或清空标签及说明，改评和撤回都会清除旧详情。接口校验详情的评分方向，已撤回或改评后的旧详情请求不能恢复原评分。

评价保存在回答消息上，历史数据默认未评价。平台窗口通过流式落库回执取得新回答的消息 ID，重新打开对话时从消息接口恢复评价。用户提问和未落库的回答不展示评价按钮。

写入接口按当前渠道的组织权限、会话所有者、会话 ID 及助手消息 ID 校验。请求指定目标评价，重复提交相同值幂等。数据库迁移为 OpsPilot 0094（评价）、0095（单个原因、说明）和 0096（多选标签，原原因迁入列表）。
