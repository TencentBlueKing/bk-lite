# 02 — 画布编辑态节点/折线草稿写回

Status: done

Blocked by: 01 — 布局配置落盘与刷新回填

**What to build:** 父级画布编辑态且非分享模式下，用户可直接拖动节点与连线折点；变更实时写入该组件实例草稿，靠页面「保存」落库。查看态允许节点临时拖动，但不可编辑折点、不可落库；分享态不可误改。

- [x] 仅在父级画布可编辑且非分享模式下，节点与折点可编辑并写回草稿（不设组件内「编辑布局」开关）
- [x] 查看态：节点可临时拖动（ephemeral），折点不可编辑，不写回配置；编辑态可拖节点与折点，不可端点重连或改拓扑结构
- [x] 节点移动与折点变更实时写回该实例草稿 `valueConfig` 的布局字段
- [x] 工具栏无「保存布局」/「编辑布局」；页面「保存」后刷新仍保留编辑结果
- [x] 未点页面「保存」前离开或刷新，布局草稿与其他未保存改动一样丢失
