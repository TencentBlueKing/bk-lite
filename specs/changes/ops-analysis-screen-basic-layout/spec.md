# 运营分析大屏基础配置与页面布局

Status: implemented

- 列表名后缀：同上。

## Problem Statement

运营分析大屏现在主要是往画布上堆数据组件。画布背景、组件外壳和文字几乎没有可配项，查看页的目录、页头、筛选栏把画布挤得很小。编辑时配置入口分散在工具栏和宽抽屉里，重叠的组件也不好点到。搭建者很难做出适合投屏的一屏，值班时也不容易把画布当成主体来看。

## Solution

本版只完善大屏的查看、编辑和全屏基础呈现，不做成专业设计器。

编辑态改成轻量三区：左侧添加基础元素并列出画布元素，中间是完整设计画布，右侧在「画布设置」和「选中元素的样式 / 数据」之间切换。数据组件继续只绑定数据源，配置表单沿用现有 ViewConfig，不再为配数据另开抽屉。标题不再做成一种限制性元素：主标题和小节标题用带字的标题框预设，普通文案用纯文本，时钟单独可选常用时间格式。查看页把目录收起来、页头收成一行；全屏只留画布，不显示筛选按钮和全局智能体。屏幕适配增加按宽、按高，只作用在放大和分享。背景提供纯色和少量预设壁纸，不上传。

## User Stories

1. 作为大屏搭建者，我希望编辑时左侧添加元素、中间看画布、右侧改当前项，从而不用在多个弹窗之间找入口。
2. 作为大屏搭建者，我希望没选中任何元素时右侧就是画布尺寸、主题、背景和适配方式，从而画布级配置不再另开弹窗。
3. 作为大屏搭建者，我希望从左侧「图表」打开组件选择弹窗，从同一栏添加文本、时钟和装饰，从而添加入口都在左侧。
4. 作为大屏搭建者，我希望在右侧样式里输入 X、Y、宽、高并立刻看到画布变化，从而可以微调被挡住或需要对齐的元素。
5. 作为大屏搭建者，我希望换面板样式、改文字外观时画布马上变，换数据源和字段时要点「应用」才取数，从而轻操作跟手、重操作不会误打接口。
6. 作为大屏搭建者，我希望表格、事件表、网络状态拓扑的列配置在固定宽度的右侧栏里滚动查看，从而不必再打开旧的配置抽屉，画布也不会因组件类型来回被挤动。
7. 作为大屏搭建者，我希望用纯文本放说明或副文案，用标题框预设放主标题和小节标题，从而旧顶栏那种「字加装饰」一下就能摆出来，又不会把所有字都锁成标题。
8. 作为大屏搭建者，我希望把时钟拖到画布上并选择常用日期时间格式，从而投屏时能看到展示端本地时间。
9. 作为大屏搭建者，我希望用空心边框圈住一块区域，用分隔线切开上下内容，从而不必给每块内容都套数据组件外壳。单独的边角装饰不提供。
10. 作为大屏搭建者，我希望数据组件在标准、轻量、无边框三种外壳之间切换，并调节标题或内容留白，从而 KPI 像卡片、趋势图更透、3D 能贴在壁纸上。
11. 作为大屏搭建者，我希望从元素列表点名称就能选中被挡住的对象，从而重叠时不必靠猜。
12. 作为日常查看者，我希望目录可以收起、页头只占一行、没有筛选项时不出现筛选条，从而画布是页面主体。
13. 作为值班人员，我希望全屏后只看到画布，不出现筛选按钮和全局智能体，Esc 退出，从而投屏画面干净。
14. 作为值班人员，我希望按宽或按高铺到电视上，超出部分裁掉且不变形，从而非 16:9 屏幕也能用；默认仍完整放下，现网大屏不会突然被裁。
15. 作为已有大屏的维护者，我希望打开旧大屏时原来的顶栏标题和时钟还在，并且变成可移动的标题框和时钟，从而不用重做一屏。

## Implementation Decisions

### 范围与产品边界

- 只改运营分析**大屏**的查看页、编辑态、全屏、分享呈现和 PDF 打印缩放。仪表盘、报表、拓扑、架构图、网络拓扑不跟这期改壳。
- 组件仍然只绑定数据源。不引入屏级 `${变量}`、组件级静态 JSON 主数据、组件级刷新 interval，也不把 Python 转换扩到 NATS / Prometheus / SQL。
- 统一筛选语义不变：仍由数据组件的 `filter` 参数发现并绑定；文本、时钟、装饰不参与筛选扫描，也不出现数据 Tab。
- 不做交互 Tab、图层显隐/锁定/拖拽排序、多选对齐、参考线吸附、撤销重做、上传壁纸、安全区提示、拉伸变形铺满、图表点击下钻。

### 编辑器壳

- 编辑态三区：左（元素列表）、中（设计画布）、右（画布设置或选中项配置）。查看态不是三栏，仍是目录 + 页头 + 可选筛选 + 画布。
- 左栏上半是分类（图表、文字与时钟、标题、边框、分隔线、图形），下半是元素列表，用来点选画布对象。编辑态右键画布元素或列表行打开同一套操作菜单，不再使用角上的更多按钮。左栏可以收起。点「图表」打开现有组件选择弹窗，不再从顶栏添加。点其余分类后，贴着该分类右侧出现有最大高度的浮层，高度随内容收缩，超出再滚动，不另做一整条侧边栏。文字和时钟与标题、边框一样用暗色预览卡片。点中预设、再点同一分类，或点浮层和左栏以外的区域，浮层收起。卡片也可以拖到画布上，落在光标位置。不提供单独的边角。
- 数据组件从左侧「图表」进入现有组件选择器，配完数据源再落画布。之后改数据只在右侧数据 Tab。选定的图形、标题框、边框和分隔线不再在右侧用下拉框换成另一种。
- 未选中时右侧为画布设置：分辨率、主题、背景（纯色 / 预设壁纸）、显示方式（全屏铺满 / 按宽度 / 按高度）。顶栏「画布设置」只取消选中并回到这一栏，不再弹窗。
- 选中元素后右侧为「样式 / 数据」两 Tab。文本、时钟、装饰没有数据 Tab。
- 大屏编辑不再打开现有 ViewConfig 抽屉。数据 Tab 嵌入同一套 ViewConfig 表单；大屏上关掉抽屉内预览，画布即预览。右侧栏宽度固定，不随 Tab 或组件类型变化。表格、事件表的列配置在栏内横向滚动；纵向超出时表单滚动，应用按钮留在栏底。
- 样式、X/Y/宽/高写入当前编辑草稿，和拖拽一样即时反映到画布。数据 Tab 必须「应用」才写回该元素并取数。切换选中项或退出编辑时，数据表单有未应用改动要确认。整屏落库仍是顶栏保存。取消编辑仍回退到上次成功保存。
- 编辑画布和查看页都完整显示设计分辨率，不套显示方式。显示方式只作用于放大和分享。从编辑态直接放大时使用当前草稿的显示方式，不必先保存。放大不留内边距：全屏铺满贴齐窗口；按宽度贴住宽度并从上方排开，高度超出则滚动；按高度贴住高度并从左侧排开，宽度超出则滚动。
- 分辨率预设和自定义宽高都会改设计画布，并把每个元素的位置、大小按新旧宽高比缩放；文本和标题框的字号按较小的一边缩放。构图留在新画布里。宽高输入在失焦或回车后生效，避免打字过程中反复缩放。

### 查看页与全屏

- 查看页：目录可收起；页头收成一行（名称 + 常用操作）；有统一筛选项才展示筛选条，没有则整条不渲染。
- 全屏：应用内全屏（现有闸门），不引入浏览器 Fullscreen API。不显示目录、页头、筛选按钮和全局智能体；Esc 退出。进入全屏时的筛选值保持，周期刷新规则不变。查看页的筛选条不受影响。
- 分享页继续不渲染平台导航；画布适配与全屏同一套算法。

### 屏幕适配

显示方式只有三种，存量 `contain` 和缺省都视为 `fill`（全屏铺满）：

```ts
type ScreenFitAdapter = 'fill' | 'fitWidth' | 'fitHeight';
```

- `fill`：全屏铺满。宽、高分别缩放到窗口，一定铺满，图形可以变形。
- `fitWidth`：按宽度等比。高度超出则纵向滚动，高度不足则留边。
- `fitHeight`：按高度等比。宽度超出则横向滚动，宽度不足则留边。

查看页、编辑画布和 PDF / 订阅渲染仍按设计尺寸等比留边（内部 `contain`，不写入 `viewport`）。放大和分享使用上面三种，并且不再居中留一圈空白。适配字段随 `viewport` 持久化，并进入 YAML。画布的 CSS 变换使用 `scaleX` / `scaleY`；组件内部仍读单一 `fitScale`（取两边的较小值）做密度补偿。

### 画布背景与主题

- 主题仍是 `screen-dark` / `screen-light`。
- 背景：纯色，或少量内置预设壁纸（约 6～8 张，按主题配套）。壁纸铺满设计画布，随画布一起缩放。不做上传、不平铺、不提供填充方式控件。
- `normalizeScreenViewSets` 必须保留用户保存的背景，不得再每次重置成默认 `tech-grid`。缺省时才用主题默认背景。

### 元素模型

`view_sets.items` 在现有数据 / 场景组件之外增加无数据源元素。几何字段与现有项相同：`id, x, y, w, h, zIndex`。用 `kind`（或等价判别）区分，不要把标题框做成限制性「标题」类型：

| kind | 画布表现 | 数据源 |
|---|---|---|
| 现有 widget | 数据 / 场景组件 | 有（场景自拉数除外） |
| `text` | 纯文本 | 无 |
| `clock` | 实时时钟 | 无 |
| `titleFrame` | 带字标题框预设 | 无 |
| `decoration` | 空心边框 / 分隔线；已保存的边角仍可显示 | 无 |
| `shape` | 矩形 / 圆形 / 圆角矩形 | 无 |

- **文本**：一段纯文本 + 常用文字样式（字号、字重、颜色、对齐）预设。不复用现有 Markdown 文本组件。可多个。
- **时钟**：展示端本地时间；格式只能选自固定预设（至少包括 `HH:mm:ss`、`YYYY-MM-DD`、`YYYY-MM-DD HH:mm:ss`、`YYYY年M月D日`、`M月D日 HH:mm`、带星期的日期时间）。不可自定义 pattern，不配时区。可多个，各选各的格式。
- **标题框**：字和装饰焊在一起。6 个主标题预设 + 4 个小节标题预设，颜色跟大屏主题。可改文案和基础文字样式。这是旧顶栏标题的承接物。
- **哑巴装饰**：空心边框和分隔线，无文案字段。边框只用来圈区域，不替代数据组件的标准卡片。左侧不再提供边角；已经放进画布的边角仍按原位置画出来。旧预设 `a` / `b` 读入时分别对应第一套边框或科技边框、第一根分隔线或饰条分隔线。
- **图形**：矩形、圆形、圆角矩形。可改背景色、无背景、边框颜色、边框厚度、无边框、阴影，以及垂直或水平渐变的起止色。圆角矩形圆角固定 30px，圆形为正圆，不单开圆角配置。不产生筛选项。

现有数据组件复制契约不变：仅数据组件可复制，场景组件无复制。文本、时钟、标题框、装饰和图形在编辑态也可以复制：新元素沿用原内容与样式，向右下偏移 48px 并放到最上层，然后选中。分享页和内置画布不提供复制。

### 数据组件面板

`appearance.frame` 只有两档，是结构差，不是换边框色：

```ts
type ScreenWidgetFrame = 'panel' | 'bare';
```

- `panel`（标准）：有底、有边、有标题栏。卡片间距由样式固定，不提供标题留白和内容留白。
- `bare`（无边框）：无底无边无标题栏，内容铺满矩形。

已保存的 `light` 读入时视为 `panel`。不提供组件级取色器、自由圆角或边框色。颜色跟主题。图表内部字号仍走现有图表主题 / `screenRenderContext`。

默认：除 `room3D`、`application3D` 为无边框外，其余图表为标准。存量未写 `appearance` 的组件按这个补默认，不要把现有 3D 的 `bare` 改成标准。

### 元素列表

- 仅编辑态左侧。顺序按 `zIndex` 降序（越在上层越靠前）。
- 点击名称选中该元素，必要时把画布滚到它可见。
- 右键一行，菜单与画布上右键该元素相同。拖动一行到另一行，按列表从上到下重写层级。
- 不能重命名、显隐、锁定。
- 显示名现算不落库：数据组件用 `title`（空则用类型名）；文本和标题框用文案前若干字（空则「文本」「标题」）；时钟为「时钟」；边框和分隔线用预设名并去掉空格（「边框 1」显示为「边框1」）。同一本名按列表从上到下，第一次保持本名，之后加 `-1`、`-2`…。删除元素后序号按当前列表重算。

### 旧顶栏迁移

打开仍带 `decorations.showTitle` / `showClock` 的大屏时，在规范化 `view_sets` 时注入元素，之后不再渲染旧顶栏 chrome：

- `showTitle` 且标题非空 → 一个 `titleFrame`（`hero-5`，文案为原标题）。几何按旧顶栏比例相对设计宽度缩放：顶边约 14、水平居中、参考宽约 800、高约 56、字号约 24 / 字重 800（以 1920 为基准）。
- `showClock` → 一个 `clock`（默认 `YYYY-MM-DD HH:mm:ss`）。位置贴近旧右上角（右内边距约 94），参考宽约 300、高约 40、字号约 16 / 字重 700（以 1920 为基准）。

注入后把对应开关视为关闭，避免双轨。只读、内置、分享在内存中规范化即可；有编辑权的用户下次保存后持久化。YAML 导入旧结构走同一规范化。目录里的大屏名称仍是资源名，不等于画布标题框。

### 持久化与导入导出

- `viewport` 增加 `adapter` 与可保留的 `background`；后端大屏 `view_sets` 校验放行这些字段和新 `kind` 的 items。
- 筛选仍在 `view_sets.filters`。无数据源元素不产生筛选项。
- YAML 导入导出带上新字段；缺 `adapter` 或旧值 `contain` 当 `fill`；缺背景用主题默认。不为这一期单独升 YAML 主版本。

## Testing Decisions

测对外行为，不测 CSS 像素和主题色值。优先复用现有大屏接缝：`view_sets` 规范化、适配度量、布局/外观默认值、筛选扫描、组件配置提交。

1. **规范化**：旧 `decorations` 标题/时钟变成对应 items 且不再双轨渲染；保存过的背景不被重置；缺省 `adapter` 和旧值 `contain` 为 `fill`。切换分辨率时元素几何按新旧宽高比缩放。
2. **适配**：同一设计尺寸下，`fill` 的宽高缩放可以不同且铺满窗口；`fitWidth` / `fitHeight` 等比，贴住对应边，超出的一边标记为可滚动。查看、编辑和 PDF 路径固定等比留边。
3. **外观默认**：除 3D 为 `bare` 外均为 `panel`；已存 `light` 读成 `panel`；存量 3D `bare` 不被改写。
4. **筛选**：加入文本/时钟/装饰后，筛选项集合与绑定只来自数据组件。
5. **列表名**：两个空时钟显示「时钟」「时钟-1」；两个相同边框显示「边框1」「边框1-1」；两段不同文案不加序号；删除靠上的那个后，剩下的显示名回到无序号。
6. **数据配置壳**：大屏编辑不打开 ViewConfig 抽屉；「应用」才提交数据配置；样式/坐标变更不要求点应用。可用现有 `buildWidgetSubmitConfig` 与表单脏值护栏，不要为侧栏再复制一套提交逻辑。
7. **导入导出**：新旧 YAML 都能读；导出含 adapter、背景、新 kind。
8. **右键菜单**：编辑态右键画布元素或列表行，菜单相同。数据组件含编辑、符合复制契约时的复制、删除，以及置顶、置底、上移一层、下移一层。文本、时钟、标题框、装饰和图形含复制和删除，没有编辑。场景组件、分享页和内置画布没有复制。已经在最上层时置顶和上移一层不可用，最下层时置底和下移一层不可用。拖列表改变从上到下的层级顺序。

## Out of Scope

- 图层显隐、锁定、重命名
- 列表显示名与画布标题分成两个字段
- 多选、对齐、参考线、吸附、撤销重做
- 壁纸上传、自定义图片填充、视频背景
- 安全区 / 出血提示
- 拉伸铺满（非等比 `scaleX/scaleY`）以及独立的「铺满裁切」选项
- 按 Vision 搬动画插件、图标库、九宫格拼边框和换色滤镜
- Markdown 文本组件上大屏
- 交互 Tab、图层显隐动作、全局变量、图表点击写入筛选
- 组件级刷新间隔
- 把大屏数据配置迁改仪表盘抽屉；仪表盘继续用现有 ViewConfig 抽屉
- 浏览器原生全屏 API

## Further Notes

- 对照来源是蓝鲸 Vision 的编辑器深度（三区、图层列表、画布 chrome），不是它的数据源/变量模型。运营分析数据契约以本仓库数据源、`field_schema`、统一筛选和命名空间为准。
- 标题框是 6 个主标题 + 4 个小节标题，边框 9 个，分隔线 5 条。加减一张皮肤不改变「带字标题框 vs 纯文本 vs 哑巴装饰」的分工。边框只收能用静态图铺出来的皮肤，分隔线是静态线条。体积过大的标题图、九宫格拼框、动画和图标库不接入。
- 本变更不改统一筛选已确认决策。
