# 移动端运维 Micromoment（在现有 Mobile 壳上扩展）

Status: ready

## Problem Statement

当前 `mobile/` 已是可用的 **OpsPilot 智能应用 + 我的** 壳（Next.js / Tauri / antd-mobile），但未接入告警、监控、CMDB 等运维主数据。值班场景需要在手机上完成告警轻处置与只读观测；同时必须严格落在 BK-Lite **已有产品能力与 API** 上，不能假设扫码、监控关注、单条静默、ITSM，以及**尚不存在的跨模块联动**（告警↔监控↔资产↔日志互跳、证据抽屉、由告警推导监控列表等）。

## Solution

在**保留现有智能应用（OpsPilot）与账号体系**的前提下，把 Mobile 从「纯对话壳」扩展为**分模块并列**的任务壳（各 Tab 自洽，互不嵌套对方业务）：

- **待办** = 告警中心 inbox + 详情 + 轻处置（仅本模块数据与动作）
- **监控** = 监控实例列表/搜索 + 只读指标（仅本模块）
- **资产** = CMDB 资产列表（关注优先）+ 详情（仅本模块）
- **智能应用** = 现有 OpsPilot 工作台
- **我的** = 现网账号与设置
- **日志 / 运营分析** = 首期不进移动端
- **跨模块联动** = 首期明确不做

端形态延续现网：H5 同源；原生壳（Tauri）承载推送等设备能力。离线仅 L1 只读薄缓存。

## Capability Reality Check（相对旧稿的修订）

| 旧稿假设 | 现状事实 | 本版处理 |
|---|---|---|
| 现场扫码 / 条码 / QR 管 CI | **不存在** | **删除** |
| 监控「我关注的实例」 | **不存在** | 列表 = **最近查看 + 搜索**（不靠告警反推） |
| 由告警关联出监控/资产/日志证据 | **无产品级模块联动** | **删除**一切跨模块跳转与证据抽屉 |
| 告警短时静默 | **无**单条静默 API | **删除** |
| CMDB 关注 | **有** `cmdb_followed_assets` | 资产 Tab 默认列表 |
| 告警认领/转派/关闭 | **有** operator API | 保留 |
| OpsPilot | 现网已有 | 底栏保留 |
| 登录 | 域 + 账号；H5 同源 | 对齐现网 |

能力域：告警中心、监控、CMDB、OpsPilot（现网）。日志与运营分析首期不进移动。无 ITSM。

## User Stories

1. As a 值班运维, I want 打开 App 先看到我的告警待办并完成认领/转派/关闭, so that 我能在 micromoment 内处置告警中心告警。
2. As a 值班运维, I want 进入监控查看实例指标（搜索或最近查看）, so that 我可以在监控模块内主动巡检。
3. As an 运维用户, I want 从底栏「资产」看到 CMDB 资产列表并查看详情, so that 我能在资产模块内核对配置信息。
4. As an 运维用户, I want 继续使用现有智能应用发起 OpsPilot 对话, so that 复杂问答仍走已交付能力。
5. As an 运维用户, I want 用与现网一致的域账号登录, so that 不引入多租户/多实例产品概念。
6. As an 安全/平台管理员, I want 移动端写操作仅限告警中心已有操作符与明确允许的资产字段变更且可审计, so that 不会出现幻觉能力或跨模块绕权。

## Implementation Decisions

### 人格与壳（叠在现有 Mobile 上）

- 单 App；从现有双 Tab（智能应用｜我的）扩展。
- 底栏 **5 Tab**：**待办｜监控｜资产｜智能应用｜我的**。
- **搜索不进底栏**：顶栏搜索；结果按类型进入**对应模块详情**，搜索页本身不做「一键带出另一模块关联对象」。
- 各业务 Tab **闭环**：详情页不展示、不跳转其他业务模块的对象卡片。
- 「我的」：账户与安全、语言、深色模式、退出、推送开关（App）、离线说明。

### 模块边界（无跨模块联动）

| 模块 | 层级 | 移动端呈现 | 明确不做 |
|---|---|---|---|
| 告警中心 | L2 | 待办列表、详情、本模块事件/关联告警（若 API 同属告警中心）；认领/分派/转派/关闭 | 跳监控/资产/日志；监控告警第二 inbox；静默；策略配置 |
| 监控 | L1.5 只读 | 最近查看 + 搜索/列表 → 实例详情（关键指标 + 预设短时趋势） | 由告警拼「与我相关」；跳告警/资产；监控关注；策略配置 |
| CMDB 资产 | L1～L2 | 关注列表 + 搜索 → 详情（属性） | 跳告警/监控；扫码；批量改/删/建模 |
| 日志 | L0 | 不进 | 证据抽屉、通用日志台 |
| OpsPilot | L2（已有） | 智能应用 + 对话 | 不在本 change 重做引擎 |
| 运营分析 | L0 | 不进 | 一切移动入口 |

**跨模块联动（首期一律不做）包括但不限于：**

- 告警详情 → 监控摘要 / 监控实例 / CMDB 资产 / 日志片段
- 监控详情 → 关联告警 / 关联资产
- 资产详情 → 关联告警 / 关联监控
- 用告警中心数据推导监控列表「与我相关」
- 统一告警与监控原生告警的融合 inbox / 来源深链回写
- 任何「从 A 模块一键打开 B 模块对象」的产品路径

模块之间仅通过**底栏切换**或**顶栏分类型搜索**并列到达，不在详情内嵌套对方。

### 监控列表

1. **最近查看**（本地，上限建议 20）
2. **搜索 / 对象下列表**（`monitor_instance` API，权限内）

不做「来自我的告警的关联实例」。

### 告警写操作（对齐现网 API）

允许（关闭类需二次确认）：`acknowledge`、`assign` / `reassign`、`close`。

不做：单条静默；策略配置；监控/日志告警第二队列；跨模块处置。

### 资产（无扫码、无联动）

- 底栏「资产」首屏 = 列表（默认 `cmdb_followed_assets`；可搜权限内资产）。
- 详情 = 本模块属性；可选白名单字段 `PATCH`（非关键标识）+ 二次确认。
- 禁止扫码类能力与跨模块关联区。

### 端形态与登录

- H5：同源；域 + 账号密码（及现网 OTP/重置引导）。
- 原生：API 基址部署配置；登录 UI 同 H5；无多实例管理器。
- 推送仅 App；深链到**告警中心详情**（仍属告警模块内，不连带打开监控/资产）。
- H5 不承诺推送与离线缓存。

### 离线（L1）

- 缓存最近打开的告警 / 监控详情快照 / 资产卡片（分模块缓存，不拼关联包）。
- 离线只读；不做 Outbox。

### 权限

- 桌面同源 + 移动再收窄；无移动超级权限。

### 导航挂载

```
待办 (告警中心)
  └─ 告警详情
        ├─ 认领 / 分派 / 转派 / 关闭
        └─ 本模块事件 / 关联告警（同属告警中心则保留）

监控
  ├─ 最近查看 | 搜索
  └─ 实例详情（指标 + 1h/6h/24h）
        └─ 仅监控本模块信息

资产（CMDB）
  ├─ 我关注的 | 搜索
  └─ 资产详情
        └─ 仅资产本模块属性

智能应用（现网）
  └─ 应用列表 → 对话

我的
  └─ 账户 / 语言 / 深色 / 推送 / 退出

顶栏搜索 → 按类型进入对应模块详情（无关联推荐）
```

### 与现有 `mobile/` 的关系

- 保留 workbench / conversation / profile / login 与视觉基线。
- 新增待办、监控、资产路由；底栏 5 Tab。
- 实现另开工程 change。

### 测试接缝

- 验收：告警/监控/资产详情**均无**指向其他业务模块的入口；无扫码、无静默、无日志证据区；智能应用仍可用。

## Testing Decisions

- 只测外部行为与 API 契约。
- 回归现网登录、智能应用、会话、个人中心可达。

## Out of Scope

- **一切跨模块联动**（告警↔监控↔资产↔日志互跳、证据抽屉、关联对象区、由告警推导监控列表）
- 日志移动端入口；运营分析移动端入口
- 资产扫码；监控实例关注；告警单条静默
- 监控告警 / 日志告警第二套 inbox
- ITSM；离线 Outbox；多租户 / 多实例管理器
- 迷你桌面控制台
