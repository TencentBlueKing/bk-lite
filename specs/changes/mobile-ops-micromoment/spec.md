# Mobile 运维微场景 MVP

## 状态

- 结论：需求已确认，阶段 1–4 已实现；阶段 5–6 待继续
- 范围：Mobile H5 / Tauri
- 原型：`/Users/hong/Downloads/discuss.html` 仅用于表达信息架构和视觉方向；本文是 MVP 行为与验收依据

## 目标

在保留现有 OpsPilot 与账号体系的前提下，将 Mobile 从以智能应用为主的对话壳扩展为五个并列、自治的一级模块：

`待办 | 监控 | 资产 | 智能应用 | 我的`

MVP 服务于移动端短时查看和轻量处置，不把 Web 桌面模块完整搬入 Mobile。每个模块只展示和操作自身业务，不以推荐、跳转或详情嵌套的方式联动其他业务模块。

## 领域边界

### 本变更内术语

- **待办**：个人运维告警入口，不是通用任务系统。由“我的告警”“未关闭”“高优先级”三个告警预设视图组成。
- **监控实例**：沿用项目共享术语，表示某个监控对象下可上报指标的具体实例。
- **我关注的资产**：当前账号保存在 Web 既有个人配置中的资产集合，不是 Mobile 本地收藏。
- **最近查看**：当前设备在 Mobile 监控模块内成功打开过的实例浏览历史；索引存本机 `localStorage`（按账号与团队隔离），不跨设备、不写 Server；Web 暂不同步。
- **业务 Tab**：待办、监控、资产、智能应用。`我的` 是登录后的基础入口。

这些 Mobile 局部术语不写入根 `CONTEXT.md`；共享术语“监控实例”已经存在。本变更不引入新的长期架构决定，因此不新增 ADR。

## 产品原则

1. 权限、许可、账号、语言、时区等平台行为必须与 Web 的当前真实逻辑一致。
2. Mobile 不自行推导一套 `mobile_capabilities`，不硬编码超级管理员或许可豁免。
3. 服务端仍是操作权限和数据范围的最终裁决者；隐藏入口不能替代 API 鉴权。
4. 原型中的固定数字、状态、指标名和模拟数据不是验收数据，界面必须由真实 API 和元数据驱动。
5. 若实现时找不到对应的 Web 事实、现有接口无法支持本文行为，或 Web 与本文发生冲突，必须暂停对应切片并向产品确认，不得静默新造规则、缓存、模型或跨模块替代路径。
6. 原型或新增规格未展示、但当前 Mobile 已经具备的能力默认保留；如需删除、降级或改变既有交互，必须先向产品确认。本次已确认保留 Mobile 时区设置。
7. 所有用户可见数据必须来自真实 API、元数据或 Web 已确认的既有语义。前端只允许做国际化、账号时区与区域格式化，以及本文明确约定的展示回退；不得以假数据、固定默认值、跨字段猜测、前端重算或硬编码状态/级别映射掩盖缺失或错误。字段含义、空值口径、枚举映射或 Web/Mobile 结果存在争议时，必须暂停对应实现并向产品确认，不得自行补齐或假定。

## 一级信息架构与导航

### Tab 可见性

一级 Tab 使用固定 Mobile 顺序，不跟随 Web 个人顶部菜单排序：

| Tab | 应用许可 | Web 菜单权限 | 操作权限 |
|---|---|---|---|
| 待办 | `alarm` | `Alarms`、`Alarms-View` | 轻处置另需 `Alarms-Edit` |
| 监控 | `monitor` | `view_list` | MVP 只读 |
| 资产 | `cmdb` | `asset_info` | 全局搜索入口另需 `search` |
| 智能应用 | `opspilot` | `bot_list-View` | 沿用 OpsPilot 服务端权限 |
| 我的 | 已登录 | 始终可用 | 具体资料更新沿用账号 API |

- 业务 Tab 只有在应用许可有效且映射菜单可见时才展示。
- 应用许可结果复用 Web `GET /core/api/get_client/` 的客户端清单及企业许可过滤结果，不由 Mobile 解析 `LicenseRecord`。
- 菜单权限解析严格复用 Web 的事实来源和过滤语义：
  - `GET /api/menu?locale=...`；
  - `GET /core/api/get_user_menus/?name=<client>`；
  - `GET /system_mgmt/custom_menu_group/get_menus/?app=<client>`；
  - 自定义菜单生效时沿用 Web 的自定义树、目录项、`isNotMenuItem` 与 `withParentPermission` 处理。
- Web 自定义菜单删除某入口后，Mobile 对应入口也必须消失。
- 许可或菜单正在加载、读取失败时按失败关闭处理：不短暂展示业务 Tab，仅保留“我的”。
- “我的”在可用性失败时不展示顶栏 Banner；进入该页可自动重试一次，回前台与下拉刷新也会再次拉取许可/菜单。账号菜单与退出始终可用。
- 账号资料（组织/角色等 enrich）加载失败时，在头像区局部提示，并用无框刷新图标提供局部重试，同时支持下拉刷新；不与可用性失败绑成并列 notice。
- 登录、应用重新进入前台和用户主动刷新时重新获取许可与权限。当前路由失去权限时立即执行安全回退。
- Tab 隐藏与直达路由守卫使用同一个可用性结果，禁止通过 URL 绕过入口限制。

### 默认页和记忆

- 账号首次进入时打开第一个有权访问的业务 Tab，固定顺序为待办、监控、资产、智能应用；若均不可用则打开“我的”。
- 后续按账号记忆最近访问的一级 Tab。记忆值只用于导航偏好，不改变权限判断。
- 记忆的 Tab 不再可用时，回退到第一个有权业务 Tab；仍无可用业务 Tab 时回退“我的”。

### 页面层级

- 五个模块根页展示底部 Tab。
- 告警、监控实例、资产等详情页和模块内搜索页隐藏底部 Tab，返回该模块上一级。
- 新增业务页面接入现有 `MobileNavigationProvider` / `useMobileBack` 和 Tauri 原生返回手势；iOS 等平台可从左边缘右滑返回上一级。
- 临时浮层、抽屉和弹窗优先消费返回动作，关闭后才执行页面返回。
- 直达详情且没有可恢复历史栈时，回退对应模块根页；若模块已失去权限，使用全局安全回退规则。
- OpsPilot `/conversation` 是明确例外：保留现有左边缘右滑打开会话历史抽屉的交互，不启用原生右滑返回，不在本 MVP 解决手势冲突。

## 模块一：待办

### 定位

待办是告警中心的 Mobile inbox，提供告警列表、模块内详情和单条轻处置。它不是“所有需要我处理的工作”的聚合页。

### 三个预设视图

三个视图互斥切换，但数据集可以重叠；它们是同一告警列表的不同服务端筛选条件：

| 视图 | 筛选契约 |
|---|---|
| 我的告警 | 当前账号数据权限可见，`operator` 包含当前用户名，状态为 `unassigned`、`pending`、`processing` |
| 未关闭 | 当前账号数据权限可见，状态为 `unassigned`、`pending`、`processing` |
| 高优先级 | “未关闭”范围内，使用当前告警级别配置中严重度最高的第一个级别 |

- 默认进入“我的告警”。
- 高优先级按 `level_id` 从小到大取第一个已配置级别；没有有效级别时显示空态，不硬编码“严重/错误”等显示文案。
- 告警级别继续调用 Web 使用的现有接口并由 `global_config-View` 鉴权；MVP 不新增告警专属级别接口、不放宽权限，也不在 403 时硬编码级别。读取失败只影响“高优先级”视图，并提供明确的无权限或重试状态。
- 列表统一按 `created_at` 倒序，分页大小 20，支持下拉刷新和触底加载。
- “我的告警”“未关闭”“高优先级”不是生命周期状态，界面不得做成可多选状态标签。

### 列表与搜索

- 告警卡片展示：级别、标题、状态、持续时间、处理人、资源名称或来源。
- 待办根页提供模块内搜索入口。搜索页可按标题、内容或告警 ID 查询，并沿用 Web 告警筛选和当前账号数据权限。
- MVP 不显示底部 Tab 未读角标；现有告警模型没有可直接复用的“未读”语义，不能以列表数量冒充未读数。三个预设视图可以使用当前筛选条件下列表接口返回的总数作为 Tab 旁数量展示，该数字表示匹配条数，不是未读数。

### 告警详情

详情包含三个同模块区段：

1. **摘要**：级别、状态、标题、告警 ID、持续时间、首次/最近事件时间、处理人、来源、通知状态、资源类型、资源名称、告警内容，以及当前允许的轻处置动作。
2. **事件**：仅展示该告警已有事件 API 返回的事件。
3. **变更记录**：只读展示分派、认领、转派、关闭等告警操作时间线，并按账号时区格式化时间。

变更记录继续调用 Web 使用的现有操作日志接口并由 `operation_log-View` 鉴权；MVP 不新增告警专属时间线接口。无该权限时只在变更记录区显示无权限状态，不影响摘要和事件读取。

同一告警中心返回的相关告警可以在详情内展示，点击后仍打开待办模块内的另一条告警详情。详情不嵌入监控图表、资产详情、日志证据、动作执行历史，也不提供跨模块跳转。

### 轻处置状态机

MVP 只支持单条操作，不支持批量处理：

| 当前状态 | 动作 | 前端可见条件 | 结果状态 |
|---|---|---|---|
| `unassigned` | 认领/分派 | 具备 `Alarms-Edit`，从 Web 同范围的有效处理人中选择 | `pending` |
| `pending` | 认领告警 | 具备 `Alarms-Edit`，当前用户在 `operator` 中 | `processing` |
| `processing` | 转派 | 具备 `Alarms-Edit`，当前用户在 `operator` 中，选择有效新处理人 | `pending` |
| `processing` | 关闭 | 具备 `Alarms-Edit`，当前用户在 `operator` 中 | `closed` |

- 所有动作必须由服务端再次校验操作权限、当前状态、处理人身份和数据范围，并处理并发状态变化。
- 关闭沿用 Web 当前确认交互，不把“关闭原因”设为必填；服务端现有默认描述可继续使用。
- MVP 不包含静默、屏蔽、策略修改、事件转事故、动作执行或重跑。

## 模块二：监控

> **架构约束**：最近查看为 Mobile 本机 localStorage，不跨设备、不写 Server。禁止新增 Monitor Server 表、`/monitor/api/recent_views/` 或依赖 CMDB `user_configs`；展示仍走现有实例查询 API resolve。

### 根页

监控根页提供两个互斥入口，Tab 顺序为 **最近查看 | 全部实例**，默认进入 **最近查看**：

- **最近查看**：展示本机最近成功打开过的监控实例，按 `viewed_at` 倒序，最多 20 条；同实例再次查看去重置顶。列表为 Editorial 简化行：左侧弱对象图标（品类锚点）、实例名主标题、右上查看相对时间、次行「对象名 · 上报状态色字」（正常绿 / 失联红）、有值摘要指标 2–3 条（全空则不渲染）。索引 `{ object_id, instance_id, viewed_at }` 存 Mobile `localStorage`（键按账号与团队隔离）；展示时复用现有实例 API 补全状态与摘要，无权限或已删实例静默过滤。
- **全部实例**：按监控对象浏览实例列表，行为与既有实现一致。

### 全部实例

- 结构沿用 Web 监控对象组织方式：`对象分类 -> 监控对象（实例数） -> 实例列表`。
- 对象树必须过滤 Web 中不可见的对象；选择监控对象后才请求和展示该对象实例。
- 搜索框只搜索当前选中的监控对象。现有实例搜索 API 以对象为范围，MVP 不伪装成跨对象全局实例搜索。
- Web 监控菜单中的“搜索”是指标查询能力，不等同于实例名称全局搜索，不能据此放宽 Mobile 权限或范围。
- 实例列表复用对象元数据定义的展示字段以及现有列表接口；优先展示实例标识、上报状态、最后上报时间和对象已配置的摘要指标，缺失字段不造默认值。
- 实例列表支持对象内名称搜索；上报状态列提供与 Web 同源的筛选：选项为 `normal` / `unavailable`，确认后以 `vm_params[status]` 传给现有 list 接口。多选两项或清空等同不过滤；切换监控对象时清除状态筛选。MVP 不包含枚举指标、IP、集群/节点等其它表头筛选。

### 实例详情

- 顶部展示监控对象、实例名称、真实上报状态和最后上报时间。不得因为原型写了“异常”就固定显示异常。
- 只有存在多个有效插件时才显示插件选择器；插件顺序和默认项与 Web 一致。
- 默认时间范围为最近 15 分钟；可选时间范围、起止时间计算和时区规则严格沿用 Web。
- 指标来源于有效插件和 Web 指标分组元数据，不硬编码“错误率、P95、QPS”。
- 每个指标展示单位和只读趋势图；小卡不展示当前数值（当前值仅在大图 Sheet 的数值轴/tooltip 中呈现）；按可视区域懒加载。
- 实例详情是短时查看页，不要求整页下拉刷新：切换时间范围会重查指标，单卡/大图失败提供重试；用户离开后再次进入详情即重新拉取。若实现下拉刷新，不得与横向切指标、Sheet 手势冲突，且不得作为唯一刷新入口。列表类页面（最近查看、全部实例）仍须提供下拉刷新。
- 点指标卡可打开页内大图 Sheet：沿用页顶时间范围与数据源；大图使用 ECharts（时间轴、网格、tooltip）；两侧箭头切换当前实例全部指标，无需跳页。小卡仍为轻量趋势剪影。
- 指标单位展示语义与 Web `findUnitNameById` 一致：查询返回的 `displayUnit` 优先覆盖单位字典；空单位族（`short`/`none`/`counts`）不展示；最终回退为 `unit_id` 原文，不另造 Mobile 专用百分比映射。
- 自动刷新默认关闭；如实现自动刷新，其开关和周期选项必须复用 Web 已有契约。MVP 不依赖停留页内的自动轮询来保证时效。
- 明确区分“对象/插件未配置指标”和“所选时间范围暂无数据”。
- 实例详情加载成功、非 403/404、且当前 Auth `userInfo.id` 已知时写入最近查看；复用页内已有 `useAuth()`，不额外请求账号接口，也不得用 `0` 占位键；403/404 不记录。
- MVP 不提供自定义看板、指标排序、策略编辑、监控关注，也不跳转告警、资产或日志。
- v1 最近查看仅 Mobile 本机写入与读取；不新增 Server 表或 API；Web 监控详情暂不写入同一份历史。

### 复用接缝

- `GET /monitor/api/monitor_object/?add_instance_count=true`
- `POST /monitor/api/monitor_instance/{objectId}/list/`
- `POST /monitor/api/monitor_instance/{objectId}/search/`
- `GET /monitor/api/monitor_instance/{objectId}/effective_plugins/`
- `/monitor/api/metrics/`
- `/monitor/api/metrics_group/`
- `/monitor/api/metrics_instance/query/`
- `/monitor/api/metrics_instance/query_range/`
具体 HTTP 方法、参数和响应结构以实现时的现有 Web 调用与服务端路由为准；最近查看索引存 Mobile `localStorage`，展示 resolve 仍走既有实例查询 API，不为统一外观额外包装第二套实例查询 API。

## 模块三：资产

### 根页和关注

资产根页顶部提供模块内全局搜索，并提供两个互斥视图：

- **我关注的**：默认视图。
- **全部资产**：按分类和模型浏览。

“我关注的”必须共享 Web 已有账号级配置：

- 配置键：`cmdb_followed_assets`
- 结构：`{ items: [{ model_id, inst_id, followed_at }] }`
- 上限：100 条
- 排序：`followed_at` 倒序
- 读取：`GET /cmdb/api/user_configs/by_key/cmdb_followed_assets/`
- 写入：`POST /cmdb/api/user_configs/update_key/`

列表与详情均可关注或取消关注。解析关注列表时只展示当前账号仍有数据权限且实例仍存在的条目；部分模型读取失败不能泄露或伪造条目。Mobile 不维护独立收藏表或本地收藏缓存。

### 全部资产

- 「全部资产」采用两级浏览：**分类落地 → 分类内工作台**。「我关注的」承担高频捷径，全部资产承担目录浏览，不在根页直接铺全库模型工作台。
- **分类落地**：列出当前用户可见分类；展示每分类下模型数与实例合计；点选进入该分类工作台。
- **分类内工作台**：同页切换，保留「资产」标题、双 Tab 与顶栏搜索条；Tab 下展示「‹ 全部分类」返回条与当前分类摘要，横向 chip 仅展示**当前分类**内模型；选定模型后同屏展示实例。禁止在实例列表内容区左右滑切模型。
- URL：`/assets?classificationId=&modelId=&modelName=`。仅有 `modelId` 时由客户端解析所属分类并补齐。无分类上下文时展示落地页。
- 默认模型：进入分类后优先恢复该分类下上次选择的模型；失效时取该分类内首个 `count > 0` 的模型，否则取首个可见模型。
- 从「全部」切到「我关注的」时暂存全部资产查询串，切回「全部」且 URL 无分类/模型参数时恢复，避免丢失浏览上下文。
- 按 `modelId` 缓存筛选关键字、列表与滚动位置；切换模型时优先恢复缓存并以非清空方式后台刷新。
- 模型显示实例数；分类、模型可见性和计数沿用 Web 的权限及接口结果。
- 实例列表支持模型内搜索、分页、下拉刷新。
- `/assets/model` 深链回跳到带 `modelId`（及可解析的 `classificationId`）的分类工作台。
- MVP 不包含“最近变更”视图。

### 资产全局搜索

- 搜索入口只有在 `cmdb` 应用下的 `search` Web 菜单可用时展示并允许直达。
- 搜索严格沿用 Web 两阶段流程：先请求 `/cmdb/api/instance/fulltext_search/stats/` 获取各模型命中数，再按选中模型请求 `/cmdb/api/instance/fulltext_search/by_model/`。
- 界面以模型选择器/标签展示命中数，默认选中第一个有结果的模型；一次只展示一个模型的实例，不混排不同模型。
- 筛选浮层提供“精确匹配”，默认关闭，参数语义与 Web `case_sensitive` 一致。
- 不增加 Mobile 搜索历史。Web 当前历史是浏览器本地能力，不能被描述为账号跨端历史。

### 资产详情

- 头部展示模型图标、模型名称、实例名称和关注/取消关注入口。
- 正文只读展示由模型字段元数据和字段分组动态生成的基础属性，各组可折叠。
- 不硬编码某类资产字段，不因空值创造展示值。
- MVP 不包含编辑/批量编辑、订阅、资源详情、Kubernetes 专页、关系拓扑、IP 视图、配置文件和变更记录，也不提供跨模块链接。

## 模块四：智能应用

- 保留现有 OpsPilot 工作台能力：应用分类与列表、应用搜索、会话历史、会话页。
- 复用现有 `/workbench`、`/conversations`、`/conversation` 页面及 `app_type=mobile` 的 OpsPilot API 契约，只把工作台接入新的五 Tab 一级壳。
- 工作台进入会话等全屏子页后隐藏底部 Tab，返回行为除会话页手势例外外遵循统一导航契约。
- 现有会话、消息和本地恢复状态必须保持兼容，不因壳层改造清空。
- 本变更不新增或依赖模拟“在线”状态，也不把仅本地的“接收通知”开关定义为服务端通知能力。
- 不增加从 OpsPilot 到告警、监控、资产的推荐或跳转；既有会话抽屉交互不变。

## 模块五：我的

### 账号资料

- “我的”对所有已登录用户可见，展示头像或姓名首字母、显示名称、用户名、域。
- 组织与角色按服务端真实身份只读展示；Mobile 不根据用户名或文案推断管理员身份。
- 允许编辑显示名称、语言和时区，沿用 Web 的账号字段、选项、校验和保存 API。
- 邮箱只读。MVP 不提供修改邮箱和修改密码，因为当前 Mobile 没有复用 Web 安全验证闭环。
- 保留 H5 和 Tauri 现有完整退出登录流程。

### 主题、语言和时区

- 深色模式与 Web 一致，属于当前设备本地偏好：保存在本机，不上传账号服务，不承诺 Web/Mobile 或多设备同步。
- 语言和时区属于账号级可编辑偏好，使用 Web 相同的字段、默认值、选项、规范化和服务端保存逻辑。
- 登录、偏好保存及重新获取账号信息后刷新 Mobile 的认证/用户偏好状态；Web 或 Mobile 修改后，另一端重新获取账号信息即可获得新值。
- Mobile 必须建立统一日期格式化入口，使用账号时区和当前语言，覆盖本 MVP 新增页面以及现有 OpsPilot 会话、历史和搜索时间。
- API 返回值只按其既有时间语义解析一次，不得先按设备时区转换后再次偏移。
- 现有语言快捷入口和账号详情入口可以并存，但必须读写同一账号偏好源。

## 通用加载、空态与错误契约

- 首次加载必须有稳定骨架或加载态，不先渲染无权内容。
- 列表区分首次加载失败、刷新失败、空数据和无搜索结果；失败态提供重试。
- 下拉刷新保留当前视图和筛选条件；权限刷新导致入口失效时优先安全回退。
- 详情返回 403 时展示无权反馈并提供回退模块根页的明确入口；返回 404 时展示对象不存在/已删除反馈并提供同样回退入口，不继续显示旧缓存详情，也不提供无意义的重试。
- 轻处置提交期间防重复点击；服务端返回状态冲突后刷新告警详情和列表，不用前端强行覆盖。
- 关注操作失败时恢复原状态并提示，不把未保存的乐观状态保留到下次进入。
- 文案全部进入现有 Mobile i18n，禁止新增只在中文下可用的业务判断。

## 明确不做

- 日志、运营分析。
- 跨模块联动、跨模块推荐、全局跨模块搜索。
- 告警批量操作、未读体系、底部 Tab 未读角标、静默/屏蔽、策略修改、动作执行。
- Web 监控最近查看同步、跨对象实例全局搜索、监控关注、自定义指标看板。
- 资产编辑、批量编辑、完整桌面详情、Mobile 搜索历史。
- Mobile 修改邮箱、修改密码。
- 推送通知或以本地开关模拟服务端通知订阅。
- 为最近查看新增 Mobile 专属权限体系；Monitor 最近查看仅使用 Mobile 本机 `localStorage`，不改实例 list/search 主链路，不新增 Server 表或 API。

## 验收场景

### 权限、许可与导航

- 同一账号在 Web 自定义菜单中移除 `asset_info` 后刷新 Mobile，资产 Tab 消失，资产直达 URL 被守卫。
- `cmdb` 许可无效但账号有菜单权限时，资产 Tab 仍不可见。
- 权限请求未完成或失败时不闪现业务 Tab；“我的”可进入，并以自动重试 / 下拉刷新恢复可用性，账号资料失败仅在头像区局部刷新重试。
- 最近一级 Tab 失权后重新进入，落到固定顺序中的第一个可用业务 Tab；全部业务不可用时落到“我的”。
- 新增详情页在支持的平台可右滑返回，浮层先关闭；OpsPilot 会话页仍右滑打开历史抽屉。

### 待办

- “我的告警”只出现当前用户是处理人的活动告警；切换“未关闭”后可出现其他有权活动告警。
- “高优先级”随服务端级别配置变化，不依赖中文级别名。
- 无 `Alarms-Edit` 的用户可以看有权告警但看不到轻处置动作；伪造请求仍被服务端拒绝。
- 关闭告警只确认，不要求输入原因；成功后从三个活动视图中按筛选规则消失。
- 告警详情不出现监控、资产或日志跳转。

### 监控

- 只展示当前用户在 Web 可见的对象分类和监控对象，搜索请求始终带当前对象范围。
- 「全部实例」上报状态列可筛选 `normal` / `unavailable`，请求写入 `vm_params[status]`；切换对象后筛选清空。
- 成功打开实例详情后写入本机最近查看（`localStorage`）；403/404 不写入；同实例再次查看置顶；超过 20 条时截断最旧记录；不跨设备同步。
- 最近查看行的上报状态与摘要字段语义与「全部实例」一致；右侧时间为查看时间而非最后上报时间；摘要仅展示有值字段，全空不渲染假 `--`。
- 实例详情根据插件和指标分组变化，原型中的固定三个指标不会无条件出现；小卡展示单位与趋势剪影，不强制展示当前数值。
- 实例详情可不提供整页下拉刷新：切换时间范围、失败重试或再次进入即可看到新数据；列表页仍须下拉刷新。
- 指标单位文案与 Web 同指标一致（含 `displayUnit` 覆盖与空单位族处理）。
- 在 Web 切换账号时区并由 Mobile 重新读取后，同一指标查询区间与 Web 的时间语义一致，并区分无配置与无数据。
- 最近查看仅在实例详情成功且当前账号 `userInfo.id` 已知时写入，不使用 `0` 占位键。

### 资产

- Web 关注资产后 Mobile “我关注的”可见；Mobile 取消关注后 Web 刷新也消失。
- 已关注但失权或删除的实例不会展示；关注配置中其他有效项仍正常显示。
- 全局搜索先显示模型命中数，选择模型后只出现该模型实例；精确匹配默认关闭。
- 无 `search` 菜单权限时仍可在有 `asset_info` 权限下浏览资产，但不能进入全局搜索。
- 详情字段组由模型元数据决定，且只读。

### 智能应用与我的

- 接入五 Tab 后，已有 OpsPilot 会话和历史不丢失，会话页手势行为不变。
- 语言或时区在 Mobile 保存后 Web 可读取相同值；在 Web 修改后，Mobile 重新获取账号信息可生效。
- 告警、监控、资产和 OpsPilot 时间均使用账号时区，不受设备时区切换导致的二次偏移。
- 切换深色模式只影响当前设备，不写入账号级偏好。

## 验证要求

- 权限解析纯逻辑覆盖许可、静态/自定义菜单、父级权限、加载失败、失权回退和直达守卫。
- Tab 记忆按账号隔离，测试非法/过期记忆值回退。
- 待办筛选与状态机覆盖全部状态、操作权限、处理人条件和并发失败刷新。
- 监控对象范围搜索、插件选择、指标分组、时间范围和两类空态有自动化覆盖。
- 资产关注配置规范化、100 条上限、排序、失权过滤和部分请求失败有自动化覆盖；两阶段搜索覆盖模型切换与精确匹配。
- 统一时间格式化覆盖不同时区、语言、无时区值及避免二次偏移。
- H5 与 Tauri 至少各完成登录、Tab 可见性、详情返回、退出登录的端到端冒烟；支持原生手势的平台补充返回手势人工验收。
- OpsPilot 现有会话流测试必须继续通过，并补充五 Tab 接壳后的回归用例。
