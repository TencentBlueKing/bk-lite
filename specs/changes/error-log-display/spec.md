# 错误日志列表、详情与导出

Status: draft

操作日志、登录日志、API 调用日志的展示已完成。本变更只改错误日志的查询页、读出脱敏和导出。不改组织归属，不加耗时、请求 ID、任务关联和相同错误聚合。

## 页面行为

错误日志仍在系统设置下的独立页，不并入审计日志页签。

列表在当前组织就绪后请求。组织 cookie 未写入时不发请求，避免 `GroupFilterMixin` 返回 403。

重置做三件事，使用同一组值：

- 筛选清空。用户名空，应用不选。
- 时间回到近 7 天。这个区间同时写入页面状态，并作为本次请求的 `time_start`、`time_end`。
- 时间选择器更换 `key` 后重新挂载，界面回到近 7 天。`TimeSelector` 没有 `reset()`，不调用它。

请求函数接收本次筛选和时间，不读取点击当时闭包里的状态。不使用 `setTimeout`。

## 列表与详情

列是时间、业务模块、错误信息、关联用户、操作。错误信息占主要宽度。关联用户仍是 `username`。列表去掉技术模块列。默认仍按时间倒序。

业务模块用控制台应用名。库存 `app` 与控制台 id 一致时直接翻译，例如 `monitor` 显示「监控中心」。`system_mgmt` 显示「系统管理」。中间件已经把 `operation_analysis` 写成 `ops-analysis` 的，显示「运营分析」。对不上控制台 id 的值显示库存原值。不改历史行。筛选「系统管理」时同时命中 `system_mgmt`。

错误信息只拆中间件当前的三行模板：

```text
[GET] /api/v1/monitor/alert_rule/
错误类型: ValueError
错误信息: node_id 必填
```

第一行是错误信息，第二行是异常类型、请求方法和路径。对不上这个模板的记录，展示脱敏后的已记录文本，不猜测方法、类型或原因。

每行有「详情」。点击错误信息打开同一个抽屉。数据来自列表行，不新增详情接口。现有 `retrieve` 保持 405。列表响应带上 `stack_trace`。

抽屉分四块：

- 基本信息：时间、关联用户、业务模块。
- 请求信息：请求方法、路径、技术模块。技术模块是库存 `module`。
- 错误信息：异常类型、错误原因、脱敏后的已记录文本。文本可复制。
- 堆栈：实际保存的堆栈，可复制。空字符串显示「未记录堆栈」。

拆不开的记录在方法、路径、异常类型、错误原因上显示「未记录」，已记录文本仍展示。

## 导出

导出对齐操作日志、登录日志和 API 调用日志。POST `export_excel`，权限 `error_logs-View`，查询走 `GroupFilterMixin`。勾选行传 `selected_ids`，否则使用与列表相同的筛选。超过 10000 行返回 400，不截断。

导出列：时间、关联用户、业务模块、错误原因、异常类型、请求方法、路径、技术模块、已记录错误文本、堆栈。拆不开的字段在导出里同样写「未记录」。

接口上已有的技术模块筛选保留，页面不展示。NATS `save_error_log` 的入参形状不改。它写入的自由文本按拆不开的记录展示。

## 搜索

关键词对整段 `error_message` 做包含匹配。中间件记录里的错误原因、异常类型、请求方法和路径都在这段文本里，都能被搜到。不搜堆栈。与用户名、应用、时间组合。

## 脱敏

通用要求里的「已修改」用于操作日志的敏感字段变更。错误日志没有修改前后的字段，敏感值按已确认的规则显示为 `****`。

列表、抽屉、复制和导出使用同一套遮罩。新写入去掉路径上的查询串。历史行不回写数据库，读出时遮。

字段名包含 `password`、`token`、`secret`、`api_key`、`authorization`、`otp` 时，对应值显示为 `****`。历史文本里残留的查询串值同样显示为 `****`。

导出在写入 Excel 前，对错误原因、已记录错误文本和堆栈再跑高置信正则，命中后替换为 `****`。只认四种形态：PEM 私钥块、`Bearer` 令牌、`eyJ` 开头的三段 JWT、URL 里的 `user:password@`。列表、抽屉和复制不跑这套正则。按当前中间件的短文本加 5 帧堆栈、10000 行上限测量，这套正则不改变导出耗时的可测结果。

明文要求只覆盖本项目会写入错误日志的内容。业务异常的文案是固定句子，不把口令、令牌或密钥的值拼进去。堆栈来自 `traceback.format_tb`，只有源码行，没有局部变量的值。会进入日志的敏感值是请求路径上的查询串，以及字段名命中上述名单时的对应值。不为本项目不会写入的密钥形态增加规则。不扫描任意长字符串，避免改写「node_id 必填」这类原因。
