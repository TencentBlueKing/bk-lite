# 编排中心智能体生成企微群通知

状态：已实现。

用户在智能体节点填写业务问题。若本次执行定义中，智能体的 `message` 输出仅作为企业微信群通知的完整正文使用，运行时向智能体说明读者是群成员，整条回答将直接投递。模型应给出一份可发送的结果；查询成功且结果为空时简短说明，查询失败时如实说明。

若输出还用于其他业务节点、作为拼接素材或流程的显式输出，智能体依原用途回答。用途判断来自本次执行快照，已有流程无需重新编辑提示词。

系统管理按现有企微 `markdown` 消息类型投递。来自编排中心的已验签正文可使用基础排版，包括加粗和引用。群成员提醒继续由渠道根据接收人及账号关联生成。
