# 工单中心列表工作台

## 用户要求与实现顺序
1. 个人列配置：复用 UserPreference，域与用户名隔离，支持恢复默认；默认列为单号、标题、状态、提单人、当前节点、创建时间，操作列固定为查看。
2. 服务端筛选和排序：状态多选、提单人、优先级、标签、时间区间、关键词；单号、标题、状态、提单人、创建/更新时间排序，稳定 ID 次序。
3. 分组：全部、我的待办、我发起的、我关注的、我的历史（有本人处理完成任务）；复用 TicketSavedView 保存筛选条件形成个人 Tab，结果随工单变化自动更新。
4. 批量：当前页勾选，确认操作和意见，支持关注/取消关注、提交、审批通过/拒绝、认领、催办、挂起/恢复；逐单权限、节点、表单校验，失败不妨碍其他工单，反馈每单结果。不跨工单复制表单，必填缺失时引导详情补齐。

## 数据与安全
- 个人配置仅使用认证身份，不能指定他人用户名或域。列/排序/分组条件使用白名单。
- 可见范围采用 EXISTS，避免任务、关注关系联表乘积。列表按需预加载待办任务、SLA、流程名，不加载历史任务及表单全文。
- 每页最多100，批量最多50；批量不自动重试已执行项，未知/越权 ID 统一提示不可访问。
- 保留现有列表 API 默认输出，新增 fields 供工作台显式请求列。

## 验收
- 不同用户和域配置隔离，刷新保留，恢复默认；保存与删除分组。
- 状态组合/时间/关键词筛选与跨页排序；我的历史与待办互不混淆。
- 最小列查询无任务/SLA加载；查询数随页面行数不线性增长。
- 批量含无权/失效/引擎失败项仍逐项返回；前端切换分组/分页清空选择，提交期间不可重复操作。
- 本地服务浏览器闭环与相关单测、类型/样式检查。
