# 工单详情交互完善

## 范围与布局

参考 ITSM4 详情页：紧凑页头显示状态、单号、标题和操作，第二行显示提单人、时间、流程、当前节点和处理人。返回入口按最新要求改为左箭头图标（保留无障碍名称）。流程入口改为页头下缘「流程图 + 箭头」，在表单上方同页展开独立流程区域，不使用浮层。左侧表单，右侧可收起协作区集中放置流转日志、评论、附件、满意度、关注与标签、关联。

## 行为

- 附件统一展示文件名、上传人、时间、大小和评论来源，可下载；只有上传人能删除，即使超管也不能删除别人附件。
- 评论支持对已有评论回复、图片预览与附件，上传成功后统一记录到附件列表。回复和文件引用限定在当前可见工单，不能引用其他上传人的未关联文件。
- 上传使用绑定工单与上传人的签名凭据登记对象，读取真实存储大小，限制 20 MB；下载短期签名并强制作为附件，图片仅预览 PNG/JPEG/GIF/WebP。
- 节点配置、工单状态、任务归属与菜单权限共同决定操作。前后端共用服务端授权结果，明确的空操作配置禁止所有节点任务操作。历史未配置 actions 的流程保留已有行为。
- 操作集中在页头；回退、转交、提交、驳回等通过确认弹窗填写意见。满意度改为页签，完成后提单人评分。
- 流程采用 BK-Lite 风格的浅高光渐变边框、圆角与微阴影区分状态，内部保持中性表面，无彩色填充：未到达灰色、已流转蓝色、接受绿色、拒绝红色、待处理橙色；不使用对勾图标，人员直接显示姓名，无前缀；可缩放、全屏，切换节点重新定位。节点显示处理人和时间。
- 日志按真实任务和自动执行记录显示步骤名、人员标签和时间；当前步骤补充待处理标签，隐藏操作前缀和意见说明，保留回退、重开等重复经过记录。
