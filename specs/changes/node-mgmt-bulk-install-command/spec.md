# 控制器批量安装命令

Status: implemented

## Problem Statement

节点管理员要给很多台 Linux 机器安装控制器。远程安装必须逐台提供登录凭据。手动安装必须先在页面填每台的 IP、节点名和组织，再复制一条绑死该台、30 分钟内最多使用 5 次的命令。Excel 导入只是批量填这张表，分发时仍然是一机一令。管理员希望用自己的 Ansible、跳板机或镜像初始化发同一条命令，每台只填自己的 IP。

## Solution

在控制器安装配置中增加「批量命令」，与远程安装、手动安装并列。管理员选择 Linux、控制器版本和当前组织，填写最多成功台数，得到一条命令。每台机器这样执行：

```bash
curl -fsSLk 'https://<云区域节点服务>/.../bulk_bootstrap?token=<批次令牌>' | sudo bash -s -- --node_ip 10.0.0.8
```

每台只改 `--node_ip`。云区域、组织、操作系统和控制器版本在批次令牌里。节点名用执行时读到的主机名。CPU 架构在机器上识别，x86_64 与 ARM64 共用这一条命令。

平台按「当前云区域 + `--node_ip`」受理。该 IP 正在安装，或列表里已经有这个 IP 的节点，命令失败并提示重复，带上已有节点名和 IP。安装失败或超时后占位释放，同一个 IP 可以再执行。装上的节点安装方式记为手动。

## User Stories

1. As a 节点管理员, I want 生成一条 Linux 批量命令并用 `--node_ip` 指定每台 IP, so that 我不用在页面填主机清单，也不用为每台复制不同命令。
2. As a 节点管理员, I want 本机没有该 IPv4、读不到主机名或该架构没有所选版本的安装包时这一台失败, so that 不会建出身份不对或包不匹配的节点。
3. As a 节点管理员, I want 正在安装或已经存在的 IP 提示重复并带上节点名和 IP, so that 重复执行不会装出第二台。
4. As a 节点管理员, I want 安装失败或超时后用同一个 `--node_ip` 再执行, so that 失败的机器可以重试。
5. As a 节点管理员, I want 查看这一批的受理进度并撤销未用完的命令, so that 我能区分装上、重复和失败，并停掉继续接入。
6. As a 节点管理员, I want 批量装上的节点按安装页勾选推送到 CMDB 和监控，并沿用手动节点的列表、导出和远程卸载, so that 纳管之后的处理与现在的手动安装一致。

## Implementation Decisions

### 入口与页面

- 批量命令和手动安装共用现有三步：安装配置、安装中、安装完成。不另开页面。
- 安装配置的上半部分三种方式共用：操作系统、控制器版本、同步到 CMDB / 监控。组织用当前组织。
- Linux 的安装方式为三项：远程安装、手动安装、批量命令。Windows 只有现有的远程安装和手动安装。
- 远程安装和手动安装保留现有主机表、Excel 导入和批量编辑。选中批量命令后，这一块换成最多台数、有效期和一条命令；命令在安装配置这一步复制。
- 批量命令不提供 CPU 架构选择。x86_64 与 ARM64 共用这条命令。
- 安装中沿用同一步。手动安装仍是事先列出的每一行，并按行复制命令。批量命令开始时没有行，机器执行后才出现 IP、节点名、架构和结果。
- 装完的节点在节点列表中的安装方式仍显示为手动。

### 命令

- 生成时固定：当前云区域、操作者当前组织、操作系统 Linux、所选控制器版本、成功台数上限、有效期。组织不接受请求中的其他值，服务端按当前组织写入。
- 成功台数从 10、50、100、500、1000 里选，默认 100。有效期从 1 天、3 天、5 天、7 天里选，默认 3 天。页面不提供手填。接口仍按小时保存，这四项分别是 24、72、120、168 小时。页面展示到期时间。
- 复制出的命令使用该云区域现有节点服务地址。命令参数只有 `--node_ip`。令牌、组织、版本不作为每台要改的参数。
- 命令正文只含批次令牌。NATS 安装凭据仍只出现在受理之后的单台安装会话里。单台会话继续使用现有 30 分钟、最多 5 次的限制。
- 生成和撤销使用与获取手动安装命令相同的节点编辑权限。

### 单台执行

- 引导脚本先在本机确认 `--node_ip` 是本机网卡上的 IPv4，并读到非空主机名，再向平台受理。平台看不见目标机网卡，唯一性以受理时声明的 IP 为准。
- 受理时平台生成节点 ID，节点名写为主机名，IP 写为 `--node_ip`，安装方式写为手动，组织写为批次组织。随后走现有控制器安装会话和安装器，不新增第二套安装过程。
- 用户选择的是控制器版本。执行时按本机架构解析同一版本的安装包：x86_64 可沿用现有的空架构包兜底，ARM64 必须有明确的 ARM64 包。解析不到时这一台失败，原因与「没有匹配的控制器版本」相同，其他架构继续。
- 批量受理不调用远程执行器，不保存 SSH 或 WinRM 凭据。
- 主机名允许重复。同一云区域里节点身份仍是 IP。

### 重复、占位与重试

- 判重范围是整个云区域，不限于同一批次。
- 以下情况命令以失败结束，并提示重复：该 IP 已有安装中的占位；该云区域已有这个 IP 的节点。提示包含 IP；已有节点名时一并包含。安装中尚未形成节点名时，说明该 IP 正在安装。
- 同一 IP 同时受理时，先拿到占位的继续安装，后到的提示重复。占位与已有节点互斥。
- 校验失败、重复、过期、撤销和台数用尽都不占用成功台数，也不创建节点。
- 只有受理成功才占住该 IP。安装失败，或超过与控制器安装任务相同的总超时预算仍未形成节点，占位释放，同一 IP 可以再次受理。
- 节点从列表删除后，该 IP 不再因为「已安装」被判重，可以再次安装。
- 成功台数用尽后，新 IP 被拒绝并说明台数已满；已存在或安装中的 IP 仍提示重复，不把满额说成重复。
- 同一批次累计失败尝试达到成功台数上限的 5 倍后停用。停用后新的受理被拒绝，已受理的安装继续收敛。操作者撤销后重新生成命令才能继续。

### 批次状态

- 批次状态：有效、已过期、已撤销、已停用。
- 进度行状态：安装中、已安装、重复、失败、超时。
- 进度页在有受理或被拒绝的尝试后展示 IP、节点名、架构和结果。不预填空行。
- 撤销、过期和停用都拒绝新的 IP。已经装好的节点保留。已经受理且仍在安装的机器继续，直到成功、失败或超时。
- 批次记录创建人、撤销人、台数、有效期和每次尝试的结果。这就是本能力的操作记录。

### 纳管之后

- 节点安装方式保持手动。列表筛选、导出和页面远程卸载不新增安装方式枚举。
- 安装页的 CMDB、监控勾选记在批次上。受理成功后交给现有的延迟推送；Sidecar 首次写下节点时消费。未勾选不推送。推送失败不删除节点，也不把安装改成失败。
- 受理之后心跳若更新地址或名称，沿用现有 Sidecar 更新规则。

### 接口边界

- 主机执行沿用安装器令牌通道。本变更不新增给第三方系统调用的 OpenAPI 网关端点。
- 生成批次、查看进度和撤销走节点管理的登录接口，并做组织隔离。其他组织不能查看、撤销或向该批次受理。

## Testing Decisions

好的测试只看外部行为：给出批次和 `--node_ip` 后，命令是否失败、进度行是什么、云区域里有没有新节点。不断言令牌缓存键或内部表结构。

最高缝是安装器的受理接口，以及它返回给引导脚本的结果。本机地址和主机名校验放在生成出的引导命令上，用现有「把安装命令交给 shell 执行」的方式验证。页面只验证批量命令入口、复制结果里含 `--node_ip`、进度能区分受理与重复。

先验是控制器手动安装接口测试、安装会话与引导命令测试、云区域 IP 唯一性测试。

必须覆盖：

- 新 IP 受理后节点出现，安装方式为手动，名称为主机名，IP 为参数值。
- 同一云区域已有节点，或已有安装中占位时，第二次失败且提示重复，节点数不增加。并发受理只有一个成功。
- 安装失败或超时后，同一 IP 可以再次受理。
- 台数用尽时新 IP 被拒绝，已有 IP 仍返回重复。
- 撤销、过期和失败尝试停用后，新 IP 被拒绝，已安装节点还在。
- 其他组织不能使用该批次。
- ARM64 没有对应版本包时该次失败，同版本 x86_64 仍可受理。
- 命令文本含 `--node_ip` 和批次令牌，不含 NATS 密码。
- 未勾选推送目标时不推送；勾选的目标沿用延迟推送，推送失败节点仍在。
- Windows 的远程安装和手动安装入口保持可用。

## Out of Scope

- Windows 批量命令。
- 不传 `--node_ip`、由平台自行猜测 IP。
- IPv6。
- 网段白名单、事先导入允许清单、安装审批。
- 把批量安装登记成新的安装方式枚举。
- 改远程安装或逐台手动安装的命令、凭据和令牌额度。
- 向 OpenAPI 网关暴露批次生成或受理。
- 撤销时中断已经开始的安装。

## Further Notes

- 有效期最长 7 天、默认 3 天，以及失败尝试 5 倍停用，是为了限制泄露命令的窗口和乱试次数而写入的边界。页面只提供固定的台数和天数，不手填。
- 目标云区域还没有所选版本在某架构上的安装包时，批量命令会在该架构上失败。这与安装页「没有匹配的控制器版本」是同一条件。
