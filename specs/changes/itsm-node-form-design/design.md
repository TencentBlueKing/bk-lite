# 表单模板与节点配置

已确认采用表单模板复制到流程、流程统一表单、节点控制字段权限的设计。

- 流程设计顶部可搜索选择表单，先只读预览，再复制。保留完整 schema 和来源 ID；保存时创建独立表单，不改源模板。
- 应用模板替换当前表单并清空节点字段权限，确认弹窗明确提示；已发布版本不允许直接替换。
- 节点配置分处理人、操作按钮、字段配置三个页签。
- 处理人支持指定人员、处理组、提单人、人员字段；支持单人、或签、并行会签、依次会签。引用人员字段需要提单时有值，后续提交按最新字段值重新解析。
- 操作按钮按节点类型筛选配置；实际执行继续叠加任务状态、办理人、操作权限检查。空列表必须保存，不回退为默认全开放。
- 字段显示名称、标识及分组树，支持搜索、全部设置、分组设置、节点必填；父级隐藏/只读约束子字段。表单固有只读、隐藏和必填约束保留。
- 节点预览复用实际 FormRenderer，不提交工单、不运行外部取数动作。
- 发布固定表单快照，校验字段引用及权限枚举；处理组解析限定当前域。
