# 流程表单模板与节点配置

Status: done

## 同一张表单在不同节点如何呈现

流程复制一份表单作为草稿。发布后，提单、审批、处理及重开办理都从工单所绑定的版本读取字段定义。节点配置决定用户在此步能看到什么、能改什么、提交时必须填写什么。选取新模板时先预览，再确认替换；当前草稿上针对旧字段的权限配置同时清空。[设计与历史验收](design.md)

| 操作情境 | 用户看到的结果 | 服务端验收 |
| --- | --- | --- |
| 提单时填写申请金额，审批时只读 | 审批人能读取先前填写的金额，不能在该节点编辑 | 提交审批意见时保留原金额；篡改只读值应被拒绝 |
| 配置某节点的必填字段，另一节点隐藏该字段 | 切换节点预览后，必填提示和字段集合随之变化 | 提交按当前节点及表单约束校验；隐藏或只读的父级限制应传递到子字段 |
| 将「同意」改名并调整顺序，启用必填意见 | 实际处理人看到配置后的按钮；仅有查看权限的人不获得办理入口 | 按稳定的动作标识校验权限和意见。批量办理同样拒绝空白必填意见 |
| 配置退回历史节点 | 候选项来自本轮实际办理且允许退回的节点 | 拒绝上轮历史、未经过的分支及跨并行汇聚的目标；直接提交目标 ID 也要验证 |
| 关闭所有可配置按钮 | 保存并重新打开后仍保持空选择 | 运行时不能将显式空配置解释为默认开放全部操作 |
