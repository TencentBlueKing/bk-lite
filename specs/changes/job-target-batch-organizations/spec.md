# 作业目标批量调整组织

## 操作范围

管理员可以勾选目标、跨页保留勾选，或显式选中当前筛选结果。筛选结果有多页时，表头复选框旁的菜单提供跨页全选和清除选择。勾选时表格位置固定。列表将本次选中的目标固定为 ID 集合。更换筛选条件或活动组织后重新选择。一次最多调整 1000 个目标，超出上限时提示缩小范围。

列表右上角「新建」左侧常驻「批量操作」。勾选目标后可展开「调整组织」和「批量删除」，两项分别要求编辑和删除权限。批量删除须先核对目标数量并确认。

## 组织变更

每次选择一个组织和一个动作。添加时保留原组织，已关联的目标无需变更。移除时保留其他组织，未关联该组织的目标无需变更。对于会失去最后一个组织的目标，弹窗列出名称，管理员可以取消操作，也可以明确排除这些目标后提交其余变更。

预览给出可变更、无需变更和需要排除的目标数量，并按调整前后的组织组合汇总。提交时校验相同范围的最新归属和操作权限。预览过期时需重新确认。目标归属、授权投影及相关实例授权规则同步更新。

## 作业模版

脚本库和 Playbook 库沿用按筛选结果勾选、预览组织变更和确认删除的操作。切换筛选条件或活动组织后重新勾选。脚本库将原有的批量导入、批量导出合并到「批量操作」，保留未勾选时从文件导入的入口。两库分别按各自的编辑、删除权限和所选模版的组织范围校验操作。

## 验收场景

- 100 个目标中筛选出 80 个。先勾选本页，再显式选中 80 个，给这些目标追加 A。
- 从 80 个目标移除 B，其中 52 个还属于其他组织、25 个未关联 B、3 个仅属于 B。排除最后 3 个后提交，恰有 52 个目标变更。
- 预览后目标归属改变、目标被删除或操作权限被收回时，整批提交失败。

## 验证结果

2026-11-26 在本机目标管理页面连接隔离的 SQLite 测试 API 完成浏览器验收。筛选生产目标后选中全部 80 个，展开查看 3 个仅属于待移除组织的目标，排除后成功移除 52 个目标的组织关联。随后向同一批目标添加该组织，新增 77 条关联，3 条已有。数据库核对确认筛选范围外的 20 个目标保留原归属。

2026-11-26 在本机前端连接测试机后端，用两个临时目标验证右上角操作。未勾选时「批量操作」禁用，勾选后可打开「调整组织」和「批量删除」。取消删除后仍选中两个目标，确认删除后接口返回删除 2 个，列表清空、按钮恢复禁用，数据库核对两个临时目标均已删除。

2026-11-26 在本机前端连接测试机后端，分别用 21 个临时脚本和 21 个临时 Playbook 验证跨页全选。两个库均预览并提交添加组织（20 条变更，1 条已有）和移除组织（21 条变更），取消批量删除后仍保留勾选，确认后各删除 21 条。脚本库从下拉菜单导出的 ZIP 含 21 个脚本，导回原组织时 21 个同名脚本全部跳过。
