# 环境安装包首版

目标：管理员导出环境专用单文件；两台目标 Linux 主机执行同一包，各自注册；重复执行不重装、不新增节点。

批准范围：实现既定产品化方案，以及 wx-test 虚拟机安装验证；不覆盖未知既有安装或删除测试资源。

测试接缝：网关安装申请/状态 API、单文件 CLI、Sidecar 首次上报。按行为用例进行红绿验证。

## 当前实现

- SystemAPIToken 仅允许两条统一网关端点：POST node-mgmt/environment-install、POST node-mgmt/environment-install-status。安装服务再次核对授权哈希、创建者、组织、区域、固定包摘要/版本、有效期、额度。
- 先锁云区域再锁授权，跨包地址预留也互斥；同 request_id 幂等，字段变化拒绝。节点删除后不允许旧授权静默重建。
- 首次心跳验证固定归属、install_id 和素材摘要回执。真实心跳使用单独 last_heartbeat_at；一般 Node 更新不能代替心跳。
- 管理员 API 复用节点 Edit 权限与当前组织校验；提供敏感文件导出、自己创建的授权列表、吊销、安装记录及失败阶段。客户端回报不能设置 registered_at。
- 新环境包使用请求头传递短期会话 Token；旧 query 参数兼容。凭据签发时重新持锁校验，存储 I/O 不占用该事务。
- 原生 Go 入口校验发布公钥签名及官方安装器摘要，使用严格 HTTPS/CA、拒绝重定向，持久化随机身份并加锁；未知安装/不同环境拒绝覆盖。调用官方安装器并等待本地服务及平台新心跳。
- 官方安装器验证素材 SHA-256，环境路径先暂存解包，校验后才停止服务/切换目录。Linux 脚本启动失败返回非零，配置限权，严格 TLS 并传递 CA。
- Web 入口位于节点列表，使用 Ant Design app-local 组件；有中英文文案。
- 必需托管组件选择写入授权及签名清单；不选可选组件时仍自动安装 NATS Executor 基础依赖。新环境注册仅分配所选默认配置；旧安装保持原逻辑。组件必须在新鲜心跳中上报正常状态 0；CLI 在组件未健康时保留注册成功，整体退出 70。此分支尚待 VM 故障注入验收。

隔离实测时环境安装迁移使用临时编号 0049，未部署生产。提交 PR 时对齐最新主干，正式编号为 node_mgmt 0050，依赖主干 0049_collector_default_backfill；已有临时迁移的隔离库不直接套用该迁移，需单独规划迁移记录转换。安装包发布构建与环境变量说明见 agents/environment-installer/README.md。原授权私钥仅由发布环境挂载，不提交源码。
