# 02 — 生成默认组并在两条链路上自动加入

Status: in-progress

Blocked by: 01 — 创建策略组并完成成员加入与退出

**What to build:** 某个组织第一次需要某个监控对象的默认组时，用该对象各采集插件的内置模板生成一套系统策略组并设为默认，只生成一次。没有内置模板就不建空组。之后只有节点管理新建、以及 CMDB 首次对上且还没有成员决定的实例，会自动加入。指标自动发现和升级前已有实例保持无记录。

- [ ] 每个组织、每个监控对象至多一个默认策略组；生成纳入该对象采集插件的内置模板，规则记住插件
- [ ] 没有内置模板时不生成空组，默认保持为空
- [ ] 用户尚未删除或改指向之前才自动生成；删除或改指向之后不再自动再生
- [ ] 节点管理新建，且无成员决定、无旧策略、只有一个所属组织时，加入该组织的默认组
- [ ] CMDB 首次对上且满足同样条件时加入；再次同步不改组
- [ ] 指标自动发现的新实例，以及升级前已存在且无成员决定的实例，保持无记录，不被批量补进默认组
- [ ] 一次带多个组织且没有明确选组时，记为未入组，不猜测组织
- [ ] 没有默认组时仍建立实例和采集，记为未入组；之后补上默认组也不再加入
- [ ] 已有旧策略的实例自动加入时记为未入组
- [ ] 没有策略编辑权限的人安装 Agent 或触发 CMDB 同步，实例仍能进入默认组
- [ ] 测试覆盖两条自动加入链路、排除自动发现和存量实例、多组织不猜测、无模板不建空组、无权限仍可加入

## Completion evidence

- `consider_auto_join` / `ensure_default` 已有服务测试：无模板、多组织、旧策略、只生成一次。
- 节点管理新建实例、CMDB 首次创建实例之后会调用 `consider_auto_join`。指标同步路径没有调用。
- 权限用例和无页面验收还没做，任务未完成。
