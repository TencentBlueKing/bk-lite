# 06 — 策略列表只保留旧策略和单独规则

Status: ready

Blocked by: 04 — 调整已接入实例的策略组

**What to build:** 策略列表只显示旧策略和单独规则，用来查看和停用。策略组里的规则不在这里出现。不能再从策略列表空白新建，模板页也不能再批量生成按实例复制的策略。单独规则只能在实例页先选中一台再补，并标明会和它所属策略组同时告警。

- [ ] 策略列表只有旧策略和单独规则
- [ ] 策略列表不再提供空白新建，模板批量应用不再生成按实例复制的策略
- [ ] 模板页仍可维护单条配方，并进入从模板创建策略组
- [ ] 实例页选中一台后可以补一条组里没有的单独规则
- [ ] 保存单独规则时标明它会和该实例所属策略组同时告警；未停用时两边都会告警
- [ ] 单独规则不作为接入和自动同步的默认路径
- [ ] 测试覆盖策略列表过滤、禁止空白新建和模板批量下发、实例页创建单独规则及并存提示
