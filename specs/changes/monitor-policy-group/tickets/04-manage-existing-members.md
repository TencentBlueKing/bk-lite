# 04 — 调整已接入实例的策略组

Status: done

Blocked by: 01 — 创建策略组并完成成员加入与退出

**What to build:** 在实例页和策略组的实例管理里，对已经接入的实例加入、更换或退出策略组。换组是离开原组再进入新组，原规则上尚未恢复的告警结束。采集从一种插件换成另一种时所属组不变，原插件规则停止覆盖并结束告警，新插件规则开始覆盖。旧策略仍生效时能看见是否仍会一起告警。停用在单策略列表的是否生效。

- [ ] 实例页按当前组织和监控对象列出所属策略组、成员状态，以及是否仍有旧策略或单独规则
- [ ] 实例页可单台或批量加入、更换、退出，只影响选中的实例
- [ ] 策略组实例管理可把已有实例加入这一组；已在别的组时先离开。列表上的实例数进入这一页
- [ ] 成员可退出，或换到同一组织、同一对象的另一组
- [ ] 退出、换组后，原规则上尚未恢复的告警结束
- [ ] 改采集间隔或采集项不改变所属策略组
- [ ] 采集插件从一种换成另一种，或再启用第二种时，成员关系不变，覆盖随当前插件变化，不再覆盖的规则结束该实例的未恢复告警
- [x] 未停用的旧策略标出仍会一起告警。停用在单策略列表的是否生效
- [ ] 能编辑该对象策略的人才能调整成员
- [x] 测试覆盖换组结束告警、换插件只改覆盖、旧策略并存与停用、组织隔离

## Completion evidence

- 更换采集插件后成员关系不变，原插件规则不再覆盖并结束未恢复告警。
- `policy_group/join` 与 `policy_group/leave` 供实例页和策略组实例管理调用。已有加入、换组、退出由 01 的成员服务完成。
