# 03 — 接入页为本次新建实例选择策略组

Status: ready

Blocked by: 02 — 生成默认组并在两条链路上自动加入

**What to build:** 接入页打开时带上当前组织该对象的默认策略组，并只预览当前插件在这组里的规则和阈值；其他插件的规则标明对这批实例不适用。确认前可以更换策略组或关闭加入。只有本次新建的实例按这个选择写入。关掉加入记为不自动入组，之后同步不拉回。

- [ ] 页面已选中默认组，表格能看到每条待接入实例将加入哪一组，或「不加入」
- [ ] 确认前更换只影响这批还没提交的实例，不修改默认组，也不挪动已在组里的实例
- [ ] 关闭加入后只写入采集，这些实例记为不自动入组；再次同步不拉回
- [ ] 本次没有采集的指标，对应规则标明不会有数据
- [ ] 接入时不填策略名称前缀，不逐条挑选模板，不填写通知人
- [ ] 接入页里已经接入过的实例，再次提交不改它已有的成员决定
- [ ] 更换策略组沿用接入权限
- [ ] 测试覆盖加入、更换、关闭加入、未采集提示、已有实例不被改组
