# 05 — 修改规则、复制组和管理默认组

Status: done

Blocked by: 02 — 生成默认组并在两条链路上自动加入

**What to build:** 能修改一条规则的阈值、条件和通知人，只影响它当前覆盖的成员，并结束按旧条件还在告警的事件。能复制策略组、把规则另存为模板。能把另一组设为默认，或删除策略组。删除默认组后，新来的实例不再自动告警。

- [ ] 改阈值、条件或通知人后，仅该规则当前覆盖的成员按新规则检测；正在告警的事件结束。其他插件的成员、模板库和其他组不变
- [ ] 可以在规则上补选本环境的通知人；不设组级统一通知人
- [ ] 复制得到独立规则副本，不带走成员，也不成为默认组。两组之后改阈值互不影响
- [ ] 另存为模板只增加模板库的一条，当前组和其他组不变
- [ ] 从模板创建时模板按插件分组，可以只选某一个插件的规则
- [ ] 把另一组设为默认后，只影响之后新来的、还没有成员决定的实例
- [ ] 删除策略组后，原成员不再按该组告警，并记为不自动入组，未恢复告警结束
- [ ] 删除的是默认组时，该组织这个对象不再有默认组，之后新实例只采集、不自动告警，直到另指定默认组。其他组织不受影响
- [ ] 改规则、设默认、删除组需要策略编辑权限
- [x] 测试覆盖改规则的影响范围、复制独立、删除默认组后的自动加入、权限拒绝

## Completion evidence

- 改规则只改当前规则并结束其未恢复告警；复制不带成员；删除默认组后不再自动生成。
