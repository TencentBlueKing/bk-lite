# 05 — 修改规则、复制组和管理默认组

Status: done

Blocked by: 02 — 生成默认组并在两条链路上自动加入

**What to build:** 能修改一条规则的阈值，只影响它当前覆盖的成员，并结束按旧阈值还在告警的事件。无数据等条件保持创建时从模板复制的值。通知方式和通知人在策略组上设置一次，写入组内每条策略，不因此结束未恢复告警。能复制策略组。能把另一组设为默认，或删除策略组。删除默认组后，新来的实例不再自动告警。

- [x] 改阈值后，仅该规则当前覆盖的成员按新阈值检测；正在告警的事件结束。其他插件的成员、模板库和其他组不变。无数据等条件不在组里修改
- [ ] 在策略组上保存通知方式和通知人后，组内每条策略写成同一套；未恢复告警不结束。其他组不变
- [ ] 复制得到独立规则副本，不带走成员，也不成为默认组。两组之后改阈值互不影响
- [ ] 从模板创建时模板按插件分组，可以只选某一个插件的规则
- [ ] 把另一组设为默认后，只影响之后新来的、还没有成员决定的实例
- [ ] 删除策略组后，原成员不再按该组告警，并记为不自动入组，未恢复告警结束
- [ ] 删除的是默认组时，该组织这个对象不再有默认组，之后新实例只采集、不自动告警，直到另指定默认组。其他组织不受影响
- [ ] 改规则、设默认、删除组需要策略编辑权限
- [x] 测试覆盖改规则的影响范围、复制独立、删除默认组后的自动加入、权限拒绝

## Completion evidence

- 改规则只改当前规则并结束其未恢复告警；复制不带成员；删除默认组后不再自动生成。
