# 监控策略组

Status: ready

## Problem Statement

运维接入一个监控对象时，要让这批实例按一套告警规则生效。现在接入页要逐条挑选策略模板、填写名称前缀，并决定是否推送告警中心。模板页把同一对象的规则拆成许多卡片，策略页再看到按实例复制出来的一条条策略。节点管理或 CMDB 同步过来的实例没有人在接入页上操作，往往只有采集、没有告警。

## Solution

把「一整套告警」收成策略组。实例加入一组，组里的规则一起生效。策略模板仍是单条规则的配方库，用来组建新的策略组，不直接套到实例上。每个组织的每个监控对象可以有一个默认策略组，供没有人在接入页上选择的新实例使用。

加入是同一个动作，出现在三处：接入页决定本次待接入实例，实例页决定已经接入的实例，策略组的实例管理决定这一组的成员。一台实例同时只属于一个策略组。

## User Stories

1. 作为运维，我在插件接入页填写采集和实例后，默认加入该对象在当前组织的策略组，就能一次让组内规则对这批实例生效。
2. 作为运维，我在确认接入前可以更换要加入的策略组，或关掉加入，让这次只做采集、不产生这批告警。关掉加入会被记住，之后的同步不再把这些实例拉进默认组。
3. 作为运维，我在接入前能看到将生效的规则和阈值。某个指标这次没有采集时，能知道对应规则不会有数据。
4. 作为运维，我在策略组里调整一条规则的阈值后，已经加入该组且被这条规则覆盖的实例一起按新阈值检测。正在按旧阈值告警的事件结束，再按新阈值判断。无数据等条件保持创建时从模板复制的值。通知方式和通知人在策略组上设置一次，写入组内每条策略，不因此结束未恢复告警。
5. 作为运维，我可以从策略模板里勾选若干条，在当前组织创建一套新的策略组。新组没有成员。
6. 作为运维，我可以复制一套已有策略组再修改。副本不带走原组成员，规则是独立副本。
7. 作为运维，我可以为本组织的每个监控对象指定一个默认策略组。节点管理新建的实例，以及 CMDB 首次对上、且还没有成员决定、也没有旧策略的实例，自动加入该组织这个对象的默认组。
8. 作为运维，我改默认策略组后，只影响之后新出现、且还没有成员决定的实例。已经加入、退出、关闭加入，或首次出现时没有默认组的实例，后续同步不改变它的策略组。
9. 作为运维，当某个对象没有默认策略组时，同步仍建立监控实例并完成采集，只是不加入告警。
10. 作为运维，我在实例页给已经接入的实例加入或更换策略组，或让它退出。只影响选中的实例。
11. 作为运维，我在策略组的实例管理里把已有实例加入这一组，或把成员退出、换到另一组。实例若已在别的组，加入时先离开原组。
12. 作为运维，我仍在策略模板页维护单条规则。模板本身不使任何实例告警。改模板不改变已经建成的策略组。
13. 作为运维，我仍能看到切换前按实例复制的旧策略，以及不在组里的单策略。一条单策略可以覆盖一台或多台实例。它们继续按原范围告警，直到我在单策略列表关掉是否生效。未停用时会和策略组同时告警，实例页和策略组实例列表标出并存。

## Implementation Decisions

### 生效模型

- 生效单位是策略组，不是单条策略模板，也不是按实例复制出来的策略。
- 组内每一条规则对应一条现有监控策略。策略的实例范围等于该组当前成员。成员变化时更新这一条策略的实例范围，不为每个成员再复制一条策略。
- 告警、事件、无数据、调度和通知继续走现有监控策略。策略组不另做一套检测引擎。
- 组内规则从模板复制配方后与模板库断开。模板同步下发不得更新这些策略。
- 通知方式和通知人在策略组上设置，保存时写入该组全部规则对应的监控策略。接入和加入成员时不填写通知。只改通知不结束未恢复告警。
- 策略组可以整组停用或重新生效。停用写入组内每条策略的启用字段，停止扫描并结束尚未恢复的告警，不改变成员。重新生效从当前时间继续扫描。默认组停用后仍接受新成员，但在重新生效前不告警。
- 修改规则配方后，沿用现有「配方变化则结束未恢复告警」的行为，再按新条件检测。
- 实例退出、换组或删除组时，从原规则的实例范围移除，并结束该实例在这些规则上尚未恢复的告警。采集配置保持不变。
- 实例刚加入且从未上报时，不因无数据立刻告警。曾经上报过又中断，才按规则上的无数据配置告警。
- 同一条规则在同一组只有一份。复制策略组时复制出新的规则和新的监控策略，阈值之后互不影响。

### 成员状态

每台监控实例至多一条成员决定。状态：

| 状态 | 含义 | 自动同步 |
| --- | --- | --- |
| 无记录 | 还没有人做过加入决定 | 可以加入当时的默认组 |
| 在组 | 属于某一个策略组 | 不改组 |
| 不自动入组 | 接入时关闭加入、用户退出，或所属策略组被删除 | 不拉回 |
| 未入组 | 第一次出现时没有默认组，或当时已经有旧策略 | 不重新匹配 |

- 一台实例同时只属于一个策略组。换组是离开原组再加入新组，两次写入在同一个事务里完成。
- 加入时若实例上仍有旧策略或单独规则，两边都会告警。接口和页面返回并存标记，不自动停用另一边。
- 成员决定以监控实例为主键。实例后来又挂到其他组织时，不因此再加入另一个策略组。
- 自动加入使用实例创建时所写入的那一个组织。接入页使用操作者当前组织，只列出该组织下、该监控对象的策略组。节点或 CMDB 创建实例时若带了多个组织，不猜测，记为未入组，由用户在实例页选择。
- 删除监控实例时删除成员决定，并结束相关告警。CMDB 只解除关联、实例还在时，成员决定不变，告警继续。

### 默认策略组

- 每个组织、每个监控对象至多一个默认策略组。默认是指向某一策略组的指针，不是模板，也不是组上的一个可重复标记。
- 某个组织第一次需要该对象的默认组时，用该对象的内置策略模板生成一套系统策略组，并设为默认。没有内置模板时不生成空组，默认保持为空。
- 这次生成只发生一次。用户删除默认组、或把默认指到别的组之后，不再自动生成另一套系统组。
- 系统组可以改规则。改动只落在这一组的规则副本上，不回写内置模板，也不影响其他组织。
- 自动加入只发生在两条链路上：节点管理新建监控实例，以及 CMDB 首次把一条还没有成员决定的监控实例对上。指标自动发现新增实例不加入策略组。
- 接入页提交时带有明确选择：加入指定策略组，或不自动入组。这条路径不走「看看有没有默认组」。
- 装 Agent 或 CMDB 同步的调用方可以没有策略编辑权限。系统仍按该组织的默认组写入成员。改规则、设默认、删除组需要该监控对象的策略编辑权限。接入页更换策略组沿用接入权限。

### 三处入口

- 接入配置：用策略组选择替换逐条模板、名称前缀和接入时的告警中心开关。提交前可更换或关闭。表格展示每条待接入实例将加入的组。未采集的指标在规则旁标明这次没有数据。
- 实例列表：按当前组织和监控对象列出已接入实例，展示所属策略组、成员状态和是否仍有旧策略或单独规则。支持单台或批量加入、更换和退出。
- 策略组实例管理：列出这一组的成员，可加入已有实例、更换到其他组、退出，并看到成员上的旧策略是否仍在告警。停用旧策略在单策略列表完成。策略组列表上的实例数进入这一页。

策略、模板页面保留。单策略页列出不在组里的策略，可以查看、新建，并用是否生效停用。模板页继续维护单条配方，并提供「用于创建策略组」。

### 接口

成员关系只由一个应用服务写入。接入、实例页、策略组实例管理和两条自动加入链路都调用它。

- 列出某组织某对象的策略组，标出哪一个是默认。
- 创建、复制、删除策略组。创建来自所选模板。复制不复制成员。
- 读取和更新组内规则的阈值。更新写入对应监控策略。
- 设置默认策略组。
- 变更成员：加入指定组、退出、或不自动入组。支持一批实例。返回离开的原组和仍并存的旧策略。
- 接入提交在创建或复用实例的同一事务内写入成员决定。
- 查询实例时附带成员状态、所属策略组和并存策略数量，供实例页和策略组实例管理使用。

组织从调用方的当前组织取值，不信任请求体里单独传来的组织作为越权范围。实例必须属于该组织才能加入该组织的策略组。

### 初始化与迁移

- 不把现有按实例复制的策略收进策略组，也不自动停用。
- 已有实例不批量写入成员决定。它们保持无记录，直到下一次允许自动加入的链路碰到它们，或用户在页面上选择。为避免指标同步误触发，只有节点管理新建和 CMDB 首次对上会调用自动加入。
- 内置模板仍由现有插件初始化对账。策略组生成读取已经对账好的内置模板，不在启动临界区调用未就绪服务。

## Testing Decisions

测试成员服务的外部结果：成员状态、策略实例范围、告警是否结束、默认指针和模板是否被改写。不测试私有函数的调用顺序。

必须覆盖：

- 接入加入、接入关闭、确认前更换，以及关闭之后再次同步不再入组。
- 节点新建和 CMDB 首次对上加入默认组；再次同步不改组。
- 无默认组时实例和采集仍在，成员为未入组，之后补上默认组也不再加入。
- 已有旧策略的实例自动加入时记为未入组。
- 换组后实例只出现在新组的策略范围里，原组告警结束。
- 改规则只影响该组策略，不改模板，也不改其他组的副本。模板同步不下发到策略组规则。
- 删除默认组后新实例不再自动加入。
- 一个实例不能同时属于两个组。跨组织不能加入另一个组织的策略组。
- 无策略编辑权限时，同步仍可按默认组加入；改规则和设默认被拒绝。

先前的策略创建、模板可移植和告警生命周期测试保持通过。策略组规则不进入「按模板同步已下发策略」的用例。

## Out of Scope

- 按磁盘、网卡等子对象自动铺开规则。
- 在接入时按实例勾选要采集的指标子集。
- 打开 CMDB 自动创建监控实例。本期只规定：节点管理新建，或 CMDB 首次对上一条还没有成员决定的实例时如何加入默认组。
- 指标自动发现的新实例自动加入策略组。
- 自动把旧策略收进策略组，或自动停用旧策略、单独规则。
- 在策略组里把规则另存为模板。自定义模板在模板页维护。
- 在策略组里修改无数据等条件。组内只改阈值。
- 在实例页新建单策略，在策略组实例列表展示如何加入，或在这两处停用旧策略。旧策略的停用使用单策略列表的是否生效。
- 某一条规则单独设置通知。通知在策略组上设置，并写入组内每条策略。
- 插件升级后把新的内置规则合并进已经生成的策略组。

## Further Notes

原型已确认三处入口、默认组的用途，以及「关闭加入和退出都会记住」。多组织实例自动加入时不猜测组织：创建时只有一个组织就用它，接入页用当前组织，多个组织且没有明确选择则记为未入组。
