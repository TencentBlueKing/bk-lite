# 运营分析仪表盘页面问答

Status: in-progress

## Problem Statement

运维人员在运营分析里打开自己拼好的仪表盘时，右侧智能问答仍然看不见这张盘。筛选、卡片标题、趋势、排行都要靠人复述。监控专业仪表盘已经能把当前页快照带进同一套全站问答；运营分析仪表盘还没有接上。用户要的是对着已打开的盘问「现在怎么样」和「这张卡是什么意思」，不是再做一个聊天窗口，也不是让问答帮人搭盘。

## Solution

运营分析仪表盘按全站页面问答对接规范接入：用户在工作台查看或全屏该盘时提问，智能问答自动带上当轮页面快照。快照只读当前已渲染的屏幕，不另打业务接口，不改看盘界面。拓扑等未接入画布保持裸聊。公共上限沿用全站框架（约 8K 字、最多 6 张缩略图、约 2 秒采集、单图过大丢弃），本期不放宽。

## User Stories

1. As an 运维人员, I want 在运营分析仪表盘的正常查看和全屏下直接问「这张盘现在怎么样」, so that 不必把筛选、卡名和数字手动复述给智能问答。
2. As an 运维人员, I want 说出某张卡片的标题后得到针对该卡的回答, so that 我盯着某一张图或数字时不必先听无关总览。
3. As an 运维人员, I want 点名的卡即使没进当轮 6 张缩略图也能用卡名和数字得到回答, so that 盘很满时问答不会假装这张卡不存在。
4. As an 运维人员, I want 总览用到当前看得见的表和 TopN 前几行, so that 以排行为主的盘不会被说成只有几张趋势图。
5. As an 运维人员, I want 改完统一筛选再提问时答案跟新窗口走, so that 机器人不会复述上一问的旧时间或旧对象。
6. As an 运维人员, I want 部分卡片还在加载时问答明确还有组件未就绪、且不把空白当成零, so that 总览不会系统性说错。
7. As an 运维人员, I want 空盘仍能被问出「这是哪张盘」, so that 没有图时也不会编造指标。
8. As an 运维人员, I want 打开拓扑、大屏、报表等未接入画布时仍是普通聊天, so that 不会把仪表盘的截图规则套到别的画布上。

## Implementation Decisions

- 第一期只接运营分析**仪表盘看盘**：工作台 `/ops-analysis/view` 且查询参数 `type=dashboard`。全屏与查看同一张盘、同一套筛选，必须采集。内置盘与自定义盘同等交付。
- 不新做问答 UI。继续用全站智能问答；发送前采集、快照进当轮 `page_context`、不写入会话历史、点名图表时由服务端收窄——全部复用已有框架，不改 GlobalWebchat，不改 skill_channel 注入，不放宽图片/文本预算。
- 采集用页面旁路 pilot：与仪表盘页同目录，导出 `getMessage` / `getContext`（及可选 `getTextContext`），只读 URL、DOM 与通用图表截图工具。默认不改仪表盘业务组件的可见展示。表选择关闭态仍显示「已选 N 项」；仅允许把已选标签写入 rest tag 的 `title` 供采集读取。弹窗打开时读勾选行，跳过 checkbox 列。登记走现有 `*.pilot.ts` codegen；路径前缀会落到 `/ops-analysis/view/`。看盘实际 pathname 是 `/ops-analysis/view`（无尾斜杠），由 `matchPilots` 补尾斜杠后再匹配该前缀；**闸门仍只在 pilot 内看 `type=dashboard`**，不把闸门写进 codegen。否则拓扑等会误采。非仪表盘返回空快照（裸聊）。
- `getMessage().title` 用盘身份，不用 URL 整段当缓存键。约定：`ops-analysis-dashboard:` + 查询参数里的画布 `id`。`currentTime` 必须随统一筛选文案（含时间窗）和当前看得见的数据指纹变化；右上角自动刷新间隔不是查询时间窗，不能单独当指纹。省略 `currentTime` 视为每轮重采。
- 只采集当前屏幕已渲染内容，不额外请求数据源。数据范围等于用户已经能看见的内容（含其权限下已查出的数），不扩大权限。禁止采集凭据、token、密钥。
- 文字与图片是两条通道。文字用于盘身份、筛选、全部看得见的卡片标题、单值数字、表/TopN/多值/卡片列表可见行、图名说明，以及卡片的加载/失败/空态文案；图片只给真正的趋势/分布图。折线背后是密集时序，整表 dump 会撑满模型上下文并把盘名/筛选挤掉，所以不喂原始序列。TopN 若有表头 grid，采集跳过表头、读后面的数据行。表选择类筛选关闭时往往只显示「已选 N 项」：控件把已选标签写在 rest tag 的 `title` 上供采集；弹窗打开时读勾选行。
- 文本合计沿用全站约 8K 字符预算。超预算时整段按优先级丢弃，顺序固定为：① 盘身份 + 当前筛选；② 看得见的全部卡片标题 + 单值当前数字；③ 当轮已截图的图名说明；④ 每个表 / TopN / 多值 / 卡片列表当前看得见的前 10 行（含列名）。表行可以少抄，不能把盘身份挤掉。
- 缩略图沿用全站最多 6 张、约 600px JPEG、单张过大（服务端约 500KB base64）丢弃。这不是某家模型 API 写死「只能收 6 张」，而是采集耗时（整轮约 2 秒超时）、上下文/费用和请求体膨胀的公共预算。超时或失败不得挡住发消息。
- 进入 6 张名额的图：折线、柱状、饼图、仪表盘、雷达，且不是装饰性小图。不截：单值旁 sparkline、表格、TopN、卡片列表、事件表、拓扑/节点图/3D、仍在加载、被分组折叠藏起来的卡。其余按画布阅读顺序（从上到下、从左到右）截满 6 张。卡片标题从卡片外壳读取并写进 caption；option 里的通用「图表」占位不单独拼进说明。
- 点名卡片：服务端仍只在**当轮已带上的图**里收窄。未进 6 张的卡靠文字兜底，不在本期做按问题补截。
- 加载中的卡跳过数字和截图，卡片行写「加载中」，并在文字中写明还有 N 个组件未加载完。查询失败、空态把屏幕上的文案带进卡片行，失败另计数量；不把空白当成零。空盘只带盘名和筛选，images 为空。
- 编辑中、分享链接不作为验收路径：不必为关闭采集去改业务页；分享是另一条路由，codegen 前缀也不会误匹配查看页。未开启多模态的模型由现有服务端丢图留文字和图名，本期不单独处理。

## Testing Decisions

好测试只锁对外契约：给定 DOM/URL 时 `getMessage` / `getTextContext` / 纯筛选函数的返回值（title、currentTime、sections 内容与优先级、哪些节点算可截图、阅读顺序取前 6、表行条数、加载中跳过）。不测 JPEG 像素、不测真实 ECharts 出图、不测 GlobalWebchat、不测 skill_channel、不测 LLM 回答质量。

最高接缝优先用导出的纯函数 + jsdom 夹具，对齐监控仪表盘 page-context pilot 单测（标题回填、装饰图跳过、筛选指纹、`getTextContext` 含 KPI 文案）。需要锁定的行为：

- `type` 不是 `dashboard` 时不产生页面快照；`type=dashboard` 时 title 含画布 `id`
- 统一筛选文案变化则 `currentTime` 变化；仅刷新间隔变化不充当时间窗；多值/卡片列表可见行变化也必须让 `currentTime` 变
- 单值 sparkline / 过矮节点不计为可截图；有标题的折线等计入，并按阅读顺序取 6；caption 不含孤立「图表」占位
- 文字含全部看得见的卡名和单值；每个表/TopN/多值/卡片列表最多 10 行；超预算时身份/筛选仍在、表行可被裁掉
- 带加载态的卡不进入数字/截图，且文案含未加载数量；失败/空态带上屏幕文案；表选择「已选 N 项」能展开已选对象（关闭态 rest-tag `title`，弹窗勾选行跳过 checkbox 列）；多值与卡片列表按行抄（卡片列表 trailing 取最后一个 `.text-xs.font-medium`）；空盘无 images、仍有盘名

codegen 路径前缀接缝复用现有 `generate-ai-pilots` 单测：运营分析仪表盘 pilot 文件位置应推导为 `/ops-analysis/view/`。`type=dashboard` 闸门在 pilot 内测试，不把闸门写进 codegen。

手测（不替代单测）：查看态提问请求带 `page_context`；拓扑页不带；改筛选后 Console 指纹变化；点名单图时服务端只留匹配图（沿用页面问答现有日志）。

## Out of Scope

- 搭盘助手、解释如何配置数据源或组件
- 拓扑、架构、大屏、报表、网络拓扑的页面快照
- 编辑中与分享链接的验收承诺
- 放宽 6 张 / 8K / 2 秒 / 单图大小，或按用户问题补截
- 表格翻页后未渲染的行、全量接口 dump
- 新问答 UI、改 GlobalWebchat 或后端注入
- 让问答执行 ping 等操作（沿用现有智能体安全限制）
- 为对接而改仪表盘可见展示或把筛选写入 URL（rest tag 的不可见 `title` 除外）

## Further Notes

产品范围是「看盘」，能力限制来自全站页面问答，不是运营分析单独抠的。密集时序不能当数字整表送进模型；每轮快照不进历史，是为了筛选一变旧图立刻作废。非多模态模型会丢图留 caption，趋势变弱但盘名、筛选、单值和表行仍在——这是模型能力，不代表没接上。

对接写法以页面问答 app 接入规范为准；监控专业仪表盘 pilot 是参考实现。大屏、拓扑、分享页、按点名补截若要做，另开变更并重新评审公共预算。
