# 编排中心智能体附件

智能体生成文件后，本次节点执行输出 `artifacts` 引用列表。每项包含执行附件 ID、文件名、格式和大小。执行详情按本次执行展示文件并提供下载。后续节点通过画布选择器引用附件，文件字节保存在对象存储。

对外通知允许选择上游智能体的附件列表，也支持已有文档节点的单个附件引用。发送前按执行和组织查找有效附件，使用登记的名称与内容。正文提供带文件名的限时下载链接。企业微信群机器人先发送正文，再上传文件并逐个发送原生文件消息。附件超出渠道限制或投递失败时，已送达的正文和链接仍然可用。

验收覆盖同一节点生成多个文件、没有生成文件、重试处理、跨组织及跨执行引用、执行详情下载和签名链接下载。企微上传与发送通过模拟接口验证。

编排中心智能体每次执行最多等待 10 分钟，覆盖规划、工具调用和总结。达到时限后取消尚在等待的异步步骤，流程不再进入后续通知节点。

智能体回答直接作为企微群通知正文时，节点按单向通知执行。分步分析中的编号列表不会中断附件生成，生成文件的步骤须有附件工具的成功结果。群通知不接受等待收件人选择的编号问句，工具审批仍按原触发方式处理。

企微群通知的分步执行单独汇总群正文，正文里的 Markdown 数据表按行展示。用户明确要求制作报告时，节点须取得本次执行已登记的附件才能成功并进入通知步骤。
