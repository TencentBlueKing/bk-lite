# 节点管理 Agent 状态筛选与跨页勾选

Status: implemented

## Problem Statement

运维在节点清单里已经能看见 Sidecar 在线/离线和托管程序状态，也能按名称、IP、系统等条件筛选，但不能按这些运行状态把异常节点圈出来。勾选还只活在当前页，翻页后无法带着已选集合去做批量启停。结果是「看见异常」无法变成「筛出来、勾上、批量处置」。

## Solution

在现有云区域节点清单的组合筛选中增加在线状态和组件状态，全部条件 AND，服务端在分页前按与列表相同的状态口径过滤。勾选跨页保留，批量操作和系统/架构校验作用于全部已选节点。这一期不提供导入、导出。

在线状态与列表 Sidecar 列同一口径：最近 60 秒有上报为在线，否则离线。不另做一套「控制器正常/异常/未安装」枚举，避免筛选项和表格对不上。

组件状态与列表托管程序列同一口径：Sidecar 上报的采集器状态，叠加上尚未出现在上报清单里的安装任务状态，并沿用列表把部分空跑错误显示成正常的规则。可只选状态（任意组件命中），也可再限定组件名。没有该组件或没有任何组件的节点，不命中组件状态条件。不提供「某组件未安装」筛选。

## User Stories

1. As a 节点管理员, I want 按 Sidecar 在线或离线筛选节点, so that 我能先圈出失联 Agent 再批量处置。
2. As a 节点管理员, I want 按托管程序状态筛选，且可不指定组件, so that 任意采集器异常、停止、安装失败的节点都会出现。
3. As a 节点管理员, I want 指定某个组件再筛状态, so that 我能只圈出 Telegraf 异常的节点去做该组件的批量启停。
4. As a 节点管理员, I want 在线状态、组件状态与现有名称/IP/系统等条件同时生效且全部满足才命中, so that 筛出来的集合可以直接作为批量操作对象。
5. As a 节点管理员, I want 翻页后仍保留已勾选节点, so that 我可以跨页凑齐一批再操作。
6. As a 节点管理员, I want 改筛选、切换未归属或换云区域时清空已选, so that 不会把上一批结果里的节点带进新集合。
7. As a 节点管理员, I want 批量 Sidecar / 托管程序 / 批量编辑以及系统、架构一致性校验都看全部已选节点, so that 跨页勾选真正能用，而不是只对当前页生效。
8. As a 无节点权限的用户, I want 筛选结果仍受现有节点权限约束, so that 我看不到也勾不到别人的节点。

## Implementation Decisions

### 入口与组合

- 入口仍是云区域下的节点清单，沿用现有组合筛选，不另开状态快捷条，不以点击表格状态标签作为主筛选入口。
- 新增两套条件：在线状态（单选，不选则不限制）、组件状态（状态多选；组件名可选）。与现有名称、IP、操作系统、安装方式、控制器可升级、CPU 架构一起 AND。
- 不新增菜单权限。能看列表就能筛。批量安装、启停、卸载、编辑仍用现有动作权限。
- 不新增对外 OpenAPI，不改 Sidecar 上报协议。

### 在线状态

- 在线：节点最近上报时间在 60 秒内。离线：超过 60 秒。
- 与列表 Sidecar 列使用同一心跳口径。已出现在节点清单中的机器按此二维筛选，不引入第三套控制器生命周期枚举。

### 组件状态

- 过滤对象是列表托管程序列使用的合并清单：上报中的采集器，加上尚未出现在上报清单中的安装任务项。
- 可选状态与列表标签一致：正常、未知、异常、停止、未启动、安装中、安装失败。未启动包含列表中同一文案下的上报未启动与安装成功未拉起。
- 同一组件状态字段内多选为 OR（异常或停止即命中）；与在线状态及其他筛选字段仍为 AND。
- 未指定组件：任意一个合并后的组件处于所选状态之一即命中。
- 指定组件：按组件展示名匹配（例如 Telegraf），不按带操作系统后缀的内部 ID，以便 Linux / Windows 变体都能命中；只有该组件处于所选状态之一才命中。
- 节点没有任何组件，或指定组件不在合并清单中：不命中组件状态条件。
- 列表会把特定空跑错误显示成正常时，筛「异常」不得命中这些节点。
- 离线节点仍按其最后一次上报（及未结束安装任务）的组件状态筛选，筛选结果上不额外标注「状态可能过期」。

### 查询时机

- 状态过滤在服务端、分页前完成。禁止只过滤当前页再当作全量结果。
- 未知字段或未知状态码忽略该条条件，不报服务器错误，其余合法条件继续生效。
- 无命中时返回空列表。

### 跨页勾选

- 已选集合按节点 ID 跨页保留，当前页全选或取消不得覆盖其他页已选。
- 前端同时保留已选节点的必要快照（至少操作系统、CPU 架构、ID、名称、IP），供批量入口和一致性校验使用。
- 筛选条件变化、切换未归属、切换云区域时清空已选。
- 工具栏展示已选台数。不做「一键全选当前筛选结果」。
- 操作提交时，服务端仍按当前用户权限校验节点 ID；已删除或已无权限的对象拒绝执行，并返回明确失败，不得把越权 ID 执行下去。

## Testing Decisions

只锁定外部行为：给定筛选条件时的命中集合、分页前后一致性、跨页已选是否保留、改筛选是否清空、批量校验是否看全部已选、权限边界是否仍生效。不测组合筛选控件内部实现，不测 JSON 存储结构。

服务端覆盖节点搜索过滤：在线/离线、任意组件状态、指定组件状态、与现有字段 AND、空跑错误改写后不命中异常、安装中/安装失败未进入上报清单时仍能按安装状态命中、无组件不命中、非法条件忽略、分页前过滤（构造跨页数据，第一页不应混入不命中节点）。沿用现有节点搜索测试风格。

前端覆盖：新增筛选项出现在组合筛选中；跨页勾选累加且改筛选后清空；批量入口的系统/架构校验使用全部已选快照而不是当前页。跨页勾选的先例是作业平台主机选择的跨页测试，节点清单应对齐「保留已选键、翻页不丢」这一行为，而不是复用作业弹窗。

## Out of Scope

- 导入节点或 Agent 清单。
- 导出 Agent 列表（后置，不在本期交付）。
- 一键全选当前筛选结果。
- 按「某组件未安装」做存在性筛选。
- 与列表 Sidecar 列不一致的控制器「正常 / 异常 / 未安装」筛选。
- 快捷「运行不健康」（任一维度非正常的 OR 视图）。
- 点击表格状态标签作为主筛选入口。
- 修改 Sidecar 上报协议、新增对外 OpenAPI、异步导出任务。

## Further Notes

- 用户最初提到导出 Agent 列表，本轮明确筛选优先、导出后置、导入不做。
- 验收主链：离线筛选；任意组件异常；指定 Telegraf 异常；离线且 Telegraf 异常的 AND；跨页勾选累加后批量校验看全集；改筛选清空已选。
- 验收降级：无命中空态；无组件不命中组件条件；空跑错误显示为正常则筛异常不中；无权限看不到别人的节点；批量越权 ID 被拒绝。
