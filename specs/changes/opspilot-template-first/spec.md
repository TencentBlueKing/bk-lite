# OpsPilot 内置能力改为模板

状态：已完成

## 目标与边界

部署后不再自动生成可运行的成品智能体和工作台。内置智能体通过模板提供，用户主动创建实例。AI智能助手模板包含提示词、简介、开场白、工具名称和可跨环境复用的配置。

升级完整保留已有智能体和工作台，包括历史内置实例、自建实例及副本。无论是否被使用，都不删除、不改写字段或内置标识，不修改关联及历史。模板不复制模型、组织、知识库、记忆体、实例或工具的环境 ID，也不携带凭据。

## 数据与交互

- 复用 `LLMSkill.is_template` 和现有模板列表接口，内置模板由稳定 `skill_id` 标识并幂等更新，不再清空整个模板目录。
- 内置模板包含 AI智能助手与原有巡检工作台的主助手能力；AI智能助手按稳定标识固定排在第一位，其余保持原顺序。巡检模板介绍说明检查范围与必要准备，不承诺提示词和工具未实现的能力；格式化辅助智能体不作为独立成品展示。
- 顶部导航顺序为智能体、工作台，其余顺序保持。
- 智能体入口下提供“智能体”和“模版”二级菜单，与工具页一致使用页面标题下方左对齐的分段切换按钮；不显示顶部重复二级横栏。两个页面地址保留，详情设置、发布、历史仍按既有详情导航访问。
- 智能体列表“新建”直接创建空白智能体。模板页展示可复用能力，使用模板后创建用户实例并进入设置，使用当前环境工具目录绑定工具，模型由用户选择。

## 验证

- 新部署初始化只同步内置模板。重复初始化保留模板 ID 和用户自建模板。
- 升级后的初始化保留已有智能体和工作台的字段、内置标识、关联和历史。
- 模版页将 AI智能助手排在第一位。其他三项介绍说明巡检范围与使用准备。
- 浏览器已验证顶部排序、二级菜单切换及刷新、详情页导航、空白新建和从模版创建。创建实例时按名称绑定当前环境的工具，模型由用户选择。
