# 资产导出独立权限

Status: 已实施

资产列表导出从「有资产查看即可导出」拆成菜单权限 `asset_info-Export`。权限表里的操作项名称是 `Export`，挂在资产信息下，可按角色单独勾选。

- 未授权时，资产列表工具栏、更多菜单和底部选择条都不展示导出。
- 提交导出和失败导出的重试要求 `asset_info-Export`。超级管理员仍跳过菜单校验。导入仍要求 `asset_info-Add`。
- 导出菜单第一次写入时，已经拥有 `asset_info-View` 的自定义角色补一次导出权限。之后取消勾选不会在下次初始化时被加回去。内置 `normal` 不默认带导出。`manager` 仍拥有全部菜单。Guest 清单包含该权限。
