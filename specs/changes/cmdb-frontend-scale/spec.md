# CMDB 前端规模收敛

Status: implemented

日期：2026-11-09

本次只记录已确认的方案，不改代码。CMDB 用户列表保持现状，不在本次范围。

## Problem Statement

模型、资产、关联和扫描命中变多之后，CMDB 前端会把整份关联、整份命中或整本目录一次拉进浏览器。页面时间、内存和并发请求随数据量放大，大实例的关联页、大扫描的命中抽屉、采集任务下拉和应用拓扑会卡住。

## Solution

列表和抽屉只取当前要看的一页，下拉改成远程搜索，拓扑在节点到达上限后停止扩展。不带新参数的既有接口保持原来的返回，服务树、OpenAPI、NATS 和其他模块继续用默认语义。

## User Stories

1. As a CMDB 管理员, I want 打开实例关联页时先看到分组和数量，并且只加载当前展开分组的一页, so that 一台挂着大量进程、网卡或磁盘的主机不会把关联页卡住
2. As a CMDB 管理员, I want 从左侧菜单点进某一组关联时只展开那一组, so that 我不用等其他分组的实例行
3. As a CMDB 管理员, I want 选择关联和连接端口时只取完成这个动作所需的端点, so that 弹窗不再带回整份关联实例
4. As a CMDB 管理员, I want 扫描命中抽屉只显示当前标签和当前筛选的一页，扫描进行中只在有新结果时刷新, so that 大扫描不会每 5 秒重拉全部命中
5. As a CMDB 管理员, I want 采集任务、IP 采集和扫描任务里的实例、子网、接入点下拉按名称搜索, so that 打开表单不再装入一万条目录
6. As a CMDB 管理员, I want 高级筛选在我添加关联条件时才查询相关模型, so that 打开抽屉不会按相邻模型数打出一串请求
7. As a CMDB 管理员, I want 配置文件版本按页查看, so that 展开一个文件不会取回全部历史版本
8. As a CMDB 管理员, I want 应用拓扑在节点过多时停住并看到截断提示，网络拓扑继续停在 100 个节点, so that 画布和后续资源查询有确定上限

## Implementation Decisions

- 落地顺序：扫描命中抽屉、`page_size: 10000` 下拉、配置文件版本、高级筛选缓存、关联列表分页、应用拓扑上限。
- 不带新参数的关联列表、命中列表和拓扑接口保持现有调用方的返回语义。
- 模型属性批量查询已经按对端模型去重，本次不重复改那一层。

### 资产关联关系列表

- 同一条关联实例列表增加 `summary=1`：只返回分组头和 `inst_count`，不带 `inst_list`。分组计数在没有 `inst_list` 时读 `inst_count`。
- 增加 `model_asst_id` + `page` + `page_size`：只返回一个分组的一页。`page_size` 最大 50。这种查询只按当前实例和这个关联过滤，查不到就返回空页，禁止退回全图扫描。
- 关联页先请求 summary。只展开第一个有实例的分组；从菜单进入时只展开点中的那一组。展开后请求第 1 页，每页 20 条。同时最多 10 个分组的分页请求在飞。
- 属性批量查询只覆盖当前展开分组的对端模型。收起分组时丢掉该组的行，保留计数。关联或解除关联后，刷新 summary，并只刷新仍展开分组的当前页。
- 选择关联弹窗只取 `model_asst_id`、`src_inst_uuid`、`dst_inst_uuid`。弹窗里的实例表格继续用现有分页搜索。
- 端口连线只查 `interface_belong_{设备模型}`。接口超过一页时按名称搜索，每页 20 条，已选端口保持可见。

### 扫描命中抽屉

- 新增命中 summary：已匹配、未匹配数量，以及按家族、置信度、纳管状态的数量。执行未到终态时，未匹配按 0 算，命中都算在已匹配里。
- 现有分页命中接口增加 `matched`、`confidence`、`model_id`、纳管状态。家族键优先用 `family_model_id`，为空时用 `protocol`。单页仍最大 200。抽屉请求当前筛选的一页，`page_size` 为 20。
- 每 5 秒只轮询执行详情。`received_count` 或状态变化时，再刷新 summary 和当前页。执行结束后停止轮询。
- 跨页勾选留在集合里。批量写入、生成采集、推送监控继续提交已选 `hit_id`。本次不做按筛选条件全选。

### page_size 10000 的下拉

- 采集任务的实例、接入点，IP 采集的子网，扫描任务和采集工具的接入点，改为远程搜索。`page_size` 为 20，输入防抖 300ms。还没输入时不发搜索。已选项保持可见。
- 实例按 `inst_name` 包含关系搜索。禁用状态仍只根据已下发实例 id 判断。
- 子网按名称搜索。
- 接入点按名称搜索，继续只用容器节点。编辑任务用详情里的当前接入点回填，不先拉整本目录。

### 高级筛选二跳

- 关联定义按模型缓存，进行中的同一模型请求合并成一次。模型关联创建或删除时，失效两端模型的缓存。
- 打开空抽屉时不请求。用户添加一条关联条件时，才拉当前模型的关联。选定第一跳之后，只拉那一个目标模型。

### 配置文件版本

- 版本列表改为第 1 页、每页 20 条，表格用返回的总数分页。内容和对比仍按版本 id 取。
- 全局分页在 `page_size` 为 `None`、`0` 或 `-1` 时返回整表的行为保持不变，其他模块继续依赖它。

### 拓扑

- 网络拓扑节点上限保持 100。画布节点不超过 100。闭合集合的 uuid 超过 100 时，请求发出前拒绝。
- 应用拓扑构建把节点封顶 100。达到上限停止遍历，`truncated` 为 true，连线只保留两端都在结果里的边。资源概览和对外调用走同一个构建，同一上限生效。
- 每一跳按当前实例和它的模型查询。查不到就当这一跳没有邻居，禁止退回全图扫描。
- 本地没有存过深度时，默认深度为 1。用户调高后仍写入现有的 `bk-lite:cmdb:app-topo-expand-depth`。页面继续展示已有的截断提示。资源详情只传拓扑返回的节点 id。

## Testing Decisions

测试锁外部行为：请求次数、查询参数、返回形状、并发上限和截断结果。图查询用假图记录过滤条件。前端请求用可延迟的替身控制完成顺序。

- 关联页首次进入只发 1 条 summary、1 条第一组或菜单选中组的分页，以及这一组对端模型的 1 条属性批量请求。连续展开超过 10 个分组时，同时未完成的分页请求不超过 10 个。收起后行消失、计数还在。选择关联的结果只有三个端点字段。端口连线只请求两侧设备的接口关联。
- 不带新参数的关联列表仍返回完整 `inst_list`。指定分组的分页在端点属性缺失时不出现空过滤扫描。`page_size` 超过 50 拒绝。多个分组同时请求时互不串数据。
- 命中抽屉打开时只发 1 次 summary 和 1 次当前页。连续切换筛选时只采用最后一次返回。执行详情没有变化时，5 秒轮询不再请求命中。`page_size` 超过 200 拒绝。summary 数量和同一套筛选下的总数一致。
- 下拉连续输入只发出最后一次搜索，`page_size` 为 20。清空输入不再搜索。已选项不在本页时仍然可见。编辑接入点不出现 `page_size: 10000`。
- 高级筛选打开空抽屉时关联请求数为 0。选定第一跳后只再请求那一个目标模型。多个组件同时要同一个模型时，进行中的请求只有 1 次。删除关联后，两端下一次读取重新请求。
- 配置文件版本展开只请求第 1 页且参数里没有 `-1`。同时展开多个文件时，各自只带自己的文件路径。全局分页对 `-1` 仍返回整表。
- 网络画布合并结果不超过 100 个节点。101 个 uuid 的闭合集合不发出拓扑请求。应用拓扑在没有本地深度时请求深度 1，已保存的深度仍按保存值请求。遍历到 100 个节点后停止，结果里没有一端落在节点外的连线。每一跳的图查询都带当前实例。

已有关联菜单、扫描命中、网络拓扑和应用拓扑测试继续锁住原来的字段和交互。新增用例沿这些测试的假接口和假图接法写。

## Out of Scope

- CMDB 用户列表。进入 CMDB 时预拉用户、表格里的用户展示、操作日志和筛选里的用户选择，都保持现状。
- 告警使用的用户列表，以及用户列表接口的全局上限。
- 采集任务状态和概览的 30 秒轮询，K8s Pod 筛选选项。
- 命中抽屉按筛选条件全选。
- 后端自动关联、采集守门、订阅、实例拓扑树、展示名同步和唯一性规则。它们另案确认。
- 修改全局分页对 `-1` 的语义。

## Further Notes

方案已实施。用户列表仍是进入页面时预拉，每页 10000。关联列表先取汇总再按分组每页 20 条，同时最多 10 个分组请求。扫描命中改为单页 20 条，进行中的执行只轮询执行状态。下拉目录的单次请求改为 20 条，打开表单时仍会请求第一页。配置文件版本改为第 1 页 20 条。应用拓扑默认展开 1 层。网络拓扑在发起请求前拒绝超过 100 个设备。
