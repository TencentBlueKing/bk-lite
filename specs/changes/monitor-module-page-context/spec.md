# 监控模块页面问答

Status: done

## Problem Statement

运维人员在 Monitor 里看全量指标、实例列表、蜂窝、指标搜索、策略、集成和资产时，右侧智能问答大多仍是裸聊。已经接上的只有专业仪表盘，以及告警中心的活跃/历史列表（含打开的详情）。同一条仪表盘路由切到「全量指标」时，现有采集还会按专业盘去截图，容易截错卡。

用户要的是对着**当前正在看的那一屏**提问：某一个或某一类指标、红色的那几个 Pod、刚查出来的曲线、这条策略的阈值、现在接入了哪些。不要把未看见的页、未滚入的卡、密钥或整库 dump 进模型，也不要让问答去改配置、关告警或下发采集。

## Solution

把 Monitor 侧栏能进到的业务页按全站页面问答接入。发送时采集当轮快照，写入 `page_context`，不落会话历史。公共上限不放宽（约 8K 字、最多 6 张缩略图、约 2 秒采集）。

采集只跟当前视图走：列表不预拉蜂窝，蜂窝不预拉列表；分页只给当前页，不为问答翻下一页；全量指标只给已加载的短曲线。专业盘继续截图；全量指标和旧指标详情改为指标目录加压缩 JSON；指标搜索不超过 6 张仍截图，超过改 JSON；告警分布图补一张 Recharts 截图。问答只查询，不执行写操作。凭据永不进快照；问到凭据类问题时明确拒绝回答。

未改动的跳转入口（`/monitor`、`/event`、`/integration`）和未登记页保持裸聊。

## User Stories

1. As an 运维人员, I want 在专业仪表盘继续问当前盘上的图, so that 已有问答体验不回退。
2. As an 运维人员, I want 切到全量指标或打开旧指标详情后，能问某一个或某一类指标, so that 不必把几十张卡手工复述，也不会把整页曲线塞进模型。
3. As an 运维人员, I want 在监控视图列表问当前页实例，切到 Pod/节点蜂窝后再问「哪些红了」, so that 答案跟当前 Tab 和已加载格子走，没进蜂窝时不会先去拉格子数据。
4. As an 运维人员, I want 在指标搜索里问刚查出来的条件与曲线, so that 不必把表单和折线再讲一遍。
5. As an 运维人员, I want 在策略列表按当前页提问，打开详情后能问表达式和阈值, so that 能解释「为什么会告警」；问到通知人/处理人时能听到展示名。
6. As an 运维人员, I want 在集成配置、采集模板和资产上问「现在接入了哪些、IP 是多少」, so that 能核对接入事实；问密码或密钥时机器人拒绝回答。
7. As an 运维人员, I want 在对象、组织规则、策略模板和插件指标目录上按当前看得见的列表提问, so that 能查有哪些对象/规则/模板/指标，而不能通过对话去改它们。
8. As an 运维人员, I want 在告警列表对着级别分布图提问, so that 「critical 有多少」能对着图回答，下面表格仍只按当前页。
9. As an 运维人员, I want 翻页、切 Tab、改筛选后再问时答案跟新屏幕走, so that 机器人不会复述上一问的旧切片。

## Implementation Decisions

### 总则

- 不新做问答 UI。继续用全站智能问答；发送前采集、快照进当轮 `page_context`、不写入会话历史。不改 GlobalWebchat。不放宽 6 张 / 8K / 2 秒。
- 问答**只提供查询**。本期不新增关闭告警、改策略、勾选模板、下发采集、改接入配置等写操作，也不把现有智能体写工具接到这些页。
- 业务页默认零展示侵入：旁路 pilot 只读 URL / DOM / 图表实例。内存态 DOM 读不到时，才允许 hook 或不可见数据属性，不得改布局。
- 有分页的页一律只采**当前页已渲染行**，写明共 N 条、当前第 X 页；不为问答请求下一页。滚动加载（蜂窝、全量指标卡）只采**已经加载出来的**，未滚入的只报「还有 N 个」。
- 禁止凭据、token、密钥、community、云 Access Key 等进入快照。输入类型为密码的控件、密钥字段、采集模板里的密钥原文一律丢掉。
- 点名图表仍走现有服务端聚焦，点名后丢掉对话历史。全量指标的曲线 JSON 用同一套词面匹配，但**对不上不得退回全部曲线**。
- `mode="tool"` 按需拉取、另开一轮模型筛选、把未加载指标预拉出来，都不做。

### 曲线与截图通道

专业仪表盘维持「缩略图 + caption」。下列情形**不截图**，改用短 JSON（窗口起止、步长/range、`latest`/`min`/`max`、约 12–24 个顺序值；缺口用 `null` 或显式 gaps；数字收口为整数或一位小数）：

- 仪表盘「全量指标」模式
- 旧指标详情
- 指标搜索在查出来的图**超过 6 张**时

约定形态（会话对齐稿）：

```json
{
  "name": "磁盘使用率",
  "unit": "%",
  "time": "14:02~14:17",
  "range": "15min",
  "latest": 82.9,
  "min": 16.8,
  "max": 82.9,
  "value": [71, 80, 83, 82, 79, 83]
}
```

前端发送时带上：指标目录（分组 + 展示名 + 内部名；未加载只报名）以及已加载曲线的压缩 JSON。注入前由服务端按问句匹配。匹配字段为分组名、展示名、内部名；规范化去空白并小写；沿用现有标题包含、主题词、使用率/吞吐互斥、少量已测别名。**没有大模型参与筛选。**

- 命中：目录全给 + 只留命中项的 `value`
- 未命中或概览问：目录仍给（可带 `latest`/`min`/`max`），全部 `value` 去掉
- 命中过多：曲线条数再封顶，目录不裁

告警列表的级别分布图是 Recharts。本期在中性截图模块补 Recharts 适配（SVG 栅格化为约 600px JPEG），告警分布图走该通道，计入 6 张上限。折叠则不截。详情里的 Recharts 指标图仍不截，保持现有文字。

### 各页内容

**专业仪表盘**（已接，须按模式分支）  
同一路由可切「监控仪表盘 / 全量指标」。展示模式多半只在内存里，少数对象会同步查询参数。pilot 必须认当前 Segmented，切到全量指标后**停止按专业盘截图**，改走全量指标规则。KPI 火花图仍不占截图名额。

**全量指标 / 旧指标详情**  
分组默认展开，卡片滚入才有曲线。发送时不触发未滚入卡的请求。目录覆盖本页指标名；曲线 JSON 只来自已有图表实例（视口及预取行）。服务端按问句收口，未命中不退回全量 JSON。

**监控视图**  
对象树 + 实例表；仅 Pod / 节点可切蜂窝。按当前 Tab 采集，互不预取。列表：当前筛选 + 当前页行 + 页码，去掉操作列。蜂窝不是 echarts：给当前展示指标名、节点筛选（若有）、已加载格子的实例名 + 状态或当前值 + 颜色。常规问法是「红色那台 / 哪些红了」。格子上的名字目前只在 Tooltip 里，未悬停不在 DOM，允许 hook 或无展示标记，不得改六边形外观。未加载格子只报剩余个数。

**指标搜索**  
左侧查询组用表单摘要（对象、插件、实例、指标、聚合、维度过滤、时间窗），不给后台 PromQL。尚未点搜索、右侧为空时只有条件。点搜索后：查出来的图 **≤6 张则全部截图**；**超过 6 张不截图、改短 JSON**。条件摘要始终带上。

**告警策略列表 / 详情**  
列表：当前对象筛选 + 当前页摘要（名称、是否生效、监控目标数、创建人展示名、最近执行）。详情：名称、对象、监控目标、调度、表达式、阈值、持续时长、通知渠道类型。通知人与处理人**问句点到才注入，且只用展示名**（不要账号、ID）。未点名则详情快照不含这些人名。

**集成配置 / 采集模板 / 集成列表**  
接「现在接入了哪些」：插件名、节点、协议、实例名等非密钥事实。密钥字段与模板中的密钥原文永不采集。问句点到密码、community、密钥、token、Access Key 等时：不补任何凭据，并约束模型拒绝回答凭据内容。

**资产**  
当前页实例名与实例事实中的 IP（`asset.ip`）可以进快照。编辑配置抽屉按配置页规则剥密钥。只查询。

**对象 / 组织 / 策略模板 / 插件指标目录**  
当前看得见的列表或分组摘要。模板勾选状态可以写入快照，问答不得替用户勾选或批量应用。

**告警列表（加码）**  
已有列表 + 详情保持。分布图展开时补一张截图；下面表格仍只给当前页。分布图加载中/折叠则不截，不把空白当零。

**不接**  
`/monitor`、`/event`、`/integration` 仅跳转。插件额外 Tab、日志告警、其它产品线。

### 服务端

- 扩展现有页面快照聚焦：图表 caption 逻辑保留；新增指标目录/曲线 JSON 的命中裁剪（未命中保留目录、丢掉 `value`）；新增通知人/处理人点名注入；新增凭据问法拒绝约束。
- 不把筛选下沉回前端，不恢复按问法在浏览器里 `rankChartsByQuestion`。
- 非多模态模型继续丢图留 caption / 文字；全量指标 JSON 不受 `is_multimodal` 影响。

## Testing Decisions

好测试只锁对外契约：给定 DOM/URL/快照入参时，pilot 或注入函数的返回值（title、currentTime、sections 是否含目录/曲线/人名、images 数量、分页切片、模式分支、凭据问法约束）。不测 JPEG 像素、不测真实出图、不测 GlobalWebchat、不测 LLM 回答质量。

最高接缝：

- 服务端注入与聚焦：对齐现有页面上下文单测。覆盖「磁盘使用率」只留对应曲线 JSON、「磁盘」留该组、未命中只留目录、使用率不命中吞吐、通知人问句才出现展示名、凭据问句出现拒绝约束且文本无密钥哨兵。
- 专业盘 / 全量指标模式：同一路由，认「全量指标」时 `images` 不按专业盘截、文字含目录；认专业盘时行为不回退。
- 视图 Tab：列表快照无蜂窝格子；蜂窝快照含颜色与实例名、无列表未渲染页。
- 指标搜索：0 张图只有条件；3 张图走截图通道计数；7 张图无图、有 JSON。
- 分页：夹具第二页行不得出现在快照；须含「当前第 X 页」。
- 告警分布图：Collapse 展开则 `images` 至少 1 张（可用替身 dataUrl）；折叠为 0。
- 配置页夹具含密码框时快照不得出现该值。
- codegen：新增 `*.pilot.ts` 的路由前缀推导；Tab/展示模式闸门只在 pilot 内测，不写进 codegen。

手测（不替代单测）：全量指标问「磁盘使用率」请求体有目录、注入后曲线收口；视图未切蜂窝时快照无格子；搜索 1 张图带截图；策略详情问「通知谁」出现展示名、问阈值不出现人名；配置页问 community 被拒绝；告警列表展开分布图后请求带图；资产当前页含 IP。

## Out of Scope

- 为问答预拉未滚入的指标卡或蜂窝下一屏
- 用第二轮大模型筛选指标，或把页面快照改成 `mode="tool"`
- 放宽 6 张 / 8K / 2 秒
- 给模型完整原始时序或后台 PromQL
- 日志告警、插件额外 Tab、IM / 嵌入式渠道
- 通过问答改策略、关告警、下发采集、编辑接入、批量应用模板
- 为对接改业务页可见布局（蜂窝身份标记除外，且必须无展示）
- 修复蜂窝「展示指标」下拉候选项过少（那是业务页拉目录参数问题，另开变更）

## Further Notes

产品范围是「对着已经看见的监控页提问」。全量指标不用专业盘那套「截前 6 张」，是因为卡多、懒加载、问法是点名某一类。短 JSON 是 sparkline，不是 Prometheus dump，与全站「禁止原始时序」不冲突。

筛选在服务端做词面匹配，是因为前端按口语筛不准，也不想多打一轮模型。对不上只留目录，是因为全量指标若像截图那样 miss 就退回全部，content 会爆。

告警分布图补截图，会动中性截图模块；这覆盖了告警列表变更里「不为 Recharts 补适配器」的限制，仅用于这张分布图，不自动给详情指标图截图。

对接写法以 [页面问答 app 接入规范](../webchat-page-context/app-integration.md) 为准。已完成的专业仪表盘与告警列表变更仍然有效；本期在它们之上按展示模式和分布图加码，并铺开其余 Monitor 页。
