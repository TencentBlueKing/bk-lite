# 导入与新增成功后续同步任务

Status: implemented

## Problem Statement

运维在 CMDB 导入或新增资产、在监控接入新实例之后，已经建好了本域对象，但不会自动走进对端同步。列表上虽有「建立监控关联 / 同步到 CMDB」，成功当下却是空选中，必须自己回去勾选。PLG 的下一步断在保存成功这一刻。

## Solution

导入或新增成功后，立刻弹出和列表勾选后相同的确认框。确认则用这次写入的 ID 创建已有的胶水同步任务并跳进任务页。取消则只完成刚才的保存。不新增一键 upsert，不静默建监控实例或 CI。

## User Stories

1. As a CMDB 管理员, I want 在资产列表新增一条并保存成功后被询问是否同步到监控, so that 我不必再回列表勾选这一条。
2. As a CMDB 管理员, I want 导入任务成功或部分成功且确实新建了实例后被询问是否同步到监控, so that 这批新资产能接着进现有同步任务。
3. As a 监控管理员, I want 接入配置成功并产生监控实例后被询问是否同步到 CMDB, so that 新接入的对象能接着进现有反向任务。
4. As a 只装了单边应用或当前模型对不上对端的管理员, I want 成功后不要弹出同步确认, so that 不会走进对端不存在的流程。
5. As a 只想建台账或只想完成接入的管理员, I want 点取消后停留在当前工作, so that 同步不是强制的。
6. As a 一次导入新建超过 100 条的管理员, I want 确认框按现有任务上限带走前 100 条新建, so that 行为与列表批量同步一致，其余仍可在列表继续勾选。

## Implementation Decisions

- 数据形状是一次「后续同步要约」：方向（CMDB→监控 或 监控→CMDB）、有界 ID 列表、当前模型或监控对象。不是新的同步对象，也不是新的推送接口。
- 确认文案、跳转、建任务 API 与资产列表现有批量同步完全同一条路径。CMDB 侧 `createCmdbMonitorTask`，监控侧 `createMonitorCmdbTask`。上限仍是 100。
- 只对新建要约。导入里更新已有实例不进 ID 列表。新建数为 0 时不弹窗。
- 入口闸与列表相同：对端许可 fail-closed，平台树模型不出，反向无内置映射不出。
- 资产列表新增：创建接口已返回实例 UUID。保存成功、关新增弹窗之后弹确认。点取消仍刷新列表。采集任务里复用同一新增表单的地方不接这要约。
- 资产导入走现有异步转移任务，不是同步 `inst_import` 返回。转移任务结束（`succeeded` / `partial_success`）时，用摘要里的新建 UUID 要约。`failed` / `interrupted` / `cancelled` 不弹。
- 转移任务摘要补有界字段 `created_inst_uuids`，最多 100 个，按写入顺序。`created` 计数仍是全量新建数。超过 100 时确认框用这 100 个，文案带上总数。
- 监控侧接接入配置成功、且能抽出新建实例 ID 的那条路径。抽出逻辑沿用现有实例 ID 收集。弹窗发生在成功提示之后、离开配置页之前。仍禁止调用会 upsert 台账字段的 `push_to_cmdb`。
- 编辑、删除、批量改字段、扫描、采集落库、节点推送都不接。扫描继续只用已有的执行后推监控选项。
- 不改胶水任务表结构，不改关联规则，不改凭据边界。

## Testing Decisions

只测外部行为：保存成功后是否弹出与列表相同的确认、确认后是否带着这些 ID 去建任务、取消后是否不建任务、无许可或不可映射时不弹、导入只带新建 UUID、超过 100 只带前 100、导入失败终态不弹。

测试缝优先已有最高层：联动入口纯函数、转移导入摘要、资产页确认编排、接入成功抽出实例 ID。Prior art：`systemLinkage` 前端测试、列表选择操作栏测试、转移任务 hook 测试、转移导入服务测试、监控接入策略抽出测试。

## Out of Scope

- 静默调用 `push_to_monitor` / `push_to_cmdb`。
- 导入后自动开任务且不问。
- 用监控覆盖已有 CI 字段。
- 扫描路径再做一层成功弹窗。
- 离开资产页之后还对已结束导入补弹窗。
- 为无映射对象手指定对端模型。
- 提高 100 条任务上限。
