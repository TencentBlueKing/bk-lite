# 补丁周期评估通知

## 目标

在「补丁管理 / 设置 / 扫描设置」中为周期触发的全局评估增加通知配置。
通知默认关闭，只在评估结果需要关注时发送。

## 产品契约

- 通知只作用于由全局周期调度创建的评估任务；手动评估、基线变更后评估和治理后验证不在本期范围。
- 周期评估关闭时，保留通知开关和规则，但不生效。
- 开启通知后至少需要一条规则。每条规则选择一个系统管理中的现有渠道，同一渠道不得重复。
- 每个渠道独立保存接收人。除 NATS 外都必须选择至少一个接收人；NATS 只使用渠道自身配置。
- 周期任务创建时固化当时的通知规则，任务执行期间的设置变更从下一次周期任务开始生效。
- 存在不合规主机或评估失败主机时，每个配置渠道发送一条汇总；全部合规时不发送。
- 汇总包含评估完成时间、主机总数、不合规数和评估失败数；本期不提供跳转入口或测试发送。
- 通知失败不改变评估任务结果。投递状态持久化，使用有限重试和运行期补偿扫描。

## 前端交互

- 「启用周期评估」关闭时隐藏全局评估周期和周期评估通知；开启时二者置于同一灰色配置区内，且全局评估周期必填。
- 使用「周期评估通知」总开关。
- 规则以轻量配置矩阵展示，列为「通知方式 / 渠道类型 / 接收人 / 操作」，不使用卡片网格或穿梭框。
- 通知方式按需添加。接收人使用可搜索多选，超出可见数量后折叠。
- 保存按钮始终可点；点击后才触发校验。周期字段使用 Ant Design Form 默认错误样式，规则表格使用红框、红色叹号及悬停提示，配置不完整时不发起保存请求。
- 保持亮色/暗色主题和窄容器可用。

## 不在本期

- 首页「全部评估」通知。
- 治理后验证通知。
- 通知详情页、手动重试入口、跳转链接和自定义模板。
