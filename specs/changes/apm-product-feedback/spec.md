# APM 产品走查整改

## 背景

产品走查确认 APM 在服务身份、告警状态、探索入口、策略配置和接入信息架构上仍混用了技术实现口径与用户任务口径。本变更以 `DESIGN.md`、`web/DESIGN.md` 和现有 APM 真实接口为约束，收敛对应生产路由，不引入模拟数据。

## 产品决定

- 服务目录展示遥测 SDK 语言；“状态”表示应用或服务的最高活跃告警级别，不再展示推导健康度。
- 应用卡进入独立应用详情。应用管理是集成默认入口，“添加接入”是具体应用上的操作。
- 删除内置“未归类应用”。只有显式存在且对当前组织可见的 `service.namespace` 才能进入服务目录。
- 服务不会因静默被自动归档；实例超过静默窗口后进入归档历史，新遥测可恢复自动归档的实例。页面不再提供手工归档实例操作。
- SLO 启用状态是列表级操作，不进入创建或编辑表单。
- 调用链和错误页在未带深链参数时自动选择首个可用服务；错误查询在服务端限定 `status=error`。
- 端点指标在表头排序，详情展示端点级 RED 趋势与对应调用链。
- APM 告警列表展示服务与端点，不重复展示状态和值；详情提供所选告警对应服务的 RED 趋势。
- APM 告警事实仍由 APM 策略和事件流产生，不与 Monitor 的告警表合并；两者对齐交互和状态语言，但保持领域与权限边界。
- 策略列表移除测试查询与监控对象列；创建使用独立页面，启用状态保留为列表级操作。

## 拓扑术语

- 原“样本”指当前时间窗内受查询上限约束的 Trace 观测，不代表全量流量；界面统一改为“观测 Trace/观测调用”。
- 原“SVC”是 service 的缩写；界面统一显示“服务”。
- 连线箭头以节点边界为起止点，并使用固定用户空间 marker，避免缩放后箭头穿过节点或大小失真。

## 验收

- 服务页可见语言、最高活跃告警状态和独立应用详情入口，无遥测依赖宣传文案。
- 服务详情吞吐与错误率使用主题实际色值绘制，亮暗主题 Canvas 均有效。
- SLO 创建/编辑无启用项且“端点”不重复显示可选提示。
- 调用链、错误、端点在真实空数据时仍有可操作筛选或明确空态；不伪造数据。
- 告警详情、策略创建、应用详情均为生产路由并通过权限与真实 API。
- 集成菜单顺序为应用管理、接入实例；实例默认活跃且可切换查看归档记录。
- 后端目录、序列化、自动归档和 endpoint RED 查询有聚焦回归测试。
