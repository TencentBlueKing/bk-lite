# 公共能力目录公开组件（告警 / CMDB / 运营分析）

Status: implemented

## Completion Evidence

- 前端：`pnpm exec vitest run` 覆盖目录探测（`appCapabilities/__tests__`、monitor/cmdb/OA `capability.test.ts`）、告警宿主 isolation / Tab 序 / 快照对象、CMDB 入口闸门与宿主 isolation、关联拓扑保存校验、画布 surface、网络嵌入适配、3D `instUuid` 收窄查询、懒加载 `reloadKey`，均 PASS。
- 前端：`pnpm type-check` PASS。
- 后端：`uv run pytest apps/operation_analysis/tests/test_application3d_query_service.py::test_wall_narrows_query_to_one_application_id --no-cov` PASS（墙查询按单个 `application_id` 收窄，不再走全量墙）。


## Problem Statement

BK-Lite 按已售模块交付后，运维在告警处置和资产排查时仍要在监控中心、告警中心、CMDB、运营分析之间反复跳转，才能看监控视图、告警列表、资产基础信息、关联拓扑、网络运行状态和应用 3D。第一实验已验证「运营分析声明关联拓扑 → 告警详情按需加载」，但公共能力目录仍停留在应用级探测，其余小组件尚未按稳定标识开放；CMDB 与运营分析画布也还不是宿主。继续靠宿主编译期引用他模块页面、或按名称 / IP 现场反查补联动，会把模块边界和身份契约一起打穿。

## Solution

在公共能力目录上按组件粒度声明并探测 6 个公开组件（监控视图、告警列表、CMDB 基础信息、关联拓扑、网络状态拓扑、3D应用）。提供方自行完成权限、取数、空态、失败与重试；使用方只传稳定业务标识（`monitorId` / `instUuid`），先探测授权与可用性再按需加载。告警详情（页面与抽屉同一套规则）固定 Tab 顺序并统一切换当前快照对象；CMDB 资产详情按条件把关联关系默认「拓扑」换成公开关联拓扑，并按条件追加入口挂监控视图 / 告警列表 / 网络状态拓扑 / 3D；运营分析把关联拓扑登记为场景组件，供 Dashboard / Screen 选用。未购买、无模块权限、未声明或缺少稳定标识时不展示入口；资源无权等失败留在组件内提示。

## User Stories

1. As an 正在处置告警的运维人员, I want 告警详情按固定顺序看到概述、事件、监控视图、关联拓扑、资产信息、变更记录、处理动作, so that 处置路径稳定，且公共能力只在进入对应 Tab 时加载。
2. As an 运维人员, I want 一条告警挂多个对象时在详情级切换「当前对象」, so that 监控视图、关联拓扑、资产信息跟随同一对象更新，且组件每次只收到一个标识。
3. As an 运维人员, I want 快照缺少 `monitorId` 或 `instUuid` 时对应公共 Tab 在告警级不出现或进入后明确提示且不发起查询, so that 系统不会按名称、IP 等字段反查补联动。
4. As an 查看 CMDB 资产的运维人员, I want 已购买运营分析且已联动监控的资产能打开监控视图和告警列表, so that 不用跳去监控中心也能看当前监控数据与监控告警口径列表。
5. As an 已购买运营分析的运维人员, I want 普通资产在关联关系「拓扑」里看到公开关联拓扑（带告警健康）、网络设备额外看到「网络状态拓扑」、应用系统额外看到「3D应用」, so that 在资产详情就能看健康关系、一跳网络状态和当前应用单卡墙；不满足条件时默认拓扑与现网一致，且不替换列表 / 网络拓扑 / 二维应用拓扑。
6. As an 运营分析画布编辑者, I want 把「关联拓扑」作为场景组件选一个资产实例绑定 `instUuid`, so that Dashboard / Screen 能嵌入与告警、CMDB 同源的关系健康图，且资产列表只负责选参。
7. As an 未购买或未获授权某模块的用户, I want 宿主页面不出现对应公开组件入口且原有能力仍可用, so that 售卖与权限降级不会打断告警详情或 CMDB 详情。
8. As an 运维人员, I want 打开公开组件时看到的是当前数据（非告警发生时快照），失败可重试、无数据有空态, so that 嵌入态与提供方主场口径一致且可诊断。

## Implementation Decisions

### 公共能力目录与探测

- 延续系统层 `appCapabilities`：提供模块在各自 `capability` 中声明组件并登记目录；使用模块先按售卖 / 模块级访问探测，再按**稳定组件键**检查声明与可加载性。不另建运行时注册表，不把业务组件搬进 shared `src/components`。
- 授权按售卖模块；组件键解决「模块已购但某组件未声明 / 不可加载」的降级。宿主按键探测，失败与未购买统一不展示入口。
- 六个稳定声明键（与展示文案解耦）：
  - `monitor.monitorView`
  - `monitor.alertList`
  - `cmdb.baseInfo`
  - `ops-analysis.relatedTopology`
  - `ops-analysis.networkStatusTopology`
  - `ops-analysis.application3D`
- 入口层（藏入口）：未购买、无模块级访问（公共能力探测失败，含 `clientData` 无对应售卖应用）、组件未声明 / 不可加载、缺稳定标识。**跨模块公开嵌入**（告警 / CMDB 挂非本模块组件）还须已购运营分析（`hasAppAccess('ops-analysis')` / `get_client`）；同模块自用（监控主场、OA 画布）不加此门。提供方模块的探测语义不变。
- 组件内（展示入口再提示）：资源无权、不存在、关联失效、查询失败；成功无数据 → 空态。实例级 ACL 不回头关掉 Tab / 入口。
- 使用模块只传稳定业务标识，禁止直接引用提供模块页面、内部组件路径或 NATS 接口；禁止宿主串他模块数据再拼装业务组件。
- 除特别说明外，嵌入展示**当前**数据，不作告警发生时快照。
- 契约一次对齐；实现可分 PR，验收按完整 6 组件。建议实现序：目录与按键探测 → 关联拓扑扩宿主（CMDB + 画布）→ 监控两组件 + 告警 Tab → CMDB 基础信息 → 网络状态 / 3D 嵌入适配。

### 组件契约

- **监控视图**（`monitor.monitorView`）：入参严格 `{ monitorId, metricKey? }`。组件内部自举对象类型、实例与指标元数据，复用监控中心「监控视图」内容区；未传 `metricKey` 时由组件提供指标选择。宿主不预查、不透传大上下文。缺元数据或实例失效 → 组件内失败态。
- **告警列表**（`monitor.alertList`）：入参 `{ monitorId }`。复用监控中心实例 / 对象下告警列表能力（与监控详情告警 Tab 同口径）；只读列表 + 必要筛选 / 分页；点击下钻跟随监控现网。数据只打监控告警口径，不读告警中心单据。不以「禁跳 / 仅抽屉」为默认。无 `monitorId` → 不展示入口、不发起监控查询。
- **基础信息**（`cmdb.baseInfo`）：入参 `{ instUuid }`。复用 CMDB「基础信息」按模型字段组的只读呈现；嵌入态去掉编辑及写操作；提供「在 CMDB 中打开」为次要出口，不以跳转替代 Tab 内只读内容。字段与模型差异由组件自举。
- **关联拓扑**（`ops-analysis.relatedTopology`）：入参 `{ instUuid }`。延续第一实验的领域编排（CMDB 同源邻居 + 监控活跃告警叠层）；可被告警详情、CMDB、运营分析画布复用。无 `monitor_id` 的节点不得表现为健康 / 全绿。
- **网络状态拓扑**（`ops-analysis.networkStatusTopology`）：目录一个稳定键。嵌入对外契约 `{ instUuid }`（固定一跳）。领域查询与核心渲染与现有画布网络状态拓扑共用；CMDB 嵌入薄适配层将 `instUuid` 转为单元素列表、锁一跳、隐藏跳数切换。画布仍用现有 scene 配置，不要求与嵌入 props 同形。本期不新增 embed 专用后端；若现接口无法强制一跳，先在适配层 / 现有查询参数收口。不拆第二个嵌入业务声明键。
- **3D应用**（`ops-analysis.application3D`）：入参 `{ instUuid }`，宿主将其作为现有 `application_id` 口径传入。目标态：查询按单应用收窄，渲染为单卡墙；点击仍走「聚焦 → 详情 / 部署架构」。**「短期全量再过滤」只作实现过渡，不算验收完成态**；验收完成仍要求查询收窄的单卡墙。不在 CMDB 加载全量应用墙作为交付定义。

### 告警详情宿主

- Tab 顺序固定：概述 → 事件 → 监控视图 → 关联拓扑 → 资产信息 → 变更记录 → 处理动作。
- **告警详情页与抽屉同一套** Tab 序、公共组件、统一对象切换器与懒加载规则（现网两边都有详情壳）。
- 概述 / 事件 / 变更记录 / 处理动作：内容与交互保持现网，本期只调序并插入公共组件 Tab；变更记录、处理动作仍是告警中心单据 Tab，不是本期新增公开组件。
- 稳定标识只从告警快照已有字段读取（`monitor_id` / `cmdb_id` 等硬指针）；禁止打开页面后按名称、IP 等反查补齐。
- Tab 显隐看**告警整体**：任一快照对象具备对应标识，才挂对应公共 Tab；避免切换对象时 Tab 栏跳动。
- **详情级统一「当前对象」切换器**：列出快照**全部**对象（含缺少某一侧标识的对象）。监控视图、关联拓扑、资产信息只消费当前对象的 `monitorId` / `instUuid`。去掉关联拓扑等 Tab 内重复切换；可加只读「当前对象」摘要（非必须）。单据类 Tab 不纳入该切换器。
- 切到缺标识对象时：组件内明确提示、**不发起查询**（与整体显隐规则配合）。
- 懒加载达标实现：未进入过的 Tab 不 `import` 提供方组件、不发业务请求；首次激活再加载代码与数据；`import` 结果缓存；离开 Tab 默认保留实例；当前对象标识变化则按新标识重新拉数。失败由组件内重试；成功态刷新只走组件自带入口（监控视图时间选择器、关联拓扑画布工具栏），宿主不另挂刷新，资产信息成功态也不补刷新。不以「仅数据懒、组件壳提前 import」为达标，不以「每次激活强制刷新」为默认。

### CMDB 资产详情宿主

- 保留现有「关联关系 / 拓扑 / 应用拓扑」等文案与能力，不改名为「关系结构（可编辑）」一类别名。只动默认「拓扑」槽；list / network（网络拓扑）/ appOverview（应用拓扑）/ ipam / rack / room 一律不动。监控视图、告警列表、3D 等其它公开入口不动。网络状态拓扑侧栏保留，并在关联关系 Segmented 与「网络拓扑」并列一项（不替换 network）。
- 关联拓扑与默认「拓扑」**二选一替换**，不再侧栏/菜单另挂「关联拓扑」：`ops-analysis.relatedTopology` 已声明可加载 ∧ 有 `instUuid` 时，「关联关系」Segmented 仍叫「拓扑」（`t('topo')`，value 仍 `topo`），内容改为公开关联拓扑（带告警健康）。不满足则继续渲染 CMDB 默认拓扑，行为与现网一致。加载失败回退默认拓扑；组件已挂上后的空/失败留在组件内。旧直链 `/cmdb/assetData/detail/relatedTopology` 兼容跳到关联关系并落到 `tab=topo`。告警详情仍叫「关联拓扑」，不另起「健康拓扑」等别名。
- 监控视图 / 告警列表：宿主读取资产已有稳定联动（实例 `monitor_id` 或同等只读映射）；**按现网单值收紧**，且须已购运营分析 ∧ 监控已购且组件已声明，非空才展示并把该值作为 `monitorId` 传入。无映射 = 未联动，或未购 OA → 不展示入口、不发起监控查询。禁止名称 / IP 反查。本期不做一对多默认选择器；若未来出现稳定多值映射，再单独立项（宿主选择 / 切换，组件每次仍只收一个 `monitorId`）。
- 网络状态拓扑：`is_network_device_model`（现有 network 主题规则）∧ 有 `instUuid` ∧ OA 授权且组件已声明。不另维护平行 model 白名单。侧栏入口保留，点击落到关联关系 Segmented 的「网络状态拓扑」项（本页仍有切换条，不替换原网络拓扑）。旧直链 `/cmdb/assetData/detail/networkStatusTopology` 兼容跳到关联关系并落到该 Tab。不满足则 Segmented 不出现该项，侧栏也不出现。
- 3D应用：`model_id === 'system'` ∧ 有 `instUuid` ∧ OA 授权且组件已声明。`application` 详情本期不挂 3D；宿主不沿关联反查父 `system`。不要用 `app_overview` 主题（含 `application`）当 3D 闸门。
- 运营分析未购买、未授权或组件未声明时，不展示对应入口，不影响 CMDB 原有能力（含默认拓扑回退）。

### 运营分析画布宿主

- 关联拓扑登记为**新的 scene widget 类型**（如 `relatedTopology`），与 `networkStatusTopology` / `topologyMap` 并列；不挂子类型，不用普通图表 + DataSource。
- 配置器用现有资产实例列表选 1 个实例 → 绑定 `instUuid`；运行时复用现有 RelatedTopology 领域编排（关系 / 监控映射 / 告警叠层在组件内）。资产列表数据源只负责参数选择。
- 表面：Dashboard + Screen；Report、分享态不支持。
- 配置态：`instUuid` 编辑时可空 → 画布占位提示且不查数；保存时强制必选。

## Testing Decisions

好测试只锁对外行为：声明键是否可被探测、入口显隐是否只依赖模块级探测 + 稳定标识 / 模型闸门、组件是否只收到约定单值入参、宿主是否禁止静态依赖提供方内部模块、懒加载是否在首次激活前不发业务请求、失败与空态是否可区分。不锁画布内部事件名、不锁具体 DOM 结构、不把「看起来像不像」当单测。

最高接缝优先（沿用第一实验与 `appCapabilities` 既有风格）：

- **目录与探测**：六键已声明 / 未声明 / 模块不可用时的探测结果；按键粒度失败不得被误当成「整模块其他键也不可用」之外的错误显隐（未购模块则整组不可用）。
- **隔离**：告警详情页 / 抽屉、CMDB 详情宿主不得静态 import 提供方 `@/app/*` 业务实现；经 `useAppCapability`（或同等目录接缝）按需加载。先验：告警关联拓扑 isolation 测试。
- **告警宿主**：页与抽屉 Tab 序一致；公共 Tab 在告警级有标识才出现，且跨模块 Tab（监控视图、资产信息）还须已购 OA；统一切换器列出全部快照对象；当前对象缺标识时组件不发查询；对象标识变化触发重拉；单据 Tab 不依赖该切换器。
- **CMDB 宿主**：无监控联动或未购 OA 不出监控两入口；网络设备闸门跟 `is_network_device_model`；3D 仅 `system`；`application` 不出 3D；侧栏无独立「关联拓扑」；默认「拓扑」槽在声明 ∧ `instUuid` 时挂公开组件，否则及 loadFailed 回退默认拓扑；网络状态拓扑侧栏保留，且关联关系 Segmented 在「网络拓扑」旁并列该项（不替换）。同模块自用（监控主场、OA 画布）不加跨模块 OA 门。
- **监控组件**：仅 `monitorId`（及可选 `metricKey`）可驱动监控视图自举；告警列表数据口径不触及告警中心单据 API。
- **CMDB 基础信息**：只读、无写入口；`instUuid` 无权 / 不存在时组件内失败可区分。
- **关联拓扑**：复用第一实验拼图与角标口径断言；新覆盖 CMDB 宿主与画布 scene 配置（编辑可空不查、保存必选；Report / 分享态不可用）。
- **网络状态拓扑嵌入**：单 `instUuid` → 固定一跳、无跳数切换 UI；与画布可配跳数可并存但不要求 props 同形。
- **3D嵌入**：**验收完成态**断言查询侧按单应用收窄（或等价的不加载全量墙）；「全量再过滤」不得当作完成态绿灯。交互仍可进入聚焦 → 详情 / 部署架构。

手测（不替代单测）：告警多对象切换与缺标识提示；未购 OA / 监控时宿主降级；CMDB 网络设备与 `system` 条件入口；画布关联拓扑保存校验；3D 单卡墙非全量墙。

## Out of Scope

- 通过 IP、名称等非稳定字段补齐 `monitorId` 或 `instUuid`
- 用关联拓扑替换 CMDB 关联关系列表、网络拓扑或二维应用拓扑（默认「拓扑」槽在条件满足时二选一替换，见宿主段）
- 用 3D应用替换 CMDB 二维应用拓扑，或在 CMDB 以加载全量 3D 应用墙作为交付
- 宿主直接调用其他模块 NATS 并重新拼装业务组件
- 关联拓扑在 Report 和分享态中使用
- 告警列表嵌入态强制禁跳 / 仅抽屉预览（可另项）
- CMDB 监控联动一对多选择器（可另项）
- 网络状态拓扑 / 3D 的 embed 专用新后端（先适配层收口；不足再另项）
- 改写告警概述 / 事件 / 变更记录 / 处理动作的业务内容
- 将公开业务组件提升进 `src/components` 或 iframe 全页冒充嵌入

## Further Notes

- 本变更在第一实验 `ops-analysis-related-topology-embed` 之上扩展：关联拓扑从「告警抽屉实验」升级为目录化公开组件，并增加 CMDB 与画布宿主；告警侧对象切换从 Tab 内收口到详情级统一切换器。第一实验中「未把该件登记进画布」的限制由本变更显式打开（仅 Dashboard / Screen）。
- 「可以加载」是模块声明与组件键可用性，不是「这台资产有没有邻居 / 有没有指标」。缺标识是绑定门；资源无权是组件内权限门；二者与售卖门分开。
- 告警列表与拓扑告警叠层均以**监控中心告警**为准；告警中心单据只决定人站在哪条处置记录上，不进入列表或角标过滤条件。
- `cmdb_id` / 联动 `monitor_id` 来自既有快照或只读映射；本变更不负责补写历史，也不在打开详情时回查补全。
