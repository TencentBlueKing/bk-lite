# 智能体导入导出

Status: done

## Problem Statement

管理员在一套平台上配好的智能体，不能带到另一套平台。智能体上的提示词、引导语、勾选的工具、技能包和 MCP 都留在本环境。直接整份复制又会把连接密码、模型、知识库、渠道和工作台一起带走，换平台之后对不上，也容易把凭据交出去。

## Solution

有设置编辑权限的人，可以把一个智能体下载成一个 ZIP。有新建智能体权限的人，在智能体列表把这个 ZIP 导入当前组织，得到一条新的智能体，并进入它的设置页去选模型。内置工具和内置技能包按本平台已有的目录挂上。用户导入的技能包用 ZIP 里的原始包另存一条。MCP 带上链接、传输方式、描述、标签和参数定义，不带令牌和参数值。源 MCP 开过认证时，用户到工具页补凭据。当前版本没有文件里点名的内置工具或内置技能包时，整单不导入，并提示升级。

## User Stories

1. As a 能编辑智能体设置的管理员, I want 在卡片「更多」里或设置页把这个智能体下载成一个 ZIP, so that 我可以把它交给另一套平台。
2. As a 能新建智能体的管理员, I want 在列表「新建」旁边上传这个 ZIP, so that 当前组织里多出一条智能体，并打开设置页让我选模型。
3. As a 导入的管理员, I want 内置工具按名称挂上、内置技能包按包标识挂上，连接参数和技能包变量是空的, so that 我在本平台重新填写地址和密码。
4. As a 同时有工具新增权限的管理员, I want 用户导入的技能包各存成一条新包，MCP 写好链接、传输方式、描述、标签和参数定义, so that 不会盖掉本平台已有的同名包，也不会把令牌带过来。
5. As a 导入的管理员, I want 本平台没有文件里的内置工具或内置技能包时整单失败并提示升级, so that 我不会得到一条缺能力的智能体。
6. As a 导入的管理员, I want 传错文件时什么都不新建，某个技能包 ZIP 打不开时只跳过那个包, so that 我能分清整份文件无效和单个技能包损坏。
7. As a 没有工具新增权限的管理员, I want 只含提示词和内置能力的文件仍能导入，带了自定义技能包或 MCP 的文件被拒绝并写明缺的权限, so that 导入不会绕过工具页的新增权限。
8. As a 管理员, I want 知识库、记忆、渠道、工作台、历史对话和各类密码都留在原平台, so that 换平台只带走能重新配置的配方。

## Implementation Decisions

- 一次只处理一个智能体，一个 ZIP。不做批量。列表页「新建」旁边提供导入，有新建智能体权限才显示。卡片「更多」菜单的顺序是编辑、导出、删除。设置页底部「保存」旁边提供导出。两处导出都要有该智能体的设置编辑权限才显示，并且下载同一份 ZIP。
- ZIP 里是一份智能体说明，加上每个带上的非内置技能包原始 ZIP。说明中包含名称、简介、提示词、引导语、提示词参数、保留条数、每步调用次数、勾选的内置工具名、勾选的内置技能包标识及内置标记、MCP 的名称、链接、传输方式、描述、标签、参数定义（类型、变量名、是否必填），以及源 MCP 是否开过认证。
- 提示词参数里，文本值随文件走。密码类型只保留参数名和类型，值为空。工具挂在智能体上的连接参数、技能包变量不进文件。模型、组织、知识库、记忆体、强制知识库回答、允许通过对话修改知识库、聊天历史开关、渠道发布、工作台挂载、历史对话不进文件。温度以及设置页保存时写死的展示和技能类型字段也不复制，新智能体沿用空白新建的默认。
- 聊天历史开关不在文件里。导入后的智能体按空白新建的默认打开聊天历史，保留条数用文件里的数字。
- 导入写入的管理组和使用组都是导入用户浏览器 cookie 里的当前组织，两边都只含这一个组织。cookie 缺失，或该用户不在这个组织里，整单失败，不写入。新建的技能包和 MCP 的管理组同样是这个组织。新记录的域取导入用户的域，不取文件里的域。
- 当前组织已有同名智能体时仍新建一条，名称后加十进制序号直到不重名，不修改已有的那条。MCP 的名称在全平台唯一。重名时同样加序号后新建，不修改已有 MCP。结果里使用加序号之后的名称。
- 内置工具按目录中的稳定名称精确匹配，不用技能包依赖工具那套名字包含比较。内置技能包按包标识匹配本平台标记为内置的那一条，不比较版本，不携带技能包正文。任一勾选的内置工具或内置技能包在本平台找不到时，整单失败，列出缺少的名称，提示升级版本，此时不新建智能体、技能包或 MCP。
- 技能包清单里的依赖工具不参与这次失败判断。当前随版本提供的内置技能包没有填写依赖工具。依赖工具仍只在对话运行时提示。
- 非内置技能包优先携带原始 ZIP。没有原始 ZIP 但数据库里有技能正文时，导出按同一份 SKILL.md 压缩包带走，对话生成的技能因此能再导入。导入时新建一条技能包，包标识用新的 uuid，不覆盖已有行。本域已经有同名技能包时，新包名称加十进制序号，旧包不变，说明里写下调整后的名称。新行仍把这份 ZIP 存成可再次导出的原始 ZIP。没有正文，或 ZIP 打不开时，这个技能包不挂到新智能体上，导入继续，结果里写明名称。
- MCP 新建时写名称、链接、传输方式、描述、标签和参数定义。参数值写空。不写令牌，不打开认证开关。源 MCP 开过认证时，说明里记下这一笔，供设置页提示用户到工具页补令牌。工具页在启用认证且令牌为空时仍拒绝保存，用户补上令牌后才能保存。
- 权限沿用现有检查。导出要求设置编辑。导入要求新建智能体。文件里含非内置技能包或 MCP 时，还要求工具新增。缺任何一项则整单失败，并写明缺哪项权限，不写入。只有提示词和内置能力时，不要求工具新增。
- 检查顺序是先认出外层是不是智能体 ZIP，再查权限和当前组织，再查内置目录，通过之后才写入。外层无法识别时整单失败，提示文件无法识别，不进入设置页。内置目录不齐也在写入之前失败。内层技能包缺失或损坏发生在写入过程中，不回滚已经通过目录检查的智能体，只跳过该包。
- 成功导入后进入新智能体的设置页，模型为空。页面同时显示这次说明。名称加过序号、MCP 需要补令牌、密码参数为空、技能包没挂上，都写在这份说明里。硬失败停在列表，不进入设置页。

## Testing Decisions

- 测用户能看到的 ZIP 内容和导入后的智能体、技能包、MCP，以及失败时有没有留下新记录。不测压缩包内部的私有目录布局。
- 最高缝是列表导入和设置页、卡片导出都会调用的那次导出与导入。卡片和设置页导出同一份内容。组件测试只锁定按钮位置和权限下是否出现。
- 导出的 ZIP 含提示词、简介、引导语、文本参数值和保留条数。不含模型标识、组织、知识库、记忆体、渠道、工作台、历史对话、工具连接参数、技能包变量、密码参数值和 MCP 令牌。用哨兵字符串确认这些值不出现在 ZIP 里。
- 导入后的管理组、使用组等于请求 cookie 中的当前组织。同组织重名时新智能体名称带序号，旧智能体不变。模型为空。聊天历史按空白新建的默认打开。
- 内置工具按稳定名称挂上且没有连接参数。内置技能包按包标识挂上已有内置行。本平台缺少其中任何一项时，响应提示升级，数据库不新增智能体、技能包或 MCP。
- 非内置技能包导入后是新的包标识。本域已有同名时新名称带序号，旧包正文不变。对话生成且有正文的技能包会进入文件并在导入后挂上。再次导出新智能体时，这个新包的原始 ZIP 仍在。没有正文或 ZIP 损坏时，新智能体存在，该包未挂上，说明里有它的名称。
- MCP 写入链接、传输方式、描述、标签和参数定义。参数值为空，令牌为空，认证开关关闭。源 MCP 开过认证时，说明里点名新 MCP，并提示到工具页补令牌。全平台重名时新名称带序号，旧 MCP 的链接和令牌不变。
- 没有工具新增权限时，只含内置能力的文件可以导入。带非内置技能包或 MCP 的文件整单失败并指出缺的权限。没有设置编辑权限时不能导出。无法识别的外层文件整单失败且不落库。
- 技能包清单写了依赖工具、而本平台没有同名工具时，不因此失败。
- 先前测试可沿用技能包 ZIP 导入、内置技能包播种，以及智能体创建时当前组织和重名校验的做法。技能包页面「同标识同版本覆盖旧行」的测试保持原样，本变更不改那条路径。

## Out of Scope

- 一次导出或导入多个智能体。
- 为对话生成或本地目录导入的技能包另做一种打包格式。
- 改变技能包页面 ZIP 导入的覆盖规则。
- 把渠道、工作台、知识库正文、记忆内容、历史对话或模型选择放进文件。
- 用技能包依赖工具决定是否提示升级。
- 经 OpenAPI 网关新增对外导入导出端点。本变更只服务已登录控制台。
- 导入后自动替用户选定模型，或自动发布渠道、挂上工作台。

## Further Notes

- 这份约定来自 2026-11-25 的范围对齐。模板目录已经规定内置模板只带提示词、开场白、工具名和可移植行为参数。本变更是用户把自己的智能体带走，比模板多了简介、引导语、保留条数、调用上限、勾选结果、原始技能包和非内置 MCP 的链接，仍然不带凭据和环境绑定。
- 「技能包同域共用」规定技能包页面按包标识、版本和域再次导入时覆盖那一行。智能体 ZIP 里的非内置技能包不走那条覆盖，而是另存。技能包页面的导入保持覆盖。

## Review corrections

2026-11-26。导出除了模块级设置编辑权限，还校验当前组织 cookie，并用与设置编辑相同的对象权限拒绝其他组织或不具备实例 Operate 的智能体。技能包主键必须属于本域，且与绑定的包标识或名称一致，否则忽略主键，只在本域按清单 id 或名称查找。内置技能包仍可按包标识匹配，不带正文。工具和 MCP 不取其他组织的行。找不到的非内置工具不写入内置工具名，名称记入 `omitted_tools`，导入说明里点出该名称。外层智能体 ZIP 和内层技能包设有编码大小、条目数和解压体积上界，超限则整单失败。导入读取上传文件时带上界。
