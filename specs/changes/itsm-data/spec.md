# ITSM 表单与集成

Status: done

表单设计人可在「表单与集成」管理表单模型、数据字典、数据表和集成。在流程中选择模型后，字段从流程版本快照读取。字典适合维护枚举或树形选项，数据表适合维护多列业务记录，集成用于调用网关、外部 API 或 Python 动作。[表单设计](../itsm-form-designer/spec.md) · [集成配置和执行](../itsm-integrations/spec.md)

## 资源操作

- 字典项可新增、编辑和删除；层级关系必须有效。数据表可以配置列名和类型，逐行新增、编辑和删除。变更列定义时校验已有数据，不兼容的修改应提示原因，原值保留。
- 字典与数据表的「导入」均从列表发起，无需先选实例。成功后创建带独立标识的新资源，原资源继续可用。数据表导入保留字段名，普通 Excel 可按表头和单元格推断列类型。
- 资源和记录在当前域内读写。直接请求其他域的表或行也须校验访问范围。

## 设计器允许哪些字段取数

| 字段 | 用途 | 来源 | 结果或映射 |
| --- | --- | --- | --- |
| 单行文本、多行文本、数值 | 自动填值 | API、Python、数据表 | 文本接收字符串，数值接收有限数值 |
| 单选框、复选框、单选下拉、多选下拉 | 选项来源 | 字典、数据表、API、Python | 映射显示字段和选项值 |
| 单选级联、多选级联 | 选项来源 | 字典、API、Python | 返回树形选项并保留父子关系 |
| 表格、嵌套表格 | 行数据来源 | 数据表、API、Python | 返回对象数组，映射到已定义的目标列 |
| 其余字段 | 使用字段自身配置 | 无动态取数来源 | 设计器隐藏取数配置，服务端拒绝不支持的绑定 |

只有单选框、单选下拉和单选级联支持选中后填充其他字段。字典无需输入参数和列表路径，未经加工时按固定的 `label/value` 读取。数据表无需列表路径。Python 接收 `rows` 和 `params`，前者为对象数组或表格字段引用，后者为对象。

## 验收

1. 编辑已有数据的表，分别保存兼容和不兼容的列定义；核对字段定义和历史行。导出后从列表重新导入，核对原表、新表及行值。[数据表用例](../../../server/apps/itsm/tests/test_data_table_edit.py) · [字典用例](../../../server/apps/itsm/tests/test_dictionary_edit.py)
2. 在表单设计器选择来源、测试取数并选取返回字段；保存后在表单预览或业务表单检查显示值。对级联绑定数据表、向数值字段返回字符串、向表格映射不存在的列，校验须失败。[字段取数规格](../itsm-field-fetch/spec.md) · [能力与类型校验](../../../server/apps/itsm/tests/test_field_capabilities.py)
