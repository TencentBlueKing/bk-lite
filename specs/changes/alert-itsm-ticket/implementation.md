# 告警转 ITSM 工单实施

Status: implemented

已确认范围：单条告警建一张工单，详情按本地工单 ID 查回编号和状态。`end_at` 有值时只展示「工单已关闭」，不关闭告警。不展示工单链接。分派、认领、恢复、关闭可选，只追加评论。

## 接口

基址为团队 ITSM 集成里已保存的地址。认证使用已保存的 Bearer 令牌。

| 步骤 | 调用 | 成功 |
| --- | --- | --- |
| 连接测试 | `GET ticket_list/?page=1&page_size=1` | HTTP 200 且 `code=20000`。不要求 `result` |
| 读取字段 | `GET ticket_form/?workflow_key=` | 从 `canvas_data.form_data.layout` 取字段。跳过 `row`、`group`、`tab`、`tab-panel` |
| 建单 | `POST ticket_create/`，带 `workflow_key`、`is_submit=true`、`form_data` | 保存 `data.id` |
| 同步 | `GET ticket_detail/{id}/` | 读 `data.ticket` 的 `id`、`sn`、`title`、`status`、`status_display`、`end_at` |
| 留言 | `POST ticket_comment/` | HTTP 201 且 `code=20100` |

`end_at` 为空时展示 `status_display`。`end_at` 有值时展示「工单已关闭」。告警状态不变。

不调用 `ticket_update`、`ticket_handle`、`tickets_revoked`。

## 页面

- 全局配置保持现有地址、令牌、测试和启用。
- 处理规则动作类型为 ITSM 时，「创建」必选且不可取消。分派、认领、恢复、关闭可勾选。流程标识手填，可读取字段。`ticket__title` 默认来自告警标题。没有「工单关闭后关闭告警」。
- 告警列表在已有工单 ID 时显示「已关联工单」，不替换状态列。
- 详情展示工单 ID、单号、标题和状态。失败可补建，结果待确认可核查，留言失败可重发。没有工单链接，没有关闭告警按钮。
