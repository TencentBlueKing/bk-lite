# 字段取数与联动

用户已批准：动态选项、字段填值、表格填充、API 后接 Python 转换、参数/结果映射、预览与提交校验。

## 实施顺序
1. 定义字段 fetch 绑定；发布时固定配置、脚本和映射，禁止写操作作为字段取数。
2. 后端按服务/工单上下文解析已发布字段，用填单者身份执行；不接受客户端集成 ID。参数支持表单、用户、组织、关键词、分页。
3. 返回映射结果及短期签名校验证据；提交验证身份、依赖参数、绑定版本、选项和值，取数失败不放行。持久化显示快照。
4. 设计器增加取数与联动配置，支持数据字典/数据表/集成、输入绑定、可选 Python 转换、结果映射与测试。
5. 运行表单支持防抖搜索、分页、依赖联动、旧响应丢弃、手动刷新；历史单据用快照，保护手工修改。
6. 运行后端/前端测试及本地 API→Python→字段→提交闭环。

## 边界
- API 只允许 GET，或声明 View 权限且路径为明确查询语义的 POST。不能以“用户声明只读”绕过网关权限。
- Python 保持隔离 transform(rows, params) 协议；不允许字段配置任意本地代码执行。
- 字段签名只包含必要映射结果，不向浏览器泄露脚本源码、令牌或无关 API 数据；绑定的集成停用后拒绝取数。
- 动态选项签名有效期 15 分钟，过期提示刷新；缓存 30 秒、按身份权限/参数/版本隔离，提交仍验证绑定有效。

## 按来源和字段用途展示参数（2026-11-16）
- API 参数复用网关 Serializer 的 JSON Schema，显示类型/必填提示，并使用数值、布尔、枚举或文本控件。参数名固定，不再要求用户猜接口入参。
- Python 明确区分输入数据 rows（可选择表格字段）和脚本参数 params；返回列表无需额外列表路径。

## 字段能力边界（2026-11-16 已实现）
依据 ITSM4 `frontend/src/components/form-edit/config-panel/index.vue` 的 properties 驱动机制、`components/properties/field-options.vue` 的选项来源，以及 `components/fields/{number,table,nested-table,task,cab,calculate,user}/index.ts` 专属属性。
- 文本/多行文本/数值：API、Python、数据表，仅填充值；这是本次已授权联动能力的扩展，不将 ITSM4 数值字段描述为原生选项控件。
- 单选/多选/单选框/复选框：自定义、字典、API、Python、数据表，仅选项。
- 单/多级联：自定义、树形字典、API、Python，仅树形选项；普通数据表不直接生成层级。
- 子表单/嵌套表格：API、Python、数据表，仅行数据及列映射。
- 日期时间、人员/组织/CMDB/配置项、计算、任务/CAB、子流程、附件/签名、富文本/链接、布局说明等：保留专属配置，不开放通用 fetch。
- 后端能力目录为唯一运行时来源，前端按目录展示。发布、调试、取数、提交均校验同一能力约束；不支持的旧配置提示移除，不静默丢弃。
