# 联动配置简化：页面验收（2026-11-16）

## 实现范围

- 选项字段使用“选项来源”；文本/数值使用“自动填值”；表格使用“行数据来源”。
- API/Python 先测试获取受限样本，再下拉选择返回列表、名称/值、填充值或列映射；数据表直接提供列选择。
- 数值映射只列数值字段，文本映射只列字符串字段；树节点映射不列 children 内部路径。
- 输入行、脚本参数、完整 JSON、手动路径、后置加工、触发方式及调试表单值放高级设置。
- 单选字段的“选中后填充其他字段”独立折叠区。
- 样本探查仅限 form-Edit 预览，不签发提交凭据，不放宽发布/运行时映射校验；样本截断为每层最多 3 行、50 字段、10 层、64 KB。
