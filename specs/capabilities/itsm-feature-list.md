# ITSM 新增功能清单

清单覆盖 `93bf3c39ce..724ab18b7d` 的 84 条提交及本轮预置安装修复。以下按用户能完成的任务列出功能；是否会在新环境生成数据，见[初始化清单与实测](itsm-initialization.md)。

| 模块 | 新增功能 | 使用入口或前置条件 |
| --- | --- | --- |
| 服务门户 | 按服务目录和关键字找服务，收藏、最近使用、快速提单；管理员可编排九类组件和背景。服务可限定用户或处理组。 | 服务须启用，流程须有已发布版本。[门户规格](../changes/itsm-portal-workbench/spec.md) |
| 新环境开通 | 请求、事件、问题三个流程各带独立的基础表单。服务管理员选择本域有效处理组后启用；初始化重跑保留已有草稿及已发布版本。 | [安装、启用与验证](itsm-initialization.md) |
| 工单中心 | 个人展示列、分页、排序、系统和动态表单字段筛选、个人分组、我的待办／历史／关注；批量处理只提供所选工单共有的操作。 | 从单号或标题进入详情，也可从列表打开快速提单。[列表规格](../changes/itsm-ticket/spec.md) |
| 工单协作和导出 | 复制单号、关注通知、彩色标签、双向关联及解绑、评论、附件、当前节点和流转日志；后台导出可选系统列和表单字段、查记录、下载。 | 操作、字段和下载受权限约束。[详情交互](../changes/itsm-ticket/detail-experience.md) · [导出契约](../changes/itsm-ticket/spec.md#后台导出) |
| 表单与集成 | 复用表单模板，维护字典项、分层选项、数据表结构及记录；全局导入、实例导出。字段分别支持选项来源、自动填值或行数据来源。 | 按字段类型选择字典、数据表、API 或 Python，测试后映射返回字段。[字段能力表](../changes/itsm-data/spec.md) |
| 集成和平台接口 | 配置平台网关或外部 API、在线调试、上传并测试 Python 动作、对接外部待办；提供按组织授权的 OpenAPI 和内部 NATS 建单入口。 | 先配置所需凭据、网络及执行器。[集成规格](../changes/itsm-integrations/spec.md) · [平台接口](itsm.md#平台调用入口) |
| 流程设计 | 流程草稿、发布、版本管理、全局导入；模板复制、按节点预览、处理人和签核方式、节点字段权限、按钮名称和顺序、必填意见、转交范围及历史回退。 | 配置保存在草稿，发布后的版本供工单使用。[流程设计](../changes/itsm-workflow-designer/spec.md) · [节点配置](../changes/itsm-node-form-design/spec.md) |
| 流程运行和恢复 | 人工节点、分支／并行汇聚、通知、决策、自动派单及子流程；支持认领、转交、挂起恢复、退回、重开和长图定位。启动、人工操作和自动作业分别保留恢复证据。 | 有办理权限才可推进。回执未知时先核对，已成功的外部动作不能因重试再执行。[异常恢复](../changes/itsm-ticket/spec.md#异常恢复) |
| 自动化与时效 | 决策表、触发事件、包含／排除范围、组合条件、顺序动作和执行记录；单次／周期建单与防重；工作日历、SLA 预警、超时升级、挂起停表。 | 配置规则并运行对应后台任务。[自动化与时效](../changes/itsm-rule/spec.md) |
| 消息 | 站内待办和工单通知、按通道路由、飞书等 IM 复用平台账号关联；触发器可选接收人、渠道及模板或自定义正文，渲染工单变量和详情链接。兼容的手工映射在重新同步后保留。 | 渠道和外部账号需由租户绑定。[通知投递](../changes/itsm-rule/spec.md#工单事件触发器) |
| 应用与设置 | 知识文章支持富文本、Markdown、分类、附件和关联工单；值班排班、变更窗口冲突校验、批量交接和失败项重试；处理组、代理、VIP、满意度问卷快照、打印预览、通知模板、公告和基础设置。 | 业务应用在「业务协作」中使用，模板和租户参数在「管理设置」维护。[应用](../changes/itsm-apps/spec.md) · [设置](../changes/itsm-settings/spec.md) |
