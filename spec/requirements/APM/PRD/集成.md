当前接入概要：Server 根据有权访问的云区域生成无状态 OTLP/HTTP 4318 配置；Node.js、Java
和 Python 提供自动探针入口，Go 明确为手动 SDK 接入；Host、Docker 与 Kubernetes 均提供
运行时身份配置，其中 Kubernetes 使用 Downward API Pod UID。区域入口只向受信区域内网
开放，当前不提供应用级 Token。Collector、自建 OTel Collector、OBI 和 Operator 等独立接入
流程不属于当前 P0，不能只凭本历史文件宣称已支持。
