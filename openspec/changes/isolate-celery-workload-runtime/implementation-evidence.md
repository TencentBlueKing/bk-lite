# 架构实施记录（2026-10-30）

## 已实现范围

- 公共精确任务名路由：本地 88 项定义，四类队列，原 celery 队列由后台承接；无业务任务函数、模型、参数或频率修改。
- 同一配置解析器管理四池 MIN/MAX、最大总预算、同构实例数及 Beat 归属；缺失/冲突/超预算启动前失败，没有固定并发 1 的生产推荐。
- release 生成唯一 supervisor 配置；开发入口复用解析器。threads 改为受限 prefork autoscale，预取为 1，保留 ACK/retry，不隐式启用子进程回收。
- 公共 prefork 兼容池：保留任务声明，在执行池边界忽略原 threads 不支持的超时/回收参数；预检与运行报告校验兼容池类型，已有 MLOps 七项超时声明不再阻断全模块启动。
- 公共发布/执行观测，有界聚合与采样，不含业务参数；只读报告包含注册、有效路由、消费者和可用资源摘要，未知值不当零。
- Beat 路由工具默认 dry-run，仅通过 ORM 修改明确名单的三个路由字段；变更前快照、行锁、恢复前冲突校验；管理命令注册任务时禁止隐式同步周期表。
- [运行手册](../../../docs/celery-runtime-runbook.md)和专用配置模板已更新，包含容量核算、历史队列排空及回滚步骤。
