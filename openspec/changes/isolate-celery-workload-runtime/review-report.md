## 一致性与内存边界（WARNING）

保持架构范围，不改业务函数、模型、频率、ACK/retry。四池加既有三个专用worker使完整安装有7个主进程（原4个）；MIN/MAX伸缩不消除主进程成本，也不隔离共享数据库/CPU/磁盘。原生内存回收只在任务结束后检查阈值，不能保证在途任务不超过内存预算。

Beat路由修改仅调整三个显式字段；上游所有权指纹不自动刷新，因此按人工接管处理，不冒充配置管理。发布需按消费者先就绪、生产者/唯一Beat切换、历史队列排空的顺序演练，回滚保留新旧队列消费者；不得purge、批量重投或强杀繁忙任务。
