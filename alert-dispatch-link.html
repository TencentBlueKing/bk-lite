2. 关键设计点

# 节点 / 边 设计意图
① 单例锁 AGGREGATION_LOCK_KEY 防两次聚合并发对同一 fingerprint 重复建警(Alert.fingerprint 无唯一约束、select_for_update 只锁"更新"不锁"建新")
② 两条平行路径 路径1 常规指纹聚合,路径2 会话窗口超时转正,都产生"新可分派告警"
③ outbox 必经中间层 enqueue_outbox 走 get_or_create(idempotency_key) + transaction.on_commit 再发 celery —— 解决"聚合事务未提交 celery 已跑"和"重复派发"
④ target 节点自循环 (关键设计) 收到 > 200 alert_ids 时按 200 分片,重新入 outbox 队列(tasks.py:215-220),不会无限递归(分片后每片 ≤ 200)
⑤ deliver 两个入口 正常路径走 on_commit -> deliver_alert_outbox.delay；失败重试路径走 dispatch_pending_alert_outbox(每分钟扫 PENDING + 到期)
⑥ payload 异常走 retry 节点 deliver_outbox_record 捕获后写 FAILED + next_retry_at = now + 2^attempts×15s(封顶 1h),attempts ≥ max_attempts 永久 FAILED
