# October 30, 2026 Release Notes
Release Date: October 30, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| RUM | Launched the RUM module to provide insight into website access and experience from real users. |
| RUM | Supported session replay and frontend error tracking, with Source Maps restoring error locations in the original code to help reproduce and diagnose issues. |
| RUM | Supported analysis of core experience metrics, including page loading, interaction responsiveness, and layout stability, with configurable experience alerts. |
| RUM | Supported conversion funnels and release comparisons to identify where users drop off and whether experience improves after a release. |
