# October 30, 2026 Release Notes
Release Date: October 30, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| Operations Analytics | Added a built-in Operations Overview dashboard to centralize operations data and alert trends. |
| Operations Analytics | Added a read-only Elasticsearch data source. Line and bar charts now support mapping category fields, multiple numeric fields, and series fields. |

### Improvements

| Module | Improvements |
| --- | --- |
| Operations Analytics | Canvases now support updates through YAML imports, with improved dashboard layout precision and wallboard component configuration previews. |
| Operations Analytics | Unified filter option queries can reference upstream parameters. Filters with the same name and type are merged into one row, and invalid inputs are not saved. When a canvas opens, initial option corrections are written to the applied initial values without triggering a search. Upstream changes only reload options and correct the draft; charts refresh only after Search is clicked. Invalid selections are cleared instead of automatically selecting the first option. Only the built-in 3D data center filter `server_room_id__string` automatically selects an option and searches after options load; the application system filter does not trigger an automatic search. |
