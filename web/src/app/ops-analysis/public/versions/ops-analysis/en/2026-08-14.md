# August 14, 2026 Release Notes
Release Date: August 14, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| Operations Analytics | Added a Connection Library, supporting reuse of MySQL, PostgreSQL, and REST connections to reduce repeated credential configuration. |
| Operations Analytics | REST and Excel data sources now support optional Python transformations, making it easier to convert raw data into component-ready structures. |
| Operations Analytics | Added card list, radar chart, event timeline, relationship topology, and other components to enrich dashboard and large-screen presentation options. |

### Improvements

| Module | Improvements |
| --- | --- |
| Operations Analytics | Dashboards now support responsive layout by container size, further improving component scaling, clipping, and report rendering. |
| Operations Analytics | Optimized Prometheus data sources, trend chart aggregation granularity, component error display, unsaved-change reminders, and related details. |
