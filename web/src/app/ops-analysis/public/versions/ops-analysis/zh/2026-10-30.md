# 2026年10月30日 更新日志

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| 运营分析 | 新增内置「运维总览」仪表盘，集中查看运维数据与告警变化趋势 |
| 运营分析 | 新增 Elasticsearch 只读数据源，折线图与柱状图支持分类、多个数值及系列字段映射 |

### 功能优化

| 模块 | 功能优化 |
| --- | --- |
| 运营分析 | 画布支持通过 YAML 导入更新，优化仪表盘布局精度与大屏组件配置预览 |
| 运营分析 | 统一筛选的选项查询可以引用上游参数。同名同类型并成一行；非法入参不会写入。打开画布时把首次选项校正写入已应用初值且不触发搜索。上游变化只重载候选项并校正草稿，点搜索后才刷新图表；选项失效时清空，不再自动选中第一项。只有内置 3D 机房筛 `server_room_id__string` 会在选项回来后选中并搜索；应用系统不自动搜索 |
