# August 26, 2026 Release Notes
Release Date: August 26, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| APM | Service onboarding: supported Java, Python, Node.js, and Go with language-specific onboarding guidance |
| APM | Service overview: view health status and availability and latency SLO compliance from application and service perspectives |
| APM | Service topology: display inter-service call dependencies and identify downstream services such as Redis and PostgreSQL even when they are not instrumented |
| APM | Trace analysis: search traces by time and service, with detail views supporting waterfall charts, flame graphs, and span lists |
| APM | Error analysis: aggregate errors by exception type for more direct failed-request troubleshooting |
| APM | Performance alerts: configure alert policies by error rate, latency, and throughput to discover service issues promptly |
