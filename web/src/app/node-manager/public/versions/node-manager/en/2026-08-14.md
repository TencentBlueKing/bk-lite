# August 14, 2026 Release Notes
Release Date: August 14, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| Node Management | Added support for remote Windows node installation, requiring Windows Server 2016 and PowerShell 5.1 or later. |
| Node Management | Node creation now supports on-demand synchronization to CMDB and Monitoring, helping unify host identity and observable objects. |
| Node Management | Node deletion and uninstallation now support synchronized handling of related objects, reducing residual assets and invalid monitoring instances. |

### Improvements

| Module | Improvements |
| --- | --- |
| Node Management | Optimized exception handling for offline images, object storage, temporary files, and related paths, making installation and download flows more reliable. |
