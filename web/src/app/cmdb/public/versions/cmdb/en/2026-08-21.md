# August 21, 2026 Release Notes
Release Date: August 21, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| CMDB | Added scanning with support for batch scans across multiple credentials and IP ranges, currently for network device SNMP and host SSH. |
| CMDB | Scan discovery now supports generating collection tasks and pushing them to Monitoring, smoothing the flow from asset discovery to monitoring onboarding. |
| CMDB | CMDB and Monitoring linkage has been enhanced to write back monitor_id after monitoring synchronization succeeds. |
