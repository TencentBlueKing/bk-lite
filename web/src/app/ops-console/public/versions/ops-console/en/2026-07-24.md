# July 24, 2026 Release Notes
Release Date: July 24, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| System Management | User synchronization now supports configuring password rules for new users. |
| Monitoring | Host disk monitoring now supports filtering by file system type. |
| Operations Analytics | Data source parameters now support a "Date Range" type, unifying filter and canvas parameter binding. |
| Operations Analytics | The single-value component now supports date range in period comparison, with specific increment/decrement display. |
| Operations Analytics | Added a multi-value metrics component for displaying multiple metrics from the same data source. |

### Improvements

| Module | Improvements |
| --- | --- |
| System Management | Fixed an issue with the "Group Chat Assistant" notification channel integration. |
| CMDB | Fixed an issue where automatic host sync from node management could get stuck in historical tasks or fresh deployment scenarios. |
| Monitoring | Fixed a conflict when recreating a monitoring instance after deletion. |
| Alarm Center | Fixed an issue where organization information was lost when syncing alerts from the monitoring center. |
| Alarm Center | Fixed inaccurate matching when configuring assignment rules by alert source. |
| OpsPilot | The knowledge base has been fully upgraded to LLM Wiki mode, enabling automatic knowledge organization, conflict detection, and continuous evolution. |
