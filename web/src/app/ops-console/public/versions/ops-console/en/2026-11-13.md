# November 13, 2026 Release Notes
Release Date: November 13, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| CMDB | Cloud resource configuration collection now supports synchronizing cloud resource tags. |
| Monitoring | Nginx monitoring now includes cumulative request and connection counts and collection status, with optional VTS metric collection. |
| Monitoring | F5 BIG-IP monitoring now includes failover roles and configuration synchronization status, with alerts for synchronization failures and lost peer connections. |
| Alert Center | Alert enrichment now supports adding the owning application, application system, and responsible owner to identify business ownership and notification recipients. |
| Operations Analytics | Wallboards now support time-limited casting links for TVs and other devices, including expiration settings and link disabling or regeneration. |
| Operations Analytics | Added general-purpose CMDB, monitoring, and alert query data sources with conditional filtering and chart configuration. |
| OpsPilot | Agents now support unattended operation. |

### Improvements

| Module | Improvements |
| --- | --- |
| System Management | Users can now unbind their OTP authenticator from their profile. |
| CMDB | Improved asset attachment display and downloads, resolving inaccessible images in some environments. |
| Monitoring | Improved the MongoDB dashboard display of connections, cache, memory, and member status for clearer database troubleshooting. |
| APM | Improved aggregation queries for the home page, service metrics, and alert policies. |
| RUM | Improved queries for application overview, page performance, and session lists to provide a better experience with large data volumes. |
| Operations Analytics | Improved query and rendering performance for line and bar charts over long time ranges. |
| OpsPilot | Improved agent attachment handling, job result retrieval, and chat history display. |
