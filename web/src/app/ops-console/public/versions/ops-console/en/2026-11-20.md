# November 20, 2026 Release Notes
Release Date: November 20, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| System Management | Added a Super Auditor role with read-only access to data across all organizations and applications. |
| CMDB | Collection tasks can now be paused and resumed while retaining task settings and imported assets. |
| CMDB | Supported bulk handover of asset ownership using a specified user field. |
| CMDB | Asset lists now support quick filtering by related instances without opening advanced filters. |
| Monitoring | Added a dedicated SQL Server dashboard covering instance health, buffers and memory, I/O and storage, and waits. |
| Monitoring | Policy groups now support adding or removing policy templates and viewing the templates active on each monitoring instance. |
| Alert Center | Incident impact topology now supports expanding related assets and viewing current alerts for related applications and application systems. |
| Log Center | Added Grok patterns to log extractors, with built-in pattern search and extraction previews using historical logs. |
| Operations Analytics | Added a built-in Monitoring Overview wallboard showing monitoring coverage and unresolved alerts. |
| Operations Analytics | Added a built-in Network Device Summary wallboard showing network device status. |
| Operations Analytics | Wallboards now support saving a selected column from query results as a variable for component parameters. |
| Job Management | Target management now supports host credentials from System Management credential management. |
| Orchestration Center | Scheduled flows now support binding an execution account and organization, checking execution permissions before startup, and displaying the actual running organization in execution records. |
