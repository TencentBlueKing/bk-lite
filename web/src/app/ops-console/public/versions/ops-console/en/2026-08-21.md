# August 21, 2026 Release Notes
Release Date: August 21, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| System Management | System Management now supports locally adding users in batches, making batch account initialization more efficient. |
| Node Management | Added support for batch changing node organizations, making node ownership adjustments easier. |
| CMDB | Added scanning with support for batch scans across multiple credentials and IP ranges, currently for network device SNMP and host SSH. |
| CMDB | Scan discovery now supports generating collection tasks and pushing them to Monitoring, smoothing the flow from asset discovery to monitoring onboarding. |
| CMDB | CMDB and Monitoring linkage has been enhanced to write back monitor_id after monitoring synchronization succeeds. |
| Monitoring | Asset selection in alert policies now supports displaying column variables and resource_ip, making asset identification more intuitive during policy configuration. |
| Log Center | K8s log onboarding now supports configuring Namespace and Pod collection scopes, making collection boundaries more controllable. |
| Log Center | Alert policy queries now support field suggestions, making log alert condition configuration smoother. |
| Operations Analytics | Report canvases now support report types. |
| Operations Analytics | Canvas global filter conditions now support component-level customization. |
| Patch Management | Baseline compliance details now support multi-select and batch export, allowing evaluation details to be exported by host or patch perspective. |
| OpsPilot | Agents now support independent multi-channel publishing, including publishing to the platform for user access. |
| OpsPilot | Skill packages now support runtime environment variable parameter configuration. |

### Improvements

| Module | Improvements |
| --- | --- |
| System Management | Organization deletion has been changed to archive mode to avoid impacting associated assets and business data after direct deletion. |
| Node Management | Windows controller installation has been further enhanced with WinRM certificate configuration, failure diagnosis, and retry optimization. |
| Node Management | Existing services are now stopped before controller installation, reducing conflict risk during repeated installation or upgrades. |
| Monitoring | Optimized the batch application experience for alert policy templates, with clearer display of templates, instance scope, and alert conditions. |
| Log Center | Unified the log server-side timestamp contract to reduce query deviation caused by inconsistent time fields. |
| Operations Analytics | Optimized the large-screen network status topology component with linkage to Monitoring alerts and metrics. |
| OpsPilot | Optimized UI for conversation flow, thinking status, planning event display, and more. |
