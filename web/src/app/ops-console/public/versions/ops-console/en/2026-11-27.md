# November 27, 2026 Release Notes
Release Date: November 27, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| System Management | Added Tencent Cloud and Alibaba Cloud SMS and voice notification channels, supporting approved cloud provider templates. |
| System Management | Added module administrator and module auditor roles with application-level management or read-only audit permissions. |
| CMDB | Added Volcengine configuration collection for cloud servers, public IPs, load balancers, MySQL, PostgreSQL, and object storage. |
| CMDB | Collection tasks now support connectivity tests to check network access and credentials in advance. |
| Monitoring | Added RocketMQ monitoring, including Broker read and write rates and collection status. |
| Log Center | Added a Source Devices page that automatically discovers devices sending Syslog, shows recent reporting time and activity status, and links directly to log searches. |
| RUM | Session lists now support filtering by end-user ID and navigating from the session timeline to associated APM traces, connecting frontend experience with backend troubleshooting. |
| RUM | Application onboarding now supports configuring session sampling rates. |
| Operations Analytics | Bar charts now support stacking, line and bar charts support reference lines, and wallboard lists support automatic scrolling. |
| Operations Analytics | Ranking, pie, and bar charts now support sorting query results and limiting the number displayed to build Top N views. |
| Job Management | Job targets, scripts, and Ansible Playbooks now support bulk changes to their owning organization with a preview before submission. |
| Orchestration Center | WeCom group bots now support sending files directly. |
| OpsPilot | Agents can now be exported and imported into the current organization to reuse prompts, tools, and skill package settings. |
| OpsPilot | Supported rating answers and providing feedback, and generating and exporting historical analysis reports by time, channel, or selected conversation. |
