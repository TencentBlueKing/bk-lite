# August 7, 2026 Release Notes
Release Date: August 7, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| System Management | Added WeCom integration, supporting user synchronization, login authentication, and IM notifications. |
| System Management | Added support for configuring the default password policy for new platform users. |
| Monitoring | Added process monitoring to track process status and runtime conditions. |
| Monitoring | Auto-discovered object cleanup policies now support minute-level automatic cleanup. |
| CMDB | Added UIS auto-discovery to improve asset onboarding efficiency. |
| Patch Management | Added built-in public YUM, DNF, and APT patch repositories. |
| Operations Analytics | Extended report subscriptions to large-screen scenarios with support for explicitly refreshing snapshots. |

### Improvements

| Module | Improvements |
| --- | --- |
| Monitoring | Optimized the network probing view to display probing nodes and target information. |
| Monitoring | Optimized PostgreSQL monitoring with support for specifying the connection database. |
| Alert Center | Optimized the instance deletion flow to automatically synchronize and close related alerts. |
| Alert Center | Fixed sub-object alert name display and no-data aggregation issues. |
| CMDB | Fixed pagination and detail-view issues for collection tasks. |
| CMDB | Fixed timezone handling and multilingual statistics issues for operations data sources. |
| Job Management | Optimized the task creation experience with default task name generation. |
| Operations Analytics | Optimized 3D data center large-screen visuals and added persistent topology layout for network status. |
| Operations Analytics | Fixed alert operations statistics criteria, large-screen loading status, and related issues. |
