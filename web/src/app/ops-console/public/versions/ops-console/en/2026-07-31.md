# July 31, 2026 Release Notes
Release Date: July 31, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| Node Management | Non-root users can now run controller installation commands via sudo for more flexible deployments. |
| Node Management | Added time consistency validation between node and server during controller installation to improve deployment reliability. |
| System Management | Added support for refreshing login state across browser windows without reload. |
| Monitoring | Website probing now supports advanced configuration, including request content, authentication credentials, and response validation. |
| Monitoring | Added configurable asset cleanup policies for auto-discovery to improve asset lifecycle management. |
| Monitoring | Monitoring lists now support custom display fields and sorting for personalized viewing. |
| Monitoring | Added the ability to view built-in metric configurations for greater monitoring transparency. |
| Alarm Center | Alert assignment now supports selecting notification scopes by organization for more precise alert delivery. |
| Operations Analytics | Added canvas sharing to facilitate analysis collaboration and reuse. |
| Patch Management | Patch Management is officially launched, supporting patch compliance checks and automated installation for full lifecycle patch governance. |
