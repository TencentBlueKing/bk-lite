# September 4, 2026 Release Notes
Release Date: September 4, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| Monitoring | Added SSH remote collection for AIX hosts |
| Monitoring | Supported connectivity tests for Telegraf-type monitoring onboarding |
| APM | Added .NET automatic probe onboarding |
| APM | Supported optional sampling rates in onboarding scripts |
| Operations Analytics | Added a two-layer rack scenario for deployment architecture |
| Operations Analytics | Built in a Flow traffic analysis dashboard |

### Improvements

| Module | Improvements |
| --- | --- |
| Node Management | Controller installation now defaults to the latest version for the current system and architecture |
| Node Management | Host node IPs now prioritize the IP address entered during installation |
| CMDB | Adjusted the collector architecture to improve concurrency performance |
| Monitoring | Completed common collection switches and related metrics for MySQL monitoring |
| Monitoring | Improved the layout of host, probe, and database dashboards |
| Log Center | Highlighted search results based on query conditions |
| Alert Center | Distinguished received time and occurrence time in event lists |
| Alert Center | Allowed platform superusers to reassign alerts awaiting response |

| OpsPilot | Automatically managed conversation compression based on the model context window |
| OpsPilot | Improved the platform AI assistant interaction experience |
