# August 14, 2026 Release Notes
Release Date: August 14, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| Node Management | Added support for remote Windows node installation, requiring Windows Server 2016 and PowerShell 5.1 or later. |
| Node Management | Node creation now supports on-demand synchronization to CMDB and Monitoring, helping unify host identity and observable objects. |
| Node Management | Node deletion and uninstallation now support synchronized handling of related objects, reducing residual assets and invalid monitoring instances. |
| CMDB | Themed views now support instance selection, recent visits, and independent memory, making frequently used topology and resource views easier to access. |
| Monitoring | Added multiple specialized monitoring dashboards covering Docker, Etcd, HAProxy, InfluxDB, MinIO, Oracle, and more. |
| Monitoring | Added support for MinIO multi-version metric monitoring, improving observability for object storage scenarios. |
| Monitoring | Added support for creating custom SNMP templates for all objects, making network and device monitoring extensions more flexible. |
| Operations Analytics | Added a Connection Library, supporting reuse of MySQL, PostgreSQL, and REST connections to reduce repeated credential configuration. |
| Operations Analytics | REST and Excel data sources now support optional Python transformations, making it easier to convert raw data into component-ready structures. |
| Operations Analytics | Added card list, radar chart, event timeline, relationship topology, and other components to enrich dashboard and large-screen presentation options. |
| Alert Center | Alert notification times now support formatting by recipient time zone, making cross-region collaboration easier to understand. |
| Patch Management | Periodic evaluations now support notification configuration, sending summary reminders when non-compliant hosts or evaluation failures are found. |
| Patch Management | Periodic tasks now support scheduling and display by user time zone, making evaluation times better match personal usage habits. |
| Patch Management | Baseline compliance details now show failure reasons and evaluation times for more direct issue diagnosis. |
| Patch Management | Baseline management now supports viewing the compliance matrix from both host and patch perspectives. |
| OpsPilot | The knowledge base now supports approval for same-knowledge conflicts across multiple materials, making knowledge governance more controllable. |

### Improvements

| Module | Improvements |
| --- | --- |
| Node Management | Optimized exception handling for offline images, object storage, temporary files, and related paths, making installation and download flows more reliable. |
| CMDB | Upgraded the top-level Views entry into a themed workspace, supporting direct access to application topology, K8S views, network topology, IP views, data center racks, and other themed views. |
| CMDB | CMDB instance external identity has switched to UUID, improving stability for cross-module references and external integrations. |
| CMDB | Optimized host identity linkage across Node Management, CMDB, and Monitoring to reduce duplicate assets and duplicate monitored objects. |
| Monitoring | Optimized display logic for K8S Pods, SNMP multiline metrics, collection status timelines, and more, making monitoring data interpretation more accurate. |
| Log Center | Optimized log query compatibility and special-field handling to reduce the impact of unusual log content on usage. |
| Operations Analytics | Dashboards now support responsive layout by container size, further improving component scaling, clipping, and report rendering. |
| Operations Analytics | Optimized Prometheus data sources, trend chart aggregation granularity, component error display, unsaved-change reminders, and related details. |
| Alert Center | Optimized the alert delivery lifecycle by isolating delivery status by channel and supporting failure compensation, making notification results more reliable. |
| Alert Center | Restored the bulk action entry in the active alert list, making bulk alert handling more efficient. |
| OpsPilot | Optimized WebChat streaming message display and SSE reconnection, making long conversations and weak-network scenarios more stable. |
