# October 30, 2026 Release Notes
Release Date: October 30, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| CMDB | Added collection data reconciliation with configurable source priorities for each field when multiple tasks collect the same asset, while preserving manual edits. |
| CMDB | Asset lists now support advanced filtering by related resource attributes, with options to save filter configurations and export results. |
| Monitoring | Policy group rules now support independent editing of metrics, alert conditions, and no-data settings. |
| Monitoring | Added monitoring for the Hyper-V platform and Cisco WAAS/WAVE. |
| APM | Alert policies now support combining multiple conditions and scoping detection to services, endpoints, runtime instances, and downstream dependencies. |
| APM | Supported comparisons with historical windows and averages for the same time window over the past N days, with trial calculations before saving and backtesting over the most recent 24 hours. |
| APM | Added SLO burn rate alerts over long and short windows to help identify risks to service quality targets. |
| RUM | Launched the RUM module to provide insight into website access and experience from real users. |
| RUM | Supported session replay and frontend error tracking, with Source Maps restoring error locations in the original code to help reproduce and diagnose issues. |
| RUM | Supported analysis of core experience metrics, including page loading, interaction responsiveness, and layout stability, with configurable experience alerts. |
| RUM | Supported conversion funnels and release comparisons to identify where users drop off and whether experience improves after a release. |
| Log Center | Aggregation alerts now support rate, change, ratio, and historical window comparisons, with trial calculations before saving. |
| Log Center | Supported thresholds for multiple severity levels and automatic recovery. |
| Log Center | Keyword alerts can now specify a minimum number of matches within a single detection window to reduce noise from isolated log entries. |
| Operations Analytics | Added a built-in Operations Overview dashboard to centralize operations data and alert trends. |
| Operations Analytics | Added a read-only Elasticsearch data source. Line and bar charts now support mapping category fields, multiple numeric fields, and series fields. |
| Orchestration Center | Flows now support export and import for migration across environments, sharing, and reuse. |
| Patch Management | Windows patch assessments now support offline scan catalogs without connecting to Windows Update, enabling use in isolated networks. |
| OpsPilot | Added a built-in PPT Master skill package to generate downloadable PPTX files and continue editing them in the same conversation. |
| OpsPilot | Added time series forecasting algorithm tools, enabling agents to analyze metric trends and capacity risks using monitoring data. |

### Improvements

| Module | Improvements |
| --- | --- |
| CMDB | Upgraded discovery scanning to a progressive workflow of port probing, process identification, and configuration collection. Potential objects can now be discovered even without configured database credentials. |
| Monitoring | Added VMware monitoring metrics and upgraded the Redis monitoring dashboard. |
| Operations Analytics | Canvases now support updates through YAML imports, with improved dashboard layout precision and wallboard component configuration previews. |
| Job Management | Improved distribution of long Linux Ansible scripts to prevent execution failures caused by excessive script length. |
| Orchestration Center | Improved approval entry points and execution record displays for smoother flow processing. |
| OpsPilot | Improved image delivery to WeCom and Feishu by reducing duplicate attachments and improving delivery when generation is interrupted. |
