# September 18, 2026 Release Notes
Release Date: September 18, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| CMDB | Added SSL certificate TLS handshake collection |
| CMDB | Added credential management for collection onboarding |
| CMDB | Expanded Oracle collection coverage to CDB, PDB, and RAC |
| CMDB | Supported exact multi-address queries for internal and external IPs in asset lists |
| CMDB | Supported monitoring views, alert lists, monitoring policies, related topology, asset changes, and node status in asset details |
| Monitoring | Added SNMP collection for multiple brands of network and power devices, including Huawei switches, routers, and WLAN, H3C and Ruckus wireless devices, PDU, UPS, transmission devices, and more |
| Monitoring | Supported related topology, asset information, asset changes, and node status in object details |
| Log Center | Added generic Kafka log subscription integration |
| Log Center | Supported condition configuration items for Syslog and SNMP Trap extractors |
| Alert Center | Supported filtering alert and event lists by monitoring source |
| Alert Center | Displayed monitoring source event statistics in integration source details |
| Alert Center | Added WeCom application and IM channels to dispatch notification methods |
| Alert Center | Supported monitoring views, asset information, asset changes, raw alert logs, node status, service overview, and call chains in alert details |
| Operations Analytics | Supported alert-based sorting and pagination for the 3D application wall |
| OpsPilot | Added CMDB, Monitoring, Log Center, and Alert Center tools |
| OpsPilot | Supported OKF export and import for the knowledge base and enhanced embeddings |
