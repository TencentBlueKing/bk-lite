# September 11, 2026 Release Notes
Release Date: September 11, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| System Management | Supported switching the platform layout between classic and app top-bar modes |
| System Management | Provided platform API documentation with PDF export support |
| System Management | Launched a credential repository to centrally manage referenced credentials |
| CMDB | Added Redfish collection for physical servers |
| CMDB | Added NetApp ONTAP and Dell Unity storage collection in beta |
| Monitoring | Added remote host collection for FreeBSD, Solaris, and HP-UX |
| Monitoring | Supported pulling Tencent Cloud and Alibaba Cloud resources by account and selecting regions during onboarding |
| Monitoring | Built a Namespace column into the K8s Pod view with filtering support |
| Monitoring | Supported policy assignee configuration, alert claiming and dispatching, and My Alerts filtering |
| APM | Supported policy assignee configuration, alert claiming and dispatching, and My Alerts filtering |
| Log Center | Supported structured additional conditions in extractors to distinguish device logs in syslog and SNMP Trap data |
| Log Center | Supported policy assignee configuration, alert claiming and dispatching, and My Alerts filtering |
| Alert Center | Added associated topology viewing for alert objects |
| Alert Center | Supported custom alert notification templates |
| Operations Analytics | Added a built-in WeOpsX platform usage dashboard |
| Operations Analytics | Added a zombie host report, requiring CMDB, Monitoring, and Log associations to be configured first |
| Operations Analytics | Added a K8s operations dashboard |
| Operations Analytics | Supported copying canvases across directories |
| Operations Analytics | Supported screen-display embed mode for the console |
| OpsPilot | Supported importing OKF knowledge packages, with body images stored together with the package |
| Alert Center | Supported priorities for dispatch policies |
