# October 16, 2026 Release Notes
Release Date: October 16, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| Operations Analytics | AI dashboard creation supports conversational data source search and chart generation. |
| Operations Analytics | Added a built-in application topology wallboard. |
| Monitoring | Added onboarding for more than 20 vendor device models, including Calix, Ubiquiti, Cisco, Huawei, and Aruba. |
| APM | Service details can now show outbound HTTP calls and database queries by method. |
| Job Management | Added Windows and Linux host health inspections, connecting the full workflow from form to job, report, and notification. |
| Job Management | Script template parameters now support enumeration types, and links in hints are clickable. |
| Alert Center | Notification templates now apply colors automatically based on alert severity. |
| Alert Center | Pushed alerts now include object fields and an IP summary. |
| Alert Center | Alert details now provide one-click navigation to the alert source. |
| Node Management | Node installation progress can now be refreshed manually. |
| OpsPilot | Added agent-powered document generation for formats including Excel, Word, Markdown, and PDF. |
| OpsPilot | Users can now upload attachments in conversations for AI analysis based on their contents. |
| OpsPilot | Knowledge base materials can now be deleted in batches, making content management more efficient. |
| System Management | Added OpenAPI endpoints for ITSM user and organization directories. |
| System Management | Added overage limits and license reminders to license management. |
| Operations Analytics | Dashboard, report, topology, and wallboard components now support CSV data export. |

### Improvements

| Module | Improvements |
| --- | --- |
| Operations Analytics | Completed the machine room statistics in the 3D data center view. |
| Operations Analytics | Enhanced wallboard creation with size, background image, text color, undo, and redo settings. |
| Monitoring | Restructured the event entry into four levels: alerts, policy groups, individual policies, and policy templates. Entire policy groups can now be enabled or disabled with one click. |
| Job Management | Orchestration Center now automatically cancels associated jobs when a flow is terminated and strengthens sensitive information controls. |
| Alert Center | Replaced the reporting contact with the asset owner and prioritized notifying the asset owner. |
| OpsPilot | Improved agent interaction so tasks are no longer interrupted automatically when users take a long time to respond. |
