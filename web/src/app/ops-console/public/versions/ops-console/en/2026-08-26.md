# August 26, 2026 Release Notes
Release Date: August 26, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| System Management | Supported OTP whitelists in security policies |
| System Management | Supported OTP unbinding in user management |
| System Management | Supported configuring multiple pull DNs for AD user synchronization |
| Node Management | Supported WinRM HTTPS/HTTP protocols for Windows remote installation and uninstallation |
| CMDB | Added tag views with property-based filtering and remembered filter conditions |
| CMDB | Supported saving NICs during physical-server collection, allowing network topology to associate switches with server NICs |
| CMDB | Supported multi-select comparison in rack views |
| Monitoring | Added LLM monitoring and specialized dashboards for vLLM, SGLang, and llama-server |
| Monitoring | Added monitoring and specialized dashboards for Active Directory and Microsoft Exchange |
| Monitoring | Added specialized NetFlow/sFlow traffic analysis dashboards with session tables, top sessions, and top protocol analysis |
| Monitoring | Supported automatic creation of monitoring policies on the monitoring onboarding page |
| APM | Service onboarding: supported Java, Python, Node.js, and Go with language-specific onboarding guidance |
| APM | Service overview: view health status and availability and latency SLO compliance from application and service perspectives |
| APM | Service topology: display inter-service call dependencies and identify downstream services such as Redis and PostgreSQL even when they are not instrumented |
| APM | Trace analysis: search traces by time and service, with detail views supporting waterfall charts, flame graphs, and span lists |
| APM | Error analysis: aggregate errors by exception type for more direct failed-request troubleshooting |
| APM | Performance alerts: configure alert policies by error rate, latency, and throughput to discover service issues promptly |
| Log Center | Supported configuring field extractors by collection type for Syslog and SNMP Trap |
| Operations Analytics | Added the Application3D application scene component for large screens |
| Operations Analytics | Supported personal drafts on canvases |
| OpsPilot | Supported AI assistant access to current page context, currently limited to monitoring dashboard page content |
| OpsPilot | Added an OpsPilot AI assistant chat window in the lower-right corner of the platform |
