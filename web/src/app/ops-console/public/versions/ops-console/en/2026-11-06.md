# November 6, 2026 Release Notes
Release Date: November 6, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| CMDB | Tencent Cloud collection now includes TKE clusters and nodes, VPN gateways, and NAT gateways, with support for synchronizing cloud tags. |
| CMDB | Built-in models and model groups now support changes to their names, icons, and owning organizations to fit asset management practices. |
| Monitoring | Added a dedicated PostgreSQL dashboard covering database health, Top SQL, wait events, and primary-replica replication. |
| APM | Added offline Trace probes for Ruby, C++, Erlang, and Swift, with downloads and onboarding configuration available from the platform. |
| APM | Added Trace probes for PHP, Windows .NET, and specified Go processes to expand application tracing coverage. |
| Alert Center | Notification templates now support event samples and log search links, giving recipients quicker access to troubleshooting context. |
| Operations Analytics | Added rotation across multiple canvases, allowing dashboards, architecture diagrams, and other views to be added to a rotation list and played in full screen. |
| Operations Analytics | Filters now support cascading options: downstream choices update when upstream conditions change. |
| Job Management | Ansible jobs now support execution across hosts running different operating systems in the same job. |
| Orchestration Center | Added a File Distribution node that invokes the job platform to distribute files within a flow. |
| OpsPilot | Added job management tools that allow agents to execute scripts, distribute files staged in the current conversation, and provide access to job records. |
| OpsPilot | The conversation input area now supports viewing staged files. |

### Improvements

| Module | Improvements |
| --- | --- |
| Node Management | Collection configurations are now retained when nodes are deleted or uninstalled, allowing them to be reused when the nodes reconnect. |
| CMDB | Asset exports now preserve selections across pages, and collection operation logs include task and change source information. |
| Monitoring | Added replication lag and replication slot backlog metrics to PostgreSQL monitoring to help investigate synchronization issues. |
| Monitoring | Expanded Riverbed SteelHead monitoring with connection, optimization service, and peer information. |
| Operations Analytics | Expanded dashboards with host and process health status, CPU I/O wait, and other data. |
| Job Management | Improved Windows PowerShell job output to reduce garbled Chinese characters in live logs. |
| Orchestration Center | Hardened flow execution and termination handling to reduce duplicate job submissions and continued execution after termination. |
