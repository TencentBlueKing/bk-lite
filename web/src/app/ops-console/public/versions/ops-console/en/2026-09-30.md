# September 30, 2026 Release Notes
Release Date: September 30, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| System Management | Supported viewing API call logs |
| CMDB | Added Redfish collection for physical servers |
| Job Management | Supported ZIP batch import and export in the script library |
| Monitoring | Added collection for more than 20 device models, including Juniper, Radware, Riverbed, Aruba, and more |
| Monitoring | Supported multi-select, chart comparison, and multi-series activation in metric queries |
| Node Management | Supported cross-page selection and full-set batch operations in the node list |
| Node Management | Supported exporting the node list to Excel for selected items, the current page, or all items |
| Node Management | Added online status and component status to combined filters |
| Alert Center | Supported event-reference syntax in notification templates and displaying related events |
| Alert Center | Supported fuzzy asset search in alert lists and navigation into details |
| Operations Analytics | Supported flexible role-based mapping for chart data source fields |
| OpsPilot | Added built-in AD tools and a K8s configuration skill package |
| OpsPilot | Added a Feishu channel for agent publishing |
| OpsPilot | Supported image display in knowledge base Q&A |
