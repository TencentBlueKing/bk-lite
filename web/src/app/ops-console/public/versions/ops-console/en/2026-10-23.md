# October 23, 2026 Release Notes
Release Date: October 23, 2026
Learn more about product capabilities in the [official documentation](https://www.bklite.ai) or try the [Demo environment](https://bklite.canway.net).

### New Features

| Module | New Features |
| --- | --- |
| Platform | The BK-Lite Operations Assistant is now available in the WorkBuddy skill marketplace, allowing users to retrieve platform data for AI analysis. |
| System Management | Added OpenAPI endpoints for querying notification channels and delivering messages, allowing external systems to use platform notification capabilities. |
| CMDB | Network device collection now includes hardware serial numbers for chassis, boards, and other components to simplify asset verification. |
| CMDB | Asset lists and instance details now display UUIDs, with UUID filtering for precise lookup. |
| Monitoring | Added policy groups that bundle policy templates and apply them together to monitored assets. |
| Monitoring | Alert policies can now trigger only when multiple metric conditions are met, such as high CPU usage and high memory usage. |
| Alert Center | Raw event and alert data can now display CMDB enrichment information and responsible owners, providing more complete troubleshooting context. |
| Alert Center | Integration event lists now support status filtering, and byte values in alerts are automatically converted to readable units. |
| Operations Analytics | Architecture diagrams now support batch insertion and binding of CMDB resources, with access to resource details and alert status. |
| Operations Analytics | Dashboards can now be set as the login homepage, taking users directly to their preferred business view after login. |
| Job Management | Job scripts now support platform variables that automatically provide information such as the executing user and job ID. |
| Orchestration Center | Launched Orchestration Center, a new module for building flexible automation flows and automating complex tasks. |
| Orchestration Center | Supported 15 workflow node types, including job execution, document generation, and external notifications. |
| Orchestration Center | Added built-in Windows and Linux system inspection flow templates for an out-of-the-box automated inspection experience. |
| OpsPilot | WeCom persistent connections can now return AI-generated files directly, while short-connection messages provide download links. |

### Improvements

| Module | Improvements |
| --- | --- |
| CMDB | Unrecognized network devices can now be confirmed and imported after their type, brand, and model are completed. |
| Monitoring | Upgraded the MySQL dashboard with overview, performance, replication, Top SQL, and wait analysis sections, making critical anomalies easier to identify. |
| Alert Center | Improved alert severity coloring in WeCom and Feishu notifications to make urgency easier to recognize. |
| Operations Analytics | Improved the asset overview with support for light and dark themes. |
| Patch Management | Added disk space and operating system version checks before Windows patch installation to identify hosts that do not meet installation requirements. |
| Patch Management | Added WUA matching validation to Windows baseline assessments to detect patch compatibility, including whether a .NET patch matches the host .NET Framework version. |
| OpsPilot | The platform AI assistant now manages conversation history and generated files together, making them easier to find and download. |
| OpsPilot | Improved coordination between page context and tool calls, along with interaction feedback during knowledge base imports. |
