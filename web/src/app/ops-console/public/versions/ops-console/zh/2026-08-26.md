# 2026年8月26日 更新日志
版本发布时间：2026年8月26日
了解更多产品能力，欢迎查阅[官方文档](https://www.bklite.ai)或直接体验[Demo环境](https://bklite.canway.net)

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| 系统管理 | 安全策略支持 OTP 白名单 |
| 系统管理 | 用户管理支持OTP解绑 |
| 系统管理 | AD 用户同步支持配置多个拉取 DN |
| 节点管理 | Windows 远程安装/卸载支持 WinRM HTTPS/HTTP协议 |
| CMDB | 新增标签视图，支持按属性筛选并记住筛选条件 |
| CMDB | 物理服务器采集支持网卡入库，网络拓扑可关联交换机与服务器网卡 |
| CMDB | 机柜视图支持多选对比 |
| 监控中心 | 新增 vLLM、SGLang、llama-server 的 LLM 监控能力及其专业仪表盘 |
| 监控中心 | 新增 Active Directory、Microsoft Exchange 监控能力及其专业仪表盘 |
| 监控中心 | 新增 NetFlow/sFlow 专业流量分析仪表盘，支持会话表、Top 会话与 Top 协议分析 |
| 监控中心 | 监控接入页面支持自动创建监控策略 |
| APM | 服务接入：支持 Java、Python、Node.js、Go，按语言提供接入指引 |
| APM | 服务概览：从应用/服务视角查看健康状况以及可用性、时延 SLO 是否达标 |
| APM | 服务拓扑：展示服务间调用依赖，未接入的 Redis、PostgreSQL 等下游服务也可识别 |
| APM | 调用链分析：按时间、服务检索 Trace，详情支持瀑布图、火焰图与跨度列表 |
| APM | 错误分析：按异常类型聚合错误，定位失败请求更直接 |
| APM | 性能告警：按错误率、时延、吞吐配置告警策略，及时发现服务问题 |
| 日志中心 | Syslog、SNMP Trap 支持按采集类型配置字段提取器 |
| 运营分析 | 大屏新增 Application3D 应用立体场景组件 |
| 运营分析 | 画布支持个人草稿 |
| OpsPilot | AI助手支持读取当前页面上下文（目前仅开放监控仪表盘页面内容） |
| OpsPilot | 平台右下角增加OpsPilot AI助手聊天窗 |
