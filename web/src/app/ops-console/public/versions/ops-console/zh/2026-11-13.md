# 2026年11月13日 更新日志
版本发布时间：2026年11月13日
了解更多产品能力，欢迎查阅[官方文档](https://www.bklite.ai)或直接体验[Demo环境](https://bklite.canway.net)

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| CMDB | 云资源配置采集支持同步云资源的标签 |
| 监控中心 | Nginx 监控补充请求、连接累计值及采集状态，并支持按需开启 VTS 指标采集 |
| 监控中心 | F5 BIG-IP 监控新增故障切换角色与配置同步状态，支持对同步失败、对端失联等情况告警 |
| 告警中心 | 告警丰富支持补充所属应用、应用系统及负责人信息，便于识别业务归属和通知责任人 |
| 运营分析 | 大屏新增限时投屏链接，可供电视等设备展示，并支持设置有效期、停用或重新生成链接 |
| 运营分析 | 新增 CMDB、监控、告警通用查询数据源，可按条件筛选并配置图表 |
| OpsPilot | 支持智能体无人值守运行 |

### 功能优化

| 模块 | 功能优化 |
| --- | --- |
| 系统管理 | 用户可在个人信息中自助解绑 OTP 验证器 |
| CMDB | 优化资产附件展示与下载，解决部分环境下图片无法访问的问题 |
| 监控中心 | MongoDB 仪表盘优化连接、缓存、内存与成员状态展示，排查数据库运行状况更直观 |
| APM | 优化首页、服务指标和告警策略的聚合查询 |
| RUM | 优化应用概览、页面性能和会话列表查询，提升数据量较大时的访问体验 |
| 运营分析 | 优化长时间范围的折线图、柱状图查询与渲染性能 |
| OpsPilot | 优化智能体附件处理、作业结果读取和聊天历史展示 |
