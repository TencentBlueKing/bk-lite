# 2026年10月30日 更新日志
版本发布时间：2026年10月30日
了解更多产品能力，欢迎查阅[官方文档](https://www.bklite.ai)或直接体验[Demo环境](https://bklite.canway.net)

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| CMDB | 新增采集数据调和，多个任务采集同一资产时，可按字段配置来源优先级，保留人工修改 |
| CMDB | 资产列表支持按关联资源属性高级筛选，可保存筛选方案并导出结果 |
| 监控中心 | 策略组规则支持独立编辑指标、告警条件与无数据配置 |
| 监控中心 | 新增 Hyper-V 平台、Cisco WAAS/WAVE 监控 |
| APM | 告警策略支持组合多个条件，并按服务、接口、运行实例及下游依赖设置检测范围 |
| APM | 支持历史窗口、近 N 天同窗均值对比，保存前可试算并回放最近 24 小时 |
| APM | 新增 SLO 长短窗燃烧率告警，帮助发现服务质量目标的消耗风险 |
| RUM | 全新上线 RUM 模块，从真实用户视角了解网站访问与使用体验 |
| RUM | 支持会话回放与前端错误追踪，结合 Source Map 还原错误代码位置，辅助复现和定位问题 |
| RUM | 支持页面加载、交互响应、布局稳定性等核心体验指标分析，并可配置体验告警 |
| RUM | 支持转化漏斗与版本发布对比，了解用户在哪一步流失、上线后体验是否改善 |
| 日志中心 | 聚合告警支持速率、变化量、占比及历史窗口对比，保存前可试算 |
| 日志中心 | 支持分级阈值与自动恢复 |
| 日志中心 | 关键字告警可配置单个检测窗内的最少命中条数，减少零散日志干扰 |
| 运营分析 | 新增内置「运维总览」仪表盘，集中查看运维数据与告警变化趋势 |
| 运营分析 | 新增 Elasticsearch 只读数据源，折线图与柱状图支持分类、多个数值及系列字段映射 |
| 编排中心 | 流程支持导出/导入，方便跨环境迁移与分享复用 |
| 补丁管理 | Windows 补丁评估支持使用离线扫描目录，无需连接 Windows Update，适配隔离网络环境 |
| OpsPilot | 新增内置 PPT Master 技能包，支持生成可下载的 PPTX，并在同一对话中继续修改 |
| OpsPilot | 新增时序预测算法工具，赋能智能体结合监控数据分析指标走势与容量风险 |

### 功能优化

| 模块 | 功能优化 |
| --- | --- |
| CMDB | 扫描发现升级为「端口探测 → 进程识别 → 配置采集」递进流程，未配置数据库账号也可发现疑似对象 |
| 监控中心 | 补充VMware 监控指标，升级 Redis 监控仪表盘 |
| 运营分析 | 画布支持通过 YAML 导入更新，优化仪表盘布局精度与大屏组件配置预览 |
| 作业管理 | 优化 Linux Ansible 长脚本分发，避免脚本过长导致执行失败 |
| 编排中心 | 优化审批入口与执行记录展示，处理流程更顺畅 |
| OpsPilot | 优化企业微信、飞书图片回传，减少重复附图，改善生成中断时的图片投递体验 |
