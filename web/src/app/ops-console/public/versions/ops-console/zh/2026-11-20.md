# 2026年11月20日 更新日志
版本发布时间：2026年11月20日
了解更多产品能力，欢迎查阅[官方文档](https://www.bklite.ai)或直接体验[Demo环境](https://bklite.canway.net)

### 功能新增

| 模块 | 新增功能 |
| --- | --- |
| 系统管理 | 新增「超级审计员」角色，可只读查看全部组织和应用数据 |
| CMDB | 采集任务支持暂停和恢复，暂停期间保留任务配置和已入库资产 |
| CMDB | 支持按指定用户字段批量交接资产负责人 |
| CMDB | 资产列表支持按关联实例快捷筛选，无需打开高级筛选 |
| 监控中心 | 新增 SQL Server 专业仪表盘，集中查看实例健康、缓冲与内存、I/O 与存储及等待情况 |
| 监控中心 | 策略组支持增减策略模板，并可查看各监控实例当前生效的模板 |
| 告警中心 | 事故影响拓扑支持展开关联资产，并查看相关应用和应用系统的当前告警 |
| 日志中心 | 日志提取器新增 Grok 模式，支持搜索内置模式并用历史日志预览提取结果 |
| 运营分析 | 新增内置「监控概况」大屏，集中查看监控覆盖、未恢复告警情况 |
| 运营分析 | 新增内置「网络设备汇总」大屏，集中查看网络设备运行情况 |
| 运营分析 | 大屏支持将查询结果的指定列保存为变量，供组件参数引用 |
| 作业管理 | 目标管理支持引用系统管理-凭据管理中的主机凭据 |
| 编排中心 | 定时流程支持绑定执行账号和组织，启动前校验执行权限，执行记录展示实际运行组织 |
