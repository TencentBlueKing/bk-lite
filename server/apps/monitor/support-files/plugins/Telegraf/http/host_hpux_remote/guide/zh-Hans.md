# HP-UX主机远程采集

这是 Host 对象下的 HP-UX 远程采集。Linux 采集节点按采集间隔 SSH 到 HP-UX，执行系统命令。目标主机无需安装采集器。无需在表单上选择版本，版本会自动识别。

采集内容：CPU、负载、内存与交换区、磁盘容量与 inode、磁盘忙碌与吞吐、网卡、运行时长、操作系统版本。不采集硬件清单、lastlog、lsof 和连接表。

## 怎么用

1. 选择能访问该 HP-UX 的 Linux 采集节点。
2. 填写目标主机 IP、SSH 用户名（如 root）、密码或私钥，以及采集间隔。
3. 保存，等一个采集周期，在 Host 里看数据。

## 表单字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 目标主机IP | 是 | HP-UX 地址。 |
| 用户名 | 是 | SSH 用户名，例如 `root`。 |
| SSH认证方式 | 是 | 密码或 SSH 密钥。 |
| 密码 / SSH私钥 | 视认证方式 | 选密码则填密码；选密钥则填私钥，口令可空。 |
| 端口 | 否 | 默认 22。 |
| 采集间隔 | 是 | 默认 60 秒。 |
| 节点 | 是 | 执行采集的 Linux 节点。 |

## 目标主机命令

脚本按需调用这些 HP-UX 命令；某条不存在或失败则跳过，或走下一档回退：

- `uname`、`model`：操作系统版本与机型
- `uptime`：负载与运行时长
- `sar -u`，回退 `vmstat`：CPU
- `swapinfo`，必要时 `machinfo`：内存与交换区
- `bdf` / `bdf -i`：磁盘容量与 inode
- `sar -d`，回退 `iostat`：磁盘忙碌与吞吐
- `lanscan`、`nwmgr`、`lanadmin`：网卡字节计数；都不可用时回退 `netstat -in`

## 网络吞吐可能为 0

优先用 `nwmgr` / `lanadmin` 读取网卡 octet 计数器，再对相邻采集点做 rate，得到吞吐。

当这两条路径都拿不到 octet（命令不存在、无权限或解析失败）时，脚本回退到 `netstat -in`。HP-UX 上该输出是包计数，不是字节，脚本会把 `rx_bytes` / `tx_bytes` 记为 0，因此网络吞吐为 0。此时仍可能有网卡名和错误计数。要看到吞吐，请保证采集账号能执行 `nwmgr` 或 `lanadmin -g mibstats`。

部署后若控制台还没有本插件，执行 `plugin_init`。
