# Host AIX Remote

这是 Host 对象下的 **AIX 远程采集**：通过系统命令监控 AIX 操作系统。每次按间隔从 Linux 采集节点 SSH 连到 AIX 取数，不在目标主机上长期安装。命令不存在则跳过，不在表单上选择版本。版本由 `oslevel -r` 读取（例如 `7100-00`）。

本发行**不提供 Host AIX 本机采集**。本机采集的含义是选已纳入的 AIX 节点、由节点上的 nats-executor / `local.execute` 跑采集；AIX 目前不能作为已纳入节点运行 sidecar / nats-executor，因此不会用 SSH 伪装成本机，接入页上也不会再出现「本机采集却填 SSH」的 Host AIX 表单。请只用本远程插件。

采集内容：CPU（含 LPAR 授权容量与在线虚拟 CPU）、内存与分页、svmon 分类（含 pin）、1 / 5 / 15 分钟负载、进程状态（SysV `ps` 的 `s` 列，命令或列不存在则跳过）、磁盘容量 / inode / 读写 / 忙碌、网卡、运行时长。不采集硬件清单、lastlog、lsof 和连接表。

## 怎么用

1. 选择能访问该 AIX 的 Linux 采集节点。
2. 填写目标主机 IP、用户名、SSH 认证方式（密码或密钥）和采集间隔。
3. 保存，等一个采集周期，在 Host 里看数据。

## 表单字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| 目标主机IP | 是 | AIX 地址。 |
| 用户名 | 是 | 默认 `root`。 |
| SSH认证方式 | 是 | 密码或 SSH 密钥。 |
| 密码 / SSH私钥 | 视认证方式 | 选密码则填密码；选密钥则填私钥，口令可空。 |
| 端口 | 否 | 默认 22。 |
| 采集间隔 | 是 | 默认 60 秒。 |
| 节点 | 是 | 执行采集的 Linux 节点。 |

部署后若控制台还没有本插件，执行 `plugin_init`。若仍能看到旧的 Host AIX 本机接入项，同样执行 `plugin_init` 使其消失。
