# 深信服 aStor/EDS 分布式存储 SNMP 接入指南

本能力通过 Telegraf `inputs.snmp` 采集深信服 EDS / aStor 分布式存储私有 MIB（企业号 35047，对象树 `1.3.6.1.4.1.35047.2.12`）。监控对象为 **存储**，不是防火墙或其它网络设备。采集类型为 `snmp_storage_sangfor_eds`，与防火墙叶子 `snmp_sangfor` 互不占用。

证据口径：厂商 MIB 对齐；无真机 walk，待实机校验。请勿将本模板当作已完成现网采数核验。

## 前置要求

- 目标存储已启用 SNMP v2c 或 v3，并开放 UDP 161（或实际填写的端口）。
- 采集节点能够访问管理地址。
- 团体名或 v3 凭据由环境注入，不要写入仓库或截图。

## 接入步骤

1. 在监控对象 **存储**（硬件设备分类）中选择插件「深信服 aStor/EDS 分布式存储」。
2. 填写目标 IP、端口、SNMP 版本与认证信息，采集间隔建议 `60` 秒。
3. 选择采集节点并保存，等待至少一个采集周期。

## 页面字段说明

| 页面字段 | 是否必填 | 说明 |
| --- | --- | --- |
| IP | 是 | 存储管理地址。 |
| 端口 | 是 | SNMP 端口，默认 `161`。 |
| 版本 | 是 | `v2c` 或 `v3`。 |
| 团体名 | v2c 必填 | SNMPv2c 团体名。 |
| 名称 / 级别 / 认证协议 / 加密协议 | v3 按级别 | SNMPv3 安全参数。 |
| 超时时间 | 是 | 单次请求超时，默认 `10` 秒。 |
| 间隔 | 是 | 采集周期，默认 `60` 秒。 |

## 主要指标

- 集群：`sangfor_eds_cluster_*`（主机数、SSD/HDD 已用与空闲、三网正常/异常网卡数、物理容量字节、池数量）
- 块存储池：`sangfor_eds_block_pool_*`（容量字节、使用率、恢复/同步/均衡/亚健康任务、状态）
- 容量池：`sangfor_eds_capacity_pool_*`（容量、任务、daemon/PG/池状态）
- 磁盘：`sangfor_eds_disk_*`（状态、类型、容量、使用率、寿命、坏道），维度 `disk_name`
- LUN：`sangfor_eds_lun_usage_rate`，维度 `lun_name`
- 主机：`sangfor_eds_host_*`（在线、CPU、内存，字符串可解析时转换），维度 `host_name`

使用率类 DisplayString（厂商文档 0..1）采集后转换为 0-100 百分比。状态类字符串映射为 `1` 正常、`2` 异常、`3` 未知；空值与 notPresent 为 `1`；厂商字面 unknown 为 `3` 且不告警；策略仅匹配 `=2`。

不采集网络设备语义的 `device_*` 指标，也不复用防火墙 `35047.1` / `35047.2.1` OID。

## 接入后验证

保存并等待一个采集周期后，在存储对象下确认集群容量与主机数等指标可查询。若字段为空，先核对 SNMP 版本、团体名与管理地址可达性，再对照厂商 MIB 是否已在该软件版本开放对应节点。

## 常见问题

### 与防火墙插件冲突吗

不冲突。防火墙叶子使用 `snmp_sangfor` 与 `35047.1` / `35047.2.1`；本插件使用 `snmp_storage_sangfor_eds` 与 `35047.2.12`。

### 状态显示为「未知」

值为 `3` 表示厂商字面 unknown 或无法归入 documented 枚举，不会触发 `=2` 告警。待实机校验后再决定是否补充映射。
