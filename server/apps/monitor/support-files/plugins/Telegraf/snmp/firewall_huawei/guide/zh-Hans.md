# 华为 USG 防火墙 SNMP 接入指南

本插件用于监控华为 USG 防火墙的设备健康与会话/吞吐：实体 CPU/内存/温度/电压，当前会话、新建会话、建连速率、半连接、TCP/UDP/ICMP 会话数，以及整机转发吞吐。USG9500 在插有 SPU 时额外报告各 SPU CPU 使用率。接入后仍作为现有防火墙对象，无需为 USG6000E、USG9500 或 HiSecEngine USG 新建监控对象。接口指标使用平台内置 IF-MIB，本插件不扩展 ifTable / ifXTable。

## 支持机型

同一插件覆盖下列华为防火墙系列。盒式、框式与 HiSecEngine 都使用该监控对象，无需再建新对象。

- USG6000 系列
- USG6000E 系列
- USG9500（框式；SPU CPU 使用率仅在插有 SPU 时有数据）
- HiSecEngine USG

未插 SPU 或非框式机型的 SPU 表为空，不会阻断整机会话、建连速率或吞吐。部分对象在特定软件版本上为空，也不代表整机采集失败。

## 前置要求

- 选定节点能够访问目标设备的 SNMP 端口（默认 `161/UDP`）。
- 设备已启用 SNMPv2c 或 SNMPv3，并授权只读访问。
- 建议使用 SNMPv3（认证+加密）。若使用 v2c，团体名仅填写在页面专用字段中。
- 只读视图应授权标准 IF-MIB，以及 `1.3.6.1.4.1.2011.5.25.31`（实体健康）、`1.3.6.1.4.1.2011.6.122.69`（当前/新建会话）和 `1.3.6.1.4.1.2011.6.122.15`（会话统计、整机吞吐与 SPU 使用率）。

## 接入步骤

1. 确认节点到设备 IP 的 SNMP 连通性（见“接入前校验”）。
2. 选择 SNMP 版本。v2c 填写团体名；v3 填写安全名称、安全级别、认证/加密协议和密码。
3. 按需调整端口、超时和采集间隔。默认端口 `161`，超时 `10` 秒，间隔 `60` 秒。
4. 在监控对象表格中选择节点，填写设备 IP、实例名称和分组。
5. 保存并等待至少一个采集周期。

## 接入前校验

将 `TARGET` 换成设备 IP，将团体名换成只读团体（v3 环境请改用对应的 v3 探测方式）：

```bash
TARGET=192.0.2.10
snmpget -v2c -c "$SNMP_COMMUNITY" "$TARGET" 1.3.6.1.2.1.1.3.0
snmpget -v2c -c "$SNMP_COMMUNITY" "$TARGET" 1.3.6.1.2.1.1.2.0
snmpget -v2c -c "$SNMP_COMMUNITY" "$TARGET" 1.3.6.1.4.1.2011.6.122.69.1.1.2.0
snmpget -v2c -c "$SNMP_COMMUNITY" "$TARGET" 1.3.6.1.4.1.2011.6.122.15.6.5.0
```

`sysUpTime`（`1.3.6.1.2.1.1.3.0`）应返回 TimeTicks。华为 USG 的 `sysObjectID`（`1.3.6.1.2.1.1.2.0`）属于企业号 `2011`。当前并发会话（`…122.69.1.1.2`）或 64 位吞吐（`…122.15.6.5.0`）在部分版本上可能无实例，可再探测 `…122.15.1.2.1.4.0`（总会话）或 `…122.15.6.2.0`（整机会话）。

## 页面字段说明

| 页面字段 | 是否必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| IP | 是 | 无 | 目标设备管理地址。编辑时不可修改。 |
| 端口 | 是 | `161` | SNMP UDP 端口。 |
| 版本 | 是 | v2c | `v2c` 或 `v3`。 |
| 团体名 | v2c 必填 | `public` | 只读团体名。 |
| 名称 / 级别 / 认证协议 / 认证密码 / 加密协议 / 加密密码 | v3 按级别 | 按页面 | 仅 SNMPv3 使用；密码经环境变量注入，不会写入明文配置。 |
| 超时时间 | 是 | `10` 秒 | 单次 SNMP 请求超时。 |
| 间隔 | 是 | `60` 秒 | 采集周期，最小 `1` 秒。 |
| 节点 | 是 | 无 | 执行采集的节点。 |
| 实例名称 | 是 | 无 | 平台中的展示名称。 |
| 组 | 是 | 无 | 实例所属分组。 |

## 接入后验证

等待至少一个采集周期，确认实例出现并检查：

- `snmp_uptime` 持续增长。
- `device_cpu_usage`、`device_memory_usage` 有实体维度读数。
- `firewall_active_sessions` 或 `firewall_device_sessions` / `firewall_total_sessions` 有会话读数。
- `firewall_session_rate` 或 `firewall_device_session_rate` 有建连速率。
- `firewall_throughput`（64 位）有整机转发吞吐；若仅有 32 位对象，则看 `firewall_throughput32`。
- USG9500 插有 SPU 时，`firewall_spu_usage` 按槽位与 CPU 有读数。无 SPU 时该表为空，不代表整机采集失败。

## 常见问题

### 只有 uptime 和接口，没有 CPU/内存

设备 SNMP 视图可能未授权实体健康对象。请确认只读视图包含 `1.3.6.1.4.1.2011.5.25.31`。

### 有 CPU，没有会话或吞吐

请确认只读视图包含 `1.3.6.1.4.1.2011.6.122.69` 与 `1.3.6.1.4.1.2011.6.122.15`。不同系列可能只实现其中一组对象，空对象不阻断其余指标。

### 没有 SPU CPU 使用率

盒式 USG6000 / USG6000E / HiSecEngine 通常无 SPU 表。仅 USG9500 等框式设备在插有 SPU 时返回 `hwSecStatUsage`。索引是性能表的槽位/CPU 列，不要按 ENTITY 名称去对齐。

### 高速口流量为 0 或不准

接口流量走平台内置 IF-MIB 的现有 64 位 `ifHCInOctets` / `ifHCOutOctets`。本插件不新增 ifXTable 计数器。整机转发吞吐请看 `firewall_throughput`，不要把它当成接口字节。
