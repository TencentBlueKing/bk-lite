### 说明
自定义采集执行的是插件库里上传的脚本，不是主机、Nginx 等内置采集脚本。脚本只负责采集，查回的数据仍按插件选择的目标模型入库。

采集开始时按任务取一次脚本，多个 IP 共用这一份。脚本正文不会出现在下发配置里。

### 怎么连接
操作系统在创建插件时确定，任务凭据跟着操作系统走。

| 插件操作系统 | 连接方式 | 默认端口 | 凭据 |
| :--- | :--- | :--- | :--- |
| Linux | 目标已在节点管理中时，由该节点本地执行；否则由接入点 SSH 登录后执行 | 22 | 用户名、密码 |
| Windows | WinRM。协议默认 HTTPS，认证默认 NTLM | 5986 | 用户名、密码 |

Linux 脚本只能使用 bash 或 sh。Windows 脚本只能使用 powershell 或 bat。选主机时会按插件操作系统过滤；IP 范围无法事先判断系统，协议不对就会连不上。

### 怎么执行脚本
1. 在「自定义插件」里上传脚本，并选择目标模型和操作系统。
2. 在「采集 → 自定义」里选中该插件，新建任务，填写周期、接入点、IP 范围或主机，以及对应操作系统的登录凭据。
3. 任务执行时，采集器取出脚本并在目标上运行。单次脚本执行时间不超过任务超时，最长 600 秒。

### 怎么返回数据
脚本把结果打印到标准输出，内容是一个 JSON 数组。每条记录必须有 `inst_name`，其余字段名与目标模型的属性一致。没有 `inst_name` 的记录会被丢弃。

```json
[
  {"inst_name": "demo-nginx", "ip_addr": "10.0.0.8", "port": "80"}
]
```

入库后的指标名是 `{插件标识}_info`。例如插件标识为 `custom_nginx_linux_scan` 时，指标名为 `custom_nginx_linux_scan_info`。
